# 克隆使用改造：安装链路与首次配置

日期：2026-10-26。基线：已整合框架的 master `319381f`。本轮只推进公开准备计划中的安装和初始化基础，不代表整体公开发布完成。

## 已实现

- 移除部署型 npm install 生命周期，使用显式 deploy 命令。
- 增加 doctor 和 init。环境检查只执行有超时的版本命令；初始化使用独占、原子发布，保留已有配置与稳定身份，不覆盖损坏文件。
- 完整测试成功后为当前构建写入验证凭据。安装要求干净提交、对应构建及未变化的完整摘要；测试期间构建变化时拒绝签发凭据。
- 发布目录包含编译后的网页、服务端、原生适配脚本和单独安装的锁定生产依赖。运行目录不再依赖开发目录的 latest.json 或 node_modules。
- 在全新暂存目录准备和检查产物，再发布为不可变 release。摘要覆盖运行文件、依赖、权限及相对符号链接，拒绝越界链接。构建不复制 Python 缓存。
- 正式入口恢复固定网页与手机端口，并保留原有配对、证书更新、健康检查和失败回退。新增 Fastify HTTPS 监听器先等待 ready。
- launchd 保留显式配置和状态目录、浏览器路径及运行 PATH；禁止在 release 中生成 Python 字节码。已有完整 release 可校验后离线复用；保留旧源码版本回退路径。
