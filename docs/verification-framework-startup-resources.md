## CPU 定位采样

追加桌面各一次首屏 CPU profile。只按采样节点自身 URL 分类，基准应用脚本约 68.36 ms，候选约 97.80 ms。扩展分别约 329.50／230.92 ms，垃圾回收约 90.33／13.37 ms，说明单轮总耗时存在明显干扰。

候选主要应用节点包含 app chunk 的模块执行和共享 React chunk；共享 chunk 的文件名包含组件名称，不代表全部开销来自该组件。另采到 React 调试扩展的宿主节点测量。未关闭扩展、替换框架或删减 UI 来获取较低读数。下一步需要定位初始化阶段的重复渲染和同步工作，再用相同数据复验；目前不能将采样差异归因为已证实的单一性能问题，也不能标记性能门槛通过。
