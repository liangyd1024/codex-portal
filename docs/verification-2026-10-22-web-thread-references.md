# 普通网页会话引用验收

基线：`47da132`。功能提交：`7d13fae`。范围是 RCM 的普通网页执行入口。

## 行为

网页 B 输入 `@`，可选择同一连接中网页创建的 A 和桌面创建的 C，再发送要求。发起者 B 不需要交还桌面，被引用对象也不需要在桌面打开。候选同时保留已安装插件；技能仍使用 `/` 或 `$`。同名身份按原生会话 ID 区分。

网页通过原生会话级 MCP 配置加载 `rcm_references.read_referenced_thread`。这属于 RCM 提供的只读适配工具，不冒充桌面 `read_thread`。执行仍由 Codex 原生轮次完成。工具只转发已验证的 `thread/read`、`thread/items/list`，不恢复、接管或修改被引用会话，不维护会话副本或独立模型循环。

用户文字保持原样，引用 ID 和原生标题经 `turn/start.additionalContext` 传递。模型按需读取原文；保留原生工具结果和失败。每条消息最多 20 个引用，每次读取 1–20 项并沿用原生游标。单页超过 1 MiB 时返回错误，不能截断后宣称完整。标题和消息被明确标记为不可信上下文。

工具授权按目标机器、发起会话和用户曾明确选择的会话 ID 限定；模型不能传入主机、命令或文件路径扩大范围。RCM 工具脚本和授权 ID 缓存放在目标用户的 RCM 自有目录，不写入 Codex 全局配置、原生数据库或聊天记录，不包含原文，不在现有备份范围内。

## 新旧会话

实测原生版本：`0.163.0-alpha.11.1`。`thread/start.config` 和未加载会话的 `thread/resume.config` 可启用 MCP；对已加载会话调用 resume，配置覆盖不会生效。

- 新网页会话通过原生创建请求启用工具。
- 已卸载的旧会话先用同一 ID 恢复，再查询工具状态。直接查询未加载会话会返回 `thread not found`，已补回归测试并真实复验。
- 已加载且尚无工具的旧会话，在空闲、无目标运行、无队列、无后台进程和待处理请求时，原生 unsubscribe 后等待卸载，再原 ID resume。仅在已知卸载延迟不超过 10 秒时自动执行，最多等待 15 秒。
- 释放未确认、连接变化、恢复失败时返回失败并保留草稿；已释放但恢复失败时，尽力恢复原网页订阅，不伪造工具可用状态。
- 不中断既有任务。运行中追加引用、首次目标启动与引用合并发送暂不支持。

## 真实原生服务验证

仅操作独立测试会话，真实身份和原始响应保存在仓库外。

1. 开发预览通过普通网页接口创建 B。B 同时引用网页 A 和桌面 C。原生历史出现两次成功的 `rcm_references.read_referenced_thread` 工具调用，读取对象正确。最终返回内容分别匹配 A 的原始最终回复和 C 的随机标记。要求中没有给出预期答案，未使用终端或文件工具读取。B 全程没有交还桌面。
2. 独立 stdio 原生测试进程创建旧会话，先完成无引用轮次，再执行准备。准备前无工具，原 ID 释放恢复后工具可用，读取返回成功。
3. 另一个隔离进程以未加载的测试 B 执行恢复和授权，工具启用成功。测试进程退出，没有重启目标服务。
4. 直接工具读取网页和桌面来源的原始分页数据均成功。前次只读原生探测已确认读取前后 loaded 列表均为空；历史读取不要求加载被引用对象。

实际模型端到端验证在预览服务完成。SSH 目标、跨机器引用、会话交还桌面后的自有工具兼容性、真实输入法候选窗尚未验收。跨机器引用不在当前支持范围。恢复环境丢失授权缓存时须重新选择引用。
