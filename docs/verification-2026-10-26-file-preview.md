# 正文文件预览优化验收

## 范围与原生依据

基于 `49e4dbd` 开发。本记录随功能提交保存；具体功能提交可用 `git log --oneline -- scripts/file-reader.py src/web/services/file-preview-text.ts` 定位。

只读检查配置指向的桌面应用资源。正文文件引用包含复制路径、保存、系统应用打开菜单；工作区文件打开参数包含 line、column、endLine 和 right 目标。源码证据支持路径和引用位置语义，不等于完整原生界面实机对照。既有项目目录浏览使用原生 fs/getMetadata 和 fs/readDirectory，但本轮没有把项目采用或目录创建流程接入正文预览。

本轮保留网页弹窗和只读文件范围，不声称与原生编辑器完全一致。不修改原生安装、数据、会话或任务。

## 实现

- 文件夹和其他特殊文件返回明确提示，不再显示无效重试。权限限制和不存在文件同样不重试；网络错误和消息尚未保存仍可重试。HTTP 保留读取端的 retryable 信息。
- 显示真实文件名、路径，支持复制路径；失败时仍可手动选中路径。复制带行号的文件时使用核验后的文件路径。
- 支持 `:行`、`:行:列`、`#L行` 和 `#L行C列`。真实同名文件优先。源码滚动至引用行并高亮整行，状态显示引用位置；列号暂仅展示，不作列级光标定位。
- 源码使用 14px 等宽字体和 1.625 行高，保留长行并在内容区横向滚动。引用行不在预览范围时明确提示。
- Markdown 默认排版，可切回源码。带行号的 Markdown 默认源码。复用正文安全渲染器，HTML 不执行，不启用文件内路径的递归读取。
- 文本仍最多读取 1 MiB，UTF-8 截断不在边界增加乱码。Markdown 排版限制为 200,000 字符且不超过 5,000 行；更大文件保留源码。没有增加后台轮询、预读或第三方依赖。
- 关闭取消请求，迟到响应不恢复弹窗；媒体恢复正常后清除旧重试状态。

## 验证

专项测试覆盖目录四种读取模式拒绝、引用行解析、同名文件、UTF-8 边界、HTTP 重试信息、关闭取消和错误状态。完整 `npm test` 包含类型检查、构建、Node 和 Python 测试。最终数量与正式版本见本记录后续交付段。

浏览器使用 ego-browser，加载独立 4327 预览及虚构文件夹具。全部业务请求与 SSE 被夹具隔离，不操作原生会话。

- 桌面 1500×767：Enter 打开、Escape 关闭、焦点返回、Tab 焦点、默认和悬停样式通过。相邻关闭、复制、下载控件均为白底、1px 黑边；焦点轮廓清晰。
- iPhone 12 设备模式：390×844、844×390、390×500，DPR 3，5 点触控和 coarse 指针逐组核对。通过触控事件打开、切换源码和关闭。按钮至少 44×44px，页面与弹窗没有横向溢出，引用行处于内容可视区。390×500 仅模拟短可视高度，不代表真实软键盘。
- Markdown 标题、表格和代码可读；脚本内容为文本，javascript 链接不激活。切换源码不增加文件读取请求。
- 文件夹、受限文件没有重试或下载；不支持格式保留下载。网络失败可重试，关闭等待中的预览只取消一次且不重开。
- 路径复制成功与失败反馈使用模拟剪贴板验证，失败后按钮恢复可用。
- 初次设备参数跨脚本轮次失效，作废该组样本。补验在每组同一脚本内设置并检查设备参数。另一次触控坐标落在可视区外，改为先滚动至可视区再触控后通过。

## 性能与边界

源码只创建一个文本节点，引用行场景创建两个文本节点和一个高亮节点，不按行创建大量 DOM。25 万行、50 万字符的夹具仍为单个文本节点；单次自动化打开到检查约 375 ms（包含工具与渲染开销），不是纯渲染基准，也不据此声称性能最优。文本每次打开仍为元信息和文本两个请求，切换排版使用同一份内容。

未验证实体 iPhone、系统剪贴板、真实远端文件读取、原生编辑器打开或完整原生预览视觉对照。没有新增目录内容浏览、语法高亮、全文行号、图片缩放或大文件分页读取。本轮不改变图片、音视频和 PDF 的展示方式。
