# 正文文件变更卡片

## 依据与范围

依据用户提供的 Codex 截图，将文件清单放在对应轮次的回复下方。移除“工作区详情”中跨轮次累计的文件清单。保留原生正文和执行过程记录。

卡片只读取本轮原生 `fileChange`。按文件路径合并展示行，按原顺序保留同一文件的每次变更。项目内路径显示为相对路径，完整路径保留在提示中；项目外路径不截短。点击文件行展开原始变更。缺少变更内容时明确提示。进行中、失败、中断、取消和状态未确认沿用原生记录，不显示为编辑成功。

本轮没有核实原生撤销接口和最终净增删行数来源，因此不提供撤销按钮，也不将多次补丁累加冒充净变更统计。原生记录未包含的命令写文件不会被推断为文件变更。此次只调整主会话文件清单。

- 回归测试覆盖轮次隔离、重复路径、原始补丁顺序、项目边界、中文路径、空记录及失败状态。卡片协调测试覆盖缓存节点复用和变更后惰性事件处理器的替换。
- ego-browser 独立 4327 预览，使用 `mobile-browser.js` 和 `turn-files-browser.js` 拦截业务请求。验证两个轮次各有自己的卡片；无变更会话不显示卡片；切换返回后恢复本会话记录。模拟业务请求没有写入真实引擎。
- 桌面 1440×1000：卡片位于回复后方，宽度沿用正文；右侧清单已移除。键盘 Enter 展开和收起通过，焦点轮廓为 2px。已查看最终截图。
- iPhone 12 设备模拟：390×844、DPR 3、移动视口、5 点触控，核对 coarse pointer 生效。文件行触控目标为 356×44 CSS px，真实派发 touchStart/touchEnd 后展开；后续等待确认两个原始补丁已加载。长路径换行，无页面横向溢出。844×390 横屏和 390×480 缩小可视高度也无横向溢出。已查看最终截图。
- 模拟修改中、失败、成功、中断和取消状态均出现对应提示。模拟断开连接后仍保留已读卡片。追加正文时卡片、原始补丁节点和展开状态保持不变，额外网络请求为零。

## 性能与未验证项

卡片复用现有轮次缓存。原始补丁文本节点仅在展开对应文件时创建。首次模拟加载新增补丁节点数为零，展开后按原始记录创建。删除右侧每次全量遍历历史的重复汇总，没有新增接口、轮询或依赖。

本机 Node 微基准：1000 条记录、200 个文件，连续聚合 100 次共约 11.1 ms。该结果仅代表展示数据聚合，不代表原生服务响应时间，也未据此声称性能最优。

未执行实体手机、真实软键盘、系统剪贴板或中文输入法检查。本轮未修改输入流程。未通过真实文件编辑任务验证完整原生事件链路；浏览器业务验证为模拟，不能视作正式部署验收。

实现版本以包含本记录的提交为准。正式部署结果在执行安装流程后补充。
