# Mermaid 图表渲染验收

## 范围

原有消息解析将所有 fenced code 渲染为源码。新增完整 `mermaid` 代码块的图表展示、源码切换、复制、放大与失败重试。未闭合代码块仍显示源码。保留原始消息、图表方向及源码，不修改原生会话。

参考既有富消息验收与用户提供的源码截图。未取得桌面 Codex 的 Mermaid 交互证据，不声称与桌面端完全一致。

使用官方 `@mermaid-js/tiny` 12.2.0 固定资源与 MIT 许可证。本地资源约 2.81 MB，gzip 743,777 字节，仅首次可见图表加载。Tiny 不包含思维导图、架构图、KaTeX 与 ELK；无法渲染时展示源码与重试。Safari 版本基线见 vendor 说明。

主页面 CSP 不放宽。渲染使用不允许同源权限的 sandbox iframe，禁止网络连接，严格模式禁用图表节点脚本与链接交互。仅渲染页面允许 SVG 所需的内联样式。返回 SVG 作为 data 图片展示，不插入工作台 HTML。图表源码限 30,000 字符、300 条边；渲染超时后销毁隔离页并允许重试。

按可见区域渲染，队列串行；成功结果缓存上限为 24 张及约 4 MB 字符。相同源码保留 DOM，避免流式更新时重建图表。

## 自动测试

`npm test`：675 项 Node 测试、72 项 Python 测试通过。

新增回归测试覆盖完整与未闭合代码块、原始源码保留、流式 DOM 保留及源码变化替换、资源白名单、渲染页 CSP 与主页面 CSP 隔离。

## 浏览器隔离验证

开发预览 4327 已被其他项目使用，未停止该服务、未更改开发预览端口。本次未启动独立应用预览。

使用 ego-browser 独立标签页，浏览器拦截只提供本地静态文件和虚构消息；不调用业务接口。自动化工具不能拦截独立 iframe 的全部资源请求，因此隔离样本将相同渲染脚本内联到 sandbox srcdoc，通过测试 nonce 加载。此模拟不能代替正式 iframe 的 HTTP、CSP 和资源加载验证。

- 桌面 1280×900：中文七节点流程图、时序图显示；源码逐字一致，复制内容一致；放大、Esc 关闭、焦点返回通过。
- 语法错误：显示原始源码、失败提示及重试入口；放大保持禁用。
- 默认、悬停、焦点与禁用样式检查；按钮沿用共享控件变量。
- iPhone 12 模拟：390×844、DPR 3、移动视口、5 点触控，`pointer: coarse` 生效。通过触控事件验证源码切换、放大及关闭。按钮触控区域不小于 44×44。
- iPhone 12 横屏 844×390、缩小可视高度 390×420：无页面横向溢出。长图在自身区域内滚动，不修改 LR 方向。
- 100 次消息更新保留同一图表和图片节点，隔离样本约 4.9 ms；重复源码复用相同图片 URL。该数据仅为单次模拟场景，不代表跨设备性能最优。

实体手机、真实软键盘和旧版 Safari 未验证。本次不修改输入流程。不操作既有会话或发送测试消息。
