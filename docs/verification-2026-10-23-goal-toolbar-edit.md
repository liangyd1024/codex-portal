# 目标栏直接编辑与原生继续语义

## 原生依据与改动

只读核对桌面应用包中的 app-primary-58a09006cc0c.js：目标栏 SE.Row 的 onClick 打开目标编辑器。保存调用 setThreadGoal，appendTranscriptItem 为 false。app-initial-c95ddb62696e.js 的 u8t 向 thread/goal/set 提交 objective 与 status=active。此前仅修改内容、保留暂停状态的实现不符合此保存逻辑。本记录更新此前目标编辑验收中的状态语义。

目标栏左侧图标、标题、用时区域改为可聚焦按钮，点击或按 Enter 打开现有目标编辑框。右侧保留删除和暂停／继续。修改内容后，服务端校验编辑基线，再通过原生接口提交新内容与 active；不另发 turn/start，不替换预算，不改写历史。无变化保存仍不写入。原生引擎决定实际执行及用量限制。

编辑保存期间禁用目标栏操作。成功后恢复入口焦点。失败保留草稿，跨会话迟到回执不抢焦点。复用原有弹框和样式变量，没有新增依赖、计时器或轮询。
