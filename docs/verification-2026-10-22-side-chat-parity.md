# 侧边聊天与选文交互验收

日期：2026-10-22。

## 范围

侧边聊天复用主聊天的输入工具、图片处理、引用和消息渲染。支持图片、图文剪贴板、技能、已安装插件、会话引用、计划及执行计划、运行中补充、停止入口和请求回答。按用户要求不提供侧边语音。选文评论增加预览和统一按钮，点击外部或 Escape 收起并保留未提交评论。主聊天和侧边聊天选择模型或思考档位后收起弹层。

仍使用原生临时会话。目标与定时任务不支持，刷新后不能恢复。不修改引擎和原生持久化数据。临时会话的异步问题回答先核对原生轮次，再使用同一连接收到的原生请求。

交互依据为用户提供的截图及已有 [选文功能核验](verification-2026-10-22-selection-tools.md)。本轮未重新读取 Codex 桌面界面，不声称像素级一致。

## 浏览器模拟验证

使用 ego-browser，开发预览配合模拟 HTTP/SSE 数据，未向真实业务会话发送消息。

- 桌面验证选文评论外部收起、主侧模型切换收起、技能及插件选择、侧边请求回答、图文复制剪切粘贴。
- 模拟请求验证图片、技能、插件、会话引用和计划选项进入侧边会话。执行计划沿用原生计划文本；运行中补充使用侧边 steer 接口。
- 模拟发送失败后保留文字、图片及引用；连接断开后禁用输入，恢复后继续使用。主聊天草稿不受侧边选择影响。
- 消息复用主聊天表格、代码和过程展示。侧边请求显示在侧边输入框上方。
- iPhone 12 参数：390×844 CSS 像素、DPR 3、mobile、触控、coarse pointer。另测 844×390 横屏及 390×500 可视高度缩小场景，无页面横向溢出；输入框可见。
- 触控模型菜单可打开并在点击外部后收起。触控模式 Enter 换行。合成中文组合输入事件不发送。
- 手机图片输入与工具入口截图已人工查看。最终一次工具菜单采样发生在打开事件后、定位事件前，得到超出视口的瞬时坐标；随后改为点击时同步定位并限制底部位置。这项最终定位调整通过代码检查，未再次浏览器验收。

浏览器任务空间已结束。实体手机、系统中文输入法和真实软键盘未实测；停止按钮未对真实任务执行。本轮未做真实临时会话新建、图片推理、插件执行和问题回答端到端验证。既有原生能力核验见上述记录。

## 性能

流式刷新合并到动画帧，复用未变化消息节点；输入高度仅在内容或宽度变化时重算。模拟连续 100 次消息增量到两个动画帧约 18 ms，已有完整消息节点保持同一 DOM 实例，新增网络请求为 0。此结果仅代表本机合成浏览器场景，不是长会话或真实网络性能结论，未声称性能最优。
