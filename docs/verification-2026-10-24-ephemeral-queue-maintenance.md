# 临时会话排队检查与登录恢复

## 问题与修复

重新加载登录和停止目标服务共用维护检查。检查遍历全部已加载会话，调用原生 `thread/queue/list`。原生临时会话返回 `ephemeral thread does not support queued submissions: <threadId>`，此前该错误直接中止检查。

仅当错误全文与当前检查的会话 ID 匹配时，将排队能力视为不适用。仍检查会话运行状态、目标、后台命令、待处理请求和检查期间的连接变化。网络错误、其他会话 ID、额外错误文本和无效返回结构继续阻止维护。未修改认证错误识别、原生引擎或原生数据。

## 边界

没有执行真实引擎重启或登录重载，避免影响运行任务。登录是否恢复须在目标 Codex 完成登录并满足维护条件后核验。没有修改 UI；没有执行手机设备或实体输入验证。
