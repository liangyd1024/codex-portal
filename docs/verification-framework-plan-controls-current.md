# 当前候选计划卡片复核

## 基准与环境

正式 4317 为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`，候选 4327 为 `41605a7075e216ec7a743ab6605cb10a138d34ff`。报告整理时重新读取版本接口，两者保持不变。候选资源为 `ec11c5735025907428ff45249d6f1eea683c5fc5ae740c174e3787bd02bae65b`。

使用同一 Ego Lite 空间，保留正常扩展与 React 调试回调。桌面 1480×747、DPR 2、无触控；iPhone 12 模式为 390×844、844×390、390×480、DPR 3、触控开启。导航后重新设置设备参数，每份样本均核对实际视口、DPR 和触控能力。

两个静态隔离入口提供同一组虚构会话、原生计划文本和模拟 HTTP 回执。正常按钮操作在桌面使用鼠标，在手机模式使用触控。没有向真实原生引擎提交计划，没有操作既有会话。

## 对照结果

共 184 份状态样本、92 组配对一致。每组比较卡片节点矩形、字体、颜色、背景、边框、隐藏状态、忙碌状态、状态文案、按钮文案与禁用状态、焦点、草稿、计划存储记录和完整提交请求体。所有样本无页面异常和横向溢出。

| 场景 | 样本／配对 | 验证内容 |
| --- | --- | --- |
| 常规提交与结果未知 | 64／32 | 展示、拒绝执行、提交等待、明确拒绝、结果未知、重复触发、核实后重试和成功 |
| 断线与 Escape | 32／16 | 离线禁用、恢复连接、组合输入期间 Escape 保护、普通 Escape 关闭 |
| 立即失败 | 24／12 | 无延迟 409 拒绝及随后成功重试 |
| 跨会话迟到回执 | 64／32 | 拒绝和成功两类回执，覆盖等待、切换后、迟到结果处理后和返回原会话 |

常规流程的提交次数依次为 0、0、1、1、2、2、2、3；重复触发未增加请求。测试对等待中的禁用按钮和结果未知时不可用的提交按钮调用 DOM click，验证程序触发保护；这部分不冒充可见按钮的真实触控。断线流程全程无提交。

组合输入期间的 Escape 通过合成带组合状态的键盘事件检查，普通 Escape 使用浏览器按键。该证据覆盖页面输入保护，不代表真实中文候选窗测试。

立即 409 拒绝后，两版焦点均落在 BODY；延迟失败具有不同的时序。此处保留基准行为，没有将共同表现误判为候选回归。

跨会话测试等待原会话计划状态实际变为 open 或 sent 后再取样，证明迟到结果已被应用处理。每个流程仅提交一次，另一会话草稿始终保留，返回原会话时原草稿仍在。两版输入禁用状态一致。成功与拒绝均没有把旧回执套用到新会话的计划卡片。

## 结论与限制

本专项未发现候选相对基准的差异，无产品代码修改。私有原始记录保存在仓库外；本报告及汇总文档为本次变更，因此没有重复运行应用测试、构建或重启服务。最近应用代码的完整回归见交付状态记录。

本报告不证明真实原生计划执行、实体手机软键盘、系统选区、剪贴板或整体性能通过。SSH 的另一次只读身份重试仍在约 15 秒后连接超时，正式与预览配置一致，未执行远端业务操作。该限制不改变上述隔离 UI 对照结果，也不能据此把真实 SSH 验收标为通过。
