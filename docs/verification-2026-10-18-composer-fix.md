## 原因与处理

- 工具栏作为输入框的兄弟节点，没有消息区的宽度约束，宽屏下执行/权限靠页面左侧、工具靠页面右侧。增加共享宽度与居中边距，工具菜单以入口按钮定位；重复的完全访问说明移到权限选择的提示中，保留目标和技能状态。
- 正式会话 `01a14e0b-13c8-7992-b221-99d2ad802915` 已空闲，但真实后台列表仍包含 `python3 /tmp/rcm-composer-preview.py`。这是之前留下的 4327 静态验收服务器。经用户明确授权，核对进程后仅停止 PID 77429。随后真实接口返回后台列表为空，对应命令状态 failed、退出码 143（SIGTERM），没有停止正式网页或目标引擎。
- 原运行提示还会把历史 commandExecution.inProgress 当作当前后台任务，实时列表为空也无法清除。改用实时列表；读取失败、断线或缺少确认时显示“后台命令状态待确认”，不显示运行动画和停止按钮。运行状态显示数量、命令悬停提示，并把停止按钮名称明确为停止后台命令。
- 图片解码使用 blob URL，而正式服务 CSP 的 img-src 只允许 self 和 data。Ego Lite 在正式页面复现 decode 失败及 img-src/blob 违规。改用 FileReader 数据 URL 进入原有缩放压缩流程，保持 CSP 不变。之前静态 Python 验收页缺少正式响应头，因此没有覆盖这次故障。
