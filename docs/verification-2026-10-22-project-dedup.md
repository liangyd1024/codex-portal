# 同目录项目合并展示

## 原因与边界

真实服务只读核对发现，用户反馈的同名同目录项目有两个原生 ID。其中一个已由桌面映射并放入自定义分区，另一个仍在根项目列表。网页原先按 ID 分别展示。

网页项目登记与桌面项目列表仍是不同流程。已有原生接口调研见 [项目创建实测](research-2026-10-21-native-project-creation.md)。本次没有发现新的可独立调用的桌面项目登记接口，没有直接改写原生存储，也没有重启桌面或引擎。需要桌面显示时，在目标机器桌面添加同一文件夹；是否复用原生 ID 由桌面处理，网页只合并展示。

## 修复

侧栏按完整根目录集合合并展示，优先保留置顶、自定义分区和桌面映射项目入口。合并全部会话，保留各会话原始 projectId；新近排序重新比较时间，手动排序保留各入口既有顺序。使用旧 ID 展开项目时定位到合并入口。不同目录的同名项目、根目录集合仅部分相交的项目、无根目录的项目不合并。不解析符号链接，不推断不同路径为同一目录。

项目选择器按目录去重。目录弹窗提示在桌面添加同一文件夹。原生项目和会话未删除、未迁移，没有建立新的项目数据来源。
