# 操作仅在失败时弹出提示

沿用 `verification-2026-10-23-inline-feedback.md` 的交互基线。截图中的归档处理中浮动提示属于旧正式版本；此前修复因空闲检查未通过而未部署。

## 改动

- 统一浮动提示入口默认忽略成功和处理中消息。忽略时不创建 DOM 节点或定时器；同一操作的旧失败提示可清除。
- 创建会话期间重复操作直接返回，保留已有忙碌状态。
- 定时任务管理会话打开失败、草稿冲突显式标记为失败，避免被过滤。
- 全局检查 `public/` 的 toast、notify 和 alert 调用。用户主动点击用量查看详情属于信息查询，显式保留；非操作完成通知。原有局部状态、归档撤销及用户开启的系统任务通知不变。
