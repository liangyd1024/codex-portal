# 手机新会话项目选择

依据用户提供的长项目下拉截图、既有 creation/mobile 验收记录，手机端将原生 select 替换为可搜索的底部模态面板。项目列表独立滚动，行高至少 48px，当前选项带勾选；同名项目显示路径区分。选择即时更新原有 select 并触发原有草稿保存逻辑，取消不修改项目和消息。桌面继续使用原生 select。没有取得 Codex 原生手机项目选择器的直接证据，不声称完全对齐其视觉实现。

面板支持关闭按钮、遮罩和 Escape 取消；方向键定位选项，Enter 选择。搜索框 Enter 不提交会话；中文组合输入期间不触发选择。创建状态禁用原有项目控件时面板同步关闭并禁用入口；页面关闭或切回桌面布局时关闭面板。尺寸跟随已有 visualViewport 变量，适应软键盘缩小的可见区域。

验证：ego-browser 空间 79，4327 隔离预览，现有 mobile-browser fixture 拦截全部 API，并在原 select 补充到 41 个模拟项目。390×844 及 390×440 均无横向溢出；短屏面板范围 y=132..440，搜索与关闭入口可见，内部列表滚动。1440px 桌面原生 select 可见，手机触发按钮隐藏。搜索、无结果、方向键和 Enter 选择、Escape/遮罩/关闭按钮取消、关闭后焦点返回、中文草稿保留、禁用同步关闭通过；组合输入事件模拟未选择项目或发出 POST。手机和短屏截图已检查，文件分别位于 /tmp/rcm-project-picker.png 和 /tmp/rcm-project-picker-short.png。

工作目录 npm test 通过 140 项 Node 与 33 项 Python（包含其他会话正在开发的回归用例）。正式安装前另在已提交 master 副本执行全量测试。未做实体 iOS/Android 软键盘、原生输入法候选或真实引擎创建会话验收；本次不发送真实消息。
