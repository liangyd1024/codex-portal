# 目标机器目录与新建项目入口

## 改动

在新建会话的项目选择器增加“浏览文件夹 / 新建项目”。目录跟随当前连接，默认打开目标 HOME；支持主目录、上级、绝对路径、隐藏目录、创建子目录和使用当前目录。空项目列表仍能进入浏览器。创建完成后选中新项目，保留原消息草稿，不自动发送。

目录读取、创建和项目登记均通过目标原生 RPC。已有同根路径项目直接复用。项目创建携带浏览器预先保存的 UUID 请求标识，失败后重试使用相同标识；成功回执校验根路径后才更新目录缓存。目录名称拒绝路径分隔符、首尾空白、点目录、空字符及超长值。创建目录不递归补建父目录，不覆盖同名文件。

保留 Origin、CSRF、手机配对和目标身份检查。写入计入部署维护检查；同一管理器的目录/项目写入串行处理。每个 RPC 步骤检查连接代次，关闭弹窗或断线后迟到结果不选中新项目。断线保留输入并禁用操作；恢复后刷新目录再继续。中文组合输入与确认保护、Escape 关闭和入口焦点恢复均保留。

协议核验 policy 升为 8，新增 projectFolders 能力，未核验或缺少接口时拒绝操作。生成协议的临时目录保留，不使用递归自动清理。

桌面差异在弹窗与 README 明示：原生项目可在网页版使用，当前不会自动加入 Codex 桌面的项目列表。依据为[双机调研](research-2026-10-21-native-project-creation.md)，没有写入桌面项目缓存或创建另一套项目数据库。
