# 浏览器备份按连接导入验收

日期：2026-10-26。基线：`1e5be7e`。本记录随实现提交。

## 行为

校验来源机器及连接 ID、机器 ID、用户和 HOME。允许连接集合不同，但只能选择身份匹配的连接。按连接筛选草稿、视图、选项和缓存，不恢复其他连接、全局设置、待处理发送与重试记录。连接集合完全一致时保留显式整份导入入口。

写入前预览状态与缓存覆盖数量。缓存预览只读取 IndexedDB 键，避免读取全部聊天缓存。没有新增轮询。未作新性能基准测量。导入失败恢复浏览器存储，缓存写入沿用 IndexedDB 事务。

## 验证

- `npm test` 最终通过 935 项 Node、79 项 Python；提交后需生成匹配提交的全量验收凭据。
- 新测试覆盖连接集合变化、移除连接、相近 ID、错误身份、错误机器、损坏缓存、越界存储与输入不变性。
- 真实浏览器使用独立静态模拟入口，未连接真实引擎。按连接导入后，所选连接状态更新；未选连接及全局设置保留。缓存写入故障注入后，状态回退、错误可见、按钮恢复。
- 桌面 1440×900、DPR 1：选择、覆盖预览、键盘 Tab 和可见焦点通过；相邻控件白底黑边风格一致。
- iPhone 12 模式：390×844、844×390、390×480，DPR 3，触控点 5；无横向溢出。选择标签和操作按钮最小高度 44px，实际触控选择通过。未测试实体手机文件选择器、软键盘或系统选区。
- 浏览器跨调用的模拟参数会重置；初次跨调用触控操作未执行，重新在同一调用设置参数后验证。一次加载等待错误地检查了隐藏 dialog 的存在，检查页面确认导入和刷新已成功；不作为应用故障。
- 一次早期全量测试在旧 passive-store 测试的临时 SQLite 建库阶段发生 Python 20 秒超时。该次不计通过。未改超时或跳过测试；独立单项及 13 项整组复查通过，最终全量回归通过。超时根因未确认，保留原日志。

正式部署结果将在提交后的验收中补记。本轮不代表历史隐私审计完成或仓库可以转为公开。
