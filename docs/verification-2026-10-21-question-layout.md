# 提问卡片字体与输入区占位

## 依据与修改

参考用户截图、2026-10-19 问题卡片协议记录及字体核验记录。使用系统字体、16px 正文与输入框、1.625 行高。覆盖旧审批卡片对问题标题、选项说明和来源文字的浅黄配色及小字号。选项整行可点，保留焦点轮廓。所有问题继续平铺，没有分页。

桌面输入区原为可压缩的 flex 子项，内部内容不随外层压缩，可能侵入正文空间。现按实际高度占位，上限为会话区域的 70%；问题列表可缩小并内部滚动，输入框和操作区不压缩。未改变消息原文、回答协议或引擎行为。
