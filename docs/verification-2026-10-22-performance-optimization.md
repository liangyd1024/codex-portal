# RCM 性能优化与分层调整验收

日期：2026-10-22。依据：[已确认优化计划](performance-and-structure-audit-2026-10-22.md)。

本轮落实计划中可验证的首屏、渲染、静态传输、SSH 连接复用及基础分层改进。未改 Codex 原生数据、执行语义或配置，没有截断会话内容，没有新增框架、运行依赖或调度器。

## 实施内容

| 范围 | 实施与边界 |
| --- | --- |
| 首屏请求 | 初始化期间合并重复刷新；已有状态可供首次工作区读取使用。前后端合并相同在途侧栏读取，不缓存完成后的业务结果。显式变更会安排新一轮读取。搜索、连接与选择变化不共用旧请求。 |
| 侧栏 | 首屏使用 `activity=deferred`，列表与项目先返回。新增只读活动端点，单批最多 200 个会话。身份由原生账号读取决定；连接、列表版本、快照和账号不匹配时丢弃迟到结果。已有活动标记沿用原观察时间，不延长有效期。默认侧栏接口仍保留原有完整响应行为。 |
| 静态资源 | 白名单文件使用 gzip、表示相关的 ETag、Vary、HEAD 和 304。压缩结果在进程内复用，文件修改后失效。鉴权和配对边界保持原有检查；不公开任意仓库文件。 |
| 正文渲染 | 按轮次和消息缓存呈现节点。未变历史复用已有 DOM；变化消息仍走原有协调逻辑。输出增量与分页位置独立更新。切会话清空呈现缓存，移除不在页面的条目。 |
| 无关刷新 | 纯正文流式事件不刷新文件列表、请求区和输入控制区。其他事件保留完整刷新。隐藏页面暂停非必要定时刷新，原有前台恢复、通知与 SSE 继续工作。输入镜像仅在文本或样式变化时重绘。 |
| 延迟初始化 | 手机访问和系统更新在首次进入分类时初始化，保留正在读取、失败与重试。首屏所需输入样式提前声明，主模块增加预加载。 |
| SSH | 当前入口的长期隧道作为自己的控制连接；独立私有目录和随机路径，不借用其他入口。只读 Python 和文件读取显式允许复用，普通写入默认不复用。ControlPersist 关闭，保留严格主机校验、配置密钥与身份验证。 |
| 分层 | 提取 `lib/core/errors.mjs`、`pending-read.mjs`、`lib/http/static-response.mjs`、`lib/transports/ssh-options.mjs`；跨端纯逻辑迁至 `shared/`，原 public 路径保留兼容导出。解除审计指出的四组循环依赖。 |

没有把所有源码立即搬到新目录。`app.js` 和 `manager.mjs` 仍有集中职责；本轮先建立明确且能单独测试的边界。相对 ESM 导入检查中，`lib/` 与 `shared/` 未发现循环。

## 性能结果

设备和工具：同一台开发 Mac，Node 原生服务，ego-browser Chromium；桌面 1440×900，窄屏 390×844。预览固定端口 4327，状态目录 `/tmp/rcm-performance-implementation-9fMD5c/state`。正式对照版本为 `8c414c8`，旧数据来自上一轮审计。数值是本机样本，不是线上百分位承诺。

### 真实服务读取

| 指标 | 优化前 | 本轮预览 |
| --- | --- | --- |
| 桌面列表出现 | 2846～2920ms | 已连接重复访问 253～268ms；独立预览首次建立连接 619ms |
| 390px 列表出现 | 单样本 4228ms | 单样本 298ms |
| 单次本机侧栏请求 | 约 1.3s，等待桌面活动探测 | 111～127ms，活动另行补齐 |
| 首屏侧栏调用数 | 桌面 2，窄屏 3 | 每次 1 |
| 首屏状态调用数 | 桌面 3 | 已连接时 1，首次连接时 2 |
| JS/CSS 传输响应体 | 440929 字节，42 个资源 | 首次 143889 字节，47 个资源，约减少 67% |
| SSH 空 Python 只读调用 | 上轮单样本 4683ms | 本轮独立连接 4851ms；复用 1032、1254、1267ms |

重复访问可使用 304；浏览器存在不同资源的重新验证行为，不能把一次响应体为零解释为完全没有网络往返。新增共享模块兼容入口使资源数略增，但总传输明显减少。

真实页面样本没有长任务，CLS 为 0.055～0.071，页面均无横向溢出。列表结果出现仍会带来布局变化，本轮没有宣称零布局偏移。

### 模拟长会话流式渲染

使用相同规模的 fixture：每轮用户消息、约 12 段 Markdown、命令及 30 行输出。每组追加 10 次。记录 80ms 合并窗口之后回调本身耗时，不包含等待窗口，也不是完整输入到显示延迟。本轮保持 fixture 的原始快照同步追加，避免定时历史读取回滚模拟数据；每组最终 10 条增量均可见。

| 历史量与视口 | 原回调中位数 | 本轮回调中位数 | 原每次创建元素 | 本轮每次有变化时创建元素 |
| --- | ---: | ---: | ---: | ---: |
| 5 轮，桌面 | 6.6ms | 1.75ms | 688 | 122 |
| 50 轮，桌面 | 34.8ms | 2.30ms | 6628 | 122 |
| 200 轮，桌面 | 127.8ms | 6.10ms | 26428 | 122 |
| 50 轮，390px | 80.0ms | 14.30ms | 6628 | 122 |

200 轮样本中一次合并回调未新建元素：内容已由同周期其他刷新呈现，最终增量完整性检查通过；原始样本保留，不剔除该点。该组其余 9 次均创建 122 个元素。窄屏测试仍记录到一次 65ms 页面长任务，因此不能声称所有帧都低于 16ms。节点创建量已不再随未变历史线性增加，整体签名计算和 DOM 扫描仍随历史增长。

原始证据：[真实加载](performance-implementation-evidence-2026-10-22/real-loading.json)、[渲染](performance-implementation-evidence-2026-10-22/render-benchmark.json)、[SSH 耗时](performance-implementation-evidence-2026-10-22/ssh.json)、[SSH 生命周期](performance-implementation-evidence-2026-10-22/ssh-lifecycle.json)、[本机侧栏独立读取](performance-implementation-evidence-2026-10-22/local-sidebar.json)。

## 功能验证

完整执行 `npm test`：**331 项 Node 测试、59 项 Python 测试全部通过**。测试使用独立临时目录，保留测试数据。

新增或扩展的回归覆盖：

- gzip 解压后内容逐字一致，质量参数拒绝压缩、表示相关 ETag、304、HEAD、文件编辑后失效。
- 在途读取只合并相同上下文；错误后能重新读取；调用方要求显示的失败不被静默调用吞掉；显式刷新排队执行。
- 搜索、连接、账号与侧栏快照变化后，旧响应不能修改新状态。
- Python 内容读取不执行桌面活动探测；独立活动结果保持账号范围与原观察时间。
- 历史节点不重建、分组迁移、变化内容回绑到实际 DOM、缓存移除。回归测试发现并修复了节点移入新分组时游标失效的问题。
- SSH 复用必须显式开启，默认写入独立，保留身份、主机校验和非后台持久连接参数。
- 现有会话创建、发送、补充、停止、接管/交还、原生任务、模型、技能、附件、历史、文件、审批、通知、草稿、配对、Origin/CSRF、备份及部署检查等行为测试继续通过。这里是自动化覆盖，不代表对真实账号逐项执行了写入操作。

浏览器验收（fixture，不向真实引擎发送业务指令）：

| 场景 | 结果 |
| --- | --- |

| 不变用户消息和图片状态 | DOM 节点保持；已有图片失败提示不被反复重建 |
| 过程展开、输入焦点和草稿 | 追加输出后保持 |

证据：[浏览器内容检查](performance-implementation-evidence-2026-10-22/browser-checks.json)、[切换和窄屏检查](performance-implementation-evidence-2026-10-22/browser-more.json)。截图保留在 `/tmp/rcm-performance-implementation-9fMD5c/`。

## 尚未覆盖和后续边界

- 中文输入法只验证了浏览器组合事件，不等于真实系统候选窗验收；390px 为浏览器模拟，未使用实体手机和软键盘。
- 图片保留检查覆盖图片不可用时的节点状态；成功图片加载、文件二进制和代码复制主要由现有行为测试覆盖，本轮未重新完成真实附件下载或剪贴板验收。
- 未向真实会话发送/停止任务，未修改定时任务或配对配置。连接、状态和性能的真实验证为只读。
- 本轮未做跨天稳定性、弱网断线注入或不同远程账号切换的真实压力测试；身份与连接隔离另有自动化及双入口真实验证。
- 全量侧栏 SQL、IndexedDB 恢复、同步状态落盘与更大历史量仍是计划中的采样项。没有依据本轮样本引入虚拟列表、修改原生数据库索引，或合并语义不等价的项目接口。
