# 侧栏默认折叠与全部折叠验收

日期：2026-10-18（Asia/Shanghai）。本次仅修改 `public/sidebar.js`，保留工作区已有的其他改动；未提交或部署。

## 行为

- 置顶、自定义分区、项目、会话和归档分组，以及分组内的项目，默认收起。工作区总入口继续显示。
- 在“侧边栏设置（⋯）”菜单加入“全部折叠”，一次收起所有分组和项目；断开连接时同样可用。执行后焦点回到菜单入口。
- 仅记录用户主动展开的节点，按连接和账号隔离。刷新保留状态，新出现的分区和项目仍默认折叠。旧版折叠列表不再用于推断展开状态，首次使用新规则会全部收起。
- 搜索自动展开匹配结果，可手动折叠或全部折叠；同一搜索的后台刷新保留折叠状态，换搜索词重新展开。普通搜索展开不改变搜索前的状态；“全部折叠”同时保存普通列表的收起状态。
- 新建会话继续展开所属分区和项目。折叠不改变当前会话、草稿或目标机器状态。

沿用仓库现有分组、菜单和键盘交互，参考已有的创建与手机交互验收记录。没有取得 Codex 原生“默认折叠 / 全部折叠”的专项验收证据，不声称与其完全一致。
