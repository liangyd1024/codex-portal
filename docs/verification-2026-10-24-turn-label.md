# 轮次标签对齐

## 原因与改动

原标签宽 40px，字号 12px、行高 18px，并允许任意位置换行。浏览器实测“共 11 轮”产生两行。刻度按钮宽 36px，与标签宽度不同。

桌面标签精简为“11轮”，失败入口精简为“重试”。标签与刻度共用 44px 宽度并居中；字号保持 12px，行高改为 16px，使用系统字体与等宽数字，禁止换行。极长标签使用省略号，悬停说明和无障碍名称保留完整轮数。手机目录保留完整文字。未增加网络请求、轮询或数据计算。

## 验证

- 按实际样式加载顺序使用隔离组件页面复现并验证。改后标签为一行，标签与刻度中心差为 0px。
- 桌面默认、悬停、可见焦点和禁用态通过；禁用透明度实测为 0.55。方向键从第一轮移动到第二轮，无横向溢出。
- iPhone 12 模拟：390×844、DPR 3、mobile=true，触控开启并核对生效。触控打开目录成功，桌面刻度隐藏，完整目录标题保留，无页面横向溢出。
- 轮次相关测试通过；`npm test` 的 672 项 Node 测试和 72 项 Python 测试全部通过。未新增仅检查 CSS 字面值的测试。
- 开发预览端口被另一工作占用，未启动完整应用预览。实体手机未验证；未改输入流程。
