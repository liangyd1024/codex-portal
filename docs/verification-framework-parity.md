## 方法与证据边界

1. 真实服务单独验证 Host、Origin、手机配对、连接及专用测试会话。
2. 双版本静态测试入口分别加载 master 原页面与重构构建产物。使用同一份浏览器模拟数据，方便复现输入、流式消息和异常状态。
3. 静态测试入口不创建 Manager、SSH 或原生引擎连接。未被模拟截获的 API 请求返回失败，不会转发到真实服务。
4. 静态入口使用测试用临时端口及独立浏览器 Origin，避免修改 4317 / 4327 的浏览器存储。它们不替换 4327 / 4338 / 4339 验收服务。
5. 真实数据与截图在仓库外保存。报告只记录虚构样本和汇总结论。
6. 浏览器模拟与实体手机分别记录，不把模拟软键盘高度当作实体软键盘验证。

## 长会话流式样本（性能结论未定）

相同模拟数据新增 200 轮，连同先前已缓存轮次共显示 201 轮、约 26 万字符。交替执行每版 10 次尾部文本更新，旧消息节点全部保留，页面异常为空。随后每版再做 6 次前台采样，分别记录 DOM 更新与两帧完成时间。DOM 更新范围约 11–1414ms，两帧完成约 1056–4965ms；一次采样开始时仍未获得焦点，期间夹杂侧栏活动刷新或详情请求。样本波动明显，未据此判断稳定退化或整体提速，也未将本轮性能验收标为通过。需要进一步控制页面焦点、刷新活动和系统负载后复测；当前原始数据保留在仓库外。

后续重新载入相同 200 轮样本，两版均为 201 个轮次节点、271537 个区域文本字符。关闭自动刷新，逐次置前并确认焦点及可见状态，从动画帧开始计时，以正文变更及其后两帧作为观测点，交替执行各 10 次增量更新。所有样本期间无 API 请求，旧节点保留且页面异常为空。master DOM 更新中位数 164.1ms、范围 111.1–719.2ms；迁移版中位数 197.4ms、范围 96.1–2144.8ms。两帧完成中位数分别为 217.45ms 和 239.25ms。迁移版前两次有约 2 秒尖峰，后续两版仍有尖峰；不能将中位数差异直接判为稳定退化。

## 新建失败场景的行为边界

模拟创建接口返回明确错误响应（HTTP 503）后，两版均允许再次提交，草稿不变。第二次创建请求等待期间连续点击两次，总创建请求仍只有两次（一次失败、一次进行中）。随后创建成功，首条消息接口返回 503，两版均显示“发送结果待确认，请勿重复发送。草稿已保留。”。

进一步实测发现：在该提示下，两版发送按钮仍启用，按 Enter 都会再次发送一次，并在模拟成功后清空草稿。因此这里只确认与 master 行为一致，不能宣称“发送结果未知时阻止再次提交”已通过。该行为在基准中同样存在，本轮未擅自改变交互语义。全部请求发生在静态模拟入口，没有创建真实会话或重复执行真实任务。

## 真实本机接口与页面对照

基准仍为 `65882af`，预览为 `35bf288`。每个入口各创建一个专用测试会话，使用不同的独立临时工作目录，不交叉控制同一会话。模型及思考档位均读取接口默认值。创建返回 HTTP 201，发送返回 HTTP 200；两个原生轮次随后均为 completed，会话为 idle，pendingRequests 为 0。请求仅要求固定文字回执，不执行命令或文件操作。原始记录只含用户消息和助手消息，助手回复均为 `RCM_PARITY_OK`。

## 真实 SSE 与浏览器断网复验

仍使用两个入口各自的专用会话。第二轮要求原样回复包含中文段落、Markdown 表格和代码块的固定样本，不调用工具。两边原生轮次均 completed，事件均包含正文增量及 turn/completed；分别收到 59 个本会话事件，其中正文增量 48 个。增量拼接、最终接口正文和预期字符串逐字一致，工具调用为空。真实网页均显示标题、段落、表格与代码块，输入框为空。只保存测试会话事件，没有将其他会话事件收入样本。

随后在各自浏览器标签用 CDP 模拟断网，未停止服务或原生任务。断网后发送禁用，验收草稿保留。恢复网络后，两版在 20 秒等待期内仍显示实时连接中断；navigator.onLine 为 true，普通版本接口返回 200。分别手动刷新页面后，发送恢复且草稿完整。测试草稿随后清空，未发送。

这项实测与此前模拟 onerror/onopen 通过的范围不同：之前仅证明应用收到恢复事件后的行为，本次自动重连没有通过。当前不能排除浏览器网络模拟方式的影响，也不能把它认定为仅迁移版缺陷。原生服务没有重启；实体手机 Wi-Fi 切换仍待验证。

## 通知状态与导航模拟对照

正式基准复核仍为 `65882af`。在两个静态模拟页面替换通知权限读取及 Service Worker 注册、通知提交接口，没有修改浏览器或系统真实权限，也没有发出真实系统通知。
