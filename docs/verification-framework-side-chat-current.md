所有交互使用虚构会话、测试图片与拦截 API。未向真实会话发送消息。结果证明这些隔离行为与正式版本源码一致，不等于真实 SSH 或实体手机通过。本轮无产品代码修改、构建或服务重启，沿用候选已有完整回归结果。

合计 204 个样本、102 组配对。比较内容包括页面状态、草稿、图片归属、请求正文、按钮状态、错误、横向溢出及实际设备参数；附件专项还比较节点语义、计算样式与几何位置。各组均无页面错误或横向溢出。

创建侧聊的 requestId 每次都是独立 UUID。比较前检查 UUID v4 格式、单流程稳定性与流程间唯一性，仅归一化该字段。原始逐字比较中的 UUID 差异保留，不作为产品差异；其他请求字段没有忽略。发送拒绝与重试两次正文完全相同，消息路径均指向测试侧聊，没有主会话消息写请求。

## 工具失败与复验边界

首轮分开派发的桌面鼠标事件未打开基准版附件预览。检查同一页面后，键盘 Enter 可打开预览，四视口附件主轮因此以桌面键盘和手机触控完成。另补单次浏览器鼠标手势，六组对照一致。保留首轮失败记录，不将其计为通过，也不声称完成物理鼠标验证。

同时带图测试在两次清理步骤报告 focus 找不到主会话附件按钮。检查同一页面时，侧聊已关闭，主会话图片与草稿均为空，没有页面错误。此前成功发送阶段的样本确认主会话图片和文本仍在。保留超时日志，只记录实际清理后状态，不据此推断工具失败原因。后续用例先移除图片，再清空文字，完成剩余横屏与短高度对照。没有重放已完成的发送步骤。

设备模式及合成事件不证明实体软键盘、中文候选窗、系统剪贴板或选区手柄。本轮没有测量性能，不据此宣称提速。原始脚本、结果及失败日志保存在仓库外。

## 仍未关闭的项目

用户要求再次重试后，按 RCM 当前配置执行严格 SSH 只读身份检查，仍约 15 秒连接超时，未进入身份验证。没有放宽主机校验或修改目标配置。

当前专项通过不代表全部功能集成验收完成。迁移结构、整体性能、真实 SSH 和实体输入等剩余项仍见[当前交付审计](framework-delivery-status.md)。正式服务和 master 未修改。
