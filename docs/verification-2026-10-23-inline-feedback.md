# 操作状态与指引就地显示

代码提交：`2800095`。沿用侧栏、反馈、手机界面及字体的已有验收基线；本轮不声称与 Codex 桌面像素一致。

## 范围

- 左侧操作取消处理中浮动提示，保留侧栏进度、忙碌状态及防重复提交。归档撤销入口保留。
- 弹窗操作失败只在弹窗内显示，直接菜单操作失败仍弹提示；操作成功但刷新失败仍区分说明。
- 原生及桌面停止请求在按钮显示等待状态。HTTP 接收不视为任务停止；原生结束状态才清除等待。断线显示“停止状态待确认”。明确拒绝后允许重试，结果未知时避免重复提交。切换会话后旧响应不刷新新会话。
- 停止等待记录仅保存在页面内存，记录本页请求反馈，不修改或替代原生任务状态，不持久化，不增加轮询。
- 重新加载登录、停止专用服务后的下一步说明移到目标连接设置。连接或断开时清除旧说明。维护确认和检查流程保留。
- 代码、手机地址和配对码复制成功局部显示两秒，失败保留文字。不同操作使用独立反馈区域。
- 手机登录撤销结果保留在撤销区域，区域保持展开。重新生成配对码后清除旧撤销结果。
- 备份范围和加密保存说明固定展示；导出成功不再重复显示成功文案，读取失败仍提示。下载文件不等同加密备份。

## 性能

模拟归档等待与成功均观察到零条浮动提示；停止重复点击验证只发出一次停止请求。侧栏每次操作减少一条浮动节点和其三秒移除定时器；保留既有五秒慢响应提示。复制仅为实际操作创建短暂计时器。未新增请求、轮询或依赖，未测量 CPU、内存或端到端时延。
