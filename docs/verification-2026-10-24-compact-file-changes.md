# 文件变更清单紧凑交互

## 范围与依据

根据本次用户截图和空间占用反馈，调整轮次下方的原生文件变更卡片。既有语义依据见 [正文文件变更卡片](verification-2026-10-23-inline-file-changes.md)。此次折叠和限高是 RCM 的体验优化，未声称与桌面端像素一致。

默认仅显示文件数量。点击标题或按 Enter / Space 展开、收起。展开列表最多高 440px，且不超过视口高度的一半，内部滚动。文件行至少高 44px，优先保留文件名，过长目录省略；展开文件后显示可选取的完整路径及原始差异。没有改写原生消息、补丁或执行语义。

数据更新仍替换绑定原始补丁的处理器，同时恢复卡片及对应文件的展开状态。没有新增接口、依赖或轮询。

## 性能及限制

默认卡片高度与文件数量无关，隐藏列表不占会话版面。差异仍按文件首次展开时创建，未额外请求数据。列表行仍在卡片生成时创建；未对超大文件集或端到端性能做基准，不声称性能最优。

此次是组件模拟验证，未运行独立完整工作台预览，也未通过真实文件编辑任务验证原生事件链路。未实测实体手机、软键盘或中文候选窗；输入流程未修改。浏览器中的收起状态沿用当前渲染缓存，不承诺刷新页面后保持。
