# 手机优化发布整合验收（2026-10-18）

基于已部署版本 dbb45bd 及其文档后续提交 5370a8c 整合，保留已上线侧栏分组、排序、账户校验、会话交还和 5 秒引擎释放配置。原开发目录未提交改动保持原样；本发布使用独立工作树。

## 发布范围

- 合入手机 44px 点击目标、48px 主要按钮、顶部更多菜单、底部接管入口、横屏紧凑布局、软键盘可视高度、抽屉焦点隔离和错误恢复。
- 适配正式版直接显示的交还按钮：手机收进更多菜单，桌面仍直接显示；保留引擎释放状态与配置。
- 合入标签页草稿持久保存、手机回车换行、中文输入候选保护、发送快照确认和迟到响应隔离。
- 合入已完成的当前会话只读自动同步修复；不重新接管或自动发送。其他待发布的侧栏默认折叠改动不包含在本版本中。

## 发布前验证

- `npm test`：72 项 Node 测试、23 项 Python 测试全部通过。日志 `/tmp/rcm-mobile-release-tests.log`。
- JS 语法与 `git diff --check` 通过。
- ego-browser 加载发布工作树代码；模拟后端拦截全部 API 和事件流。
- 320、375、390、430px 竖屏和 844×390 横屏无页面横向溢出；可见手机按钮与输入均满足 44px 触控尺寸。1280×900 桌面布局回归通过。
- 手机更多菜单交还与接管、回车换行不误发送、抽屉隔离与 Escape 焦点返回通过。模拟请求仅发生交还和接管，未发消息；页面无异常。
