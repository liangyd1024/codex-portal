## 连续操作

四视口共 88 份样本、44 组配对一致，覆盖连续流程：

1. 在会话 A 输入中文草稿并添加测试图片。
2. 打开新建页，输入独立草稿，再返回 A。
3. 切换 B，输入另一份草稿；打开详情栏、定时任务和任务详情。
4. 关闭任务详情，返回 B，再返回 A。
5. 再次打开新建页核对草稿，依次返回 B、A，最后清空专用草稿及图片。

独立断言确认 A、B、新建页三份草稿分别保留。A 的图片只在 A 出现，没有进入 B 或新建页。进入任务页面和详情期间 B 的草稿保持，返回同一会话正常关闭任务页。页面内移动输入框时 textarea 节点保持同一对象，引用高亮层文字始终等于当前输入原文加结尾换行。

## 刷新恢复

另做四视口共 56 份样本、28 组配对一致。先分别准备 A 的草稿和图片、B 的草稿、新建页草稿，再在新建页刷新浏览器。

两版刷新后均回到会话 B，没有自动打开新建页；重新打开新建页时独立草稿恢复。返回 B 后原草稿仍在，切回 A 后原草稿与图片恢复。每个流程结束时清空专用数据，没有发送消息。

刷新会创建新的文档和 textarea，本轮不声称节点跨刷新保持。节点身份断言只比较同一文档内的移动与切换。刷新后夹具重新声明虚构 B 的可操作状态，只用于恢复相同模拟条件，不代表从浏览器缓存恢复真实会话权限。
