# 当前候选媒体播放操作复核

## 版本与方法

正式基准 `227dbfe93ee88718c2437f7b7c7b119570a720a6`，候选 `41605a7075e216ec7a743ab6605cb10a138d34ff`，资源 `ec11c5735025907428ff45249d6f1eea683c5fc5ae740c174e3787bd02bae65b`。开始核对 4317、4327 版本接口，隔离静态入口使用相同版本的源码和构建产物。

生成十秒蓝色视频及十秒静音音频。元信息仍由夹具模拟，实际媒体内容经隔离 HTTP 服务传输，响应头沿用文件预览所需的 sandbox 和同源 frame-ancestors 策略。该服务没有 Manager 或原生引擎连接，不操作真实文件或会话。

使用 Ego Lite，同一验收空间、正常扩展及 React 调试回调。桌面为 1480×747、DPR 2、触控关闭；iPhone 12 模式为 390×844、844×390、390×480，DPR 3、触控开启。导航后重设参数，逐样本检查实际值。

先从实际快照识别浏览器原生“播放”“暂停”和时间进度条。操作时通过可访问树取得对应控件及边界，桌面发送鼠标点击，手机发送 touchStart／touchEnd。没有直接调用媒体 play／pause，也没有设置 currentTime 或合成播放事件。

## 结果

两类媒体、四视口、两入口，共 96 个状态样本、48 组配对一致。每次流程覆盖：

1. 读取元数据，确认十秒时长和无媒体错误。
2. 点击播放，确认 paused=false 且实际进度超过 0.2 秒。
3. 点击暂停，连续八帧内 currentTime 保持相同。
4. 点击时间进度条中点，完成定位且 currentTime=5、seeking=false。
5. 再次点击播放，确认进度比定位点继续增加超过 0.2 秒。
6. 播放中关闭，确认媒体暂停、节点不再连接到文档、src 被清除，焦点回到文件链接。

比较媒体标签、控件属性、资源参数、时长、暂停／结束／定位状态、错误、提示文案、焦点和实际视口。全部无页面错误或横向溢出。运行中的 currentTime 受采样时机影响，原始值保留，逐样本按上述进度条件验证，不要求两个浏览器样本的运行时间逐位相等；其余记录字段配对一致。

## 范围与交付

本轮补齐实际开始播放、暂停、点击定位、恢复播放及关闭清理。没有验证完整播放到自然结束、连续拖动进度手柄、全屏、音量、播放中断网或系统音频输出。静音夹具也不能证明扬声器输出。手机仍为 Chromium 设备模式，不等同于实体 Safari。

本轮没有产品代码修改、构建或服务重启，不重复运行应用测试。当前候选既有 884 项 Node、74 项 Python、类型检查和构建通过。脚本、媒体和结果保存在仓库外。正式服务与 master 保持不变，整体缺口见[交付审计](framework-delivery-status.md)。

## 当前实际候选复验与自然结束

本次重新核对正式 4317 仍为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`，真实预览 4327 为 `accb11f2cfe0e6c1e6563de1560c86540978c4ba`。重新 fetch 的 origin/master 为 `0a3ee2a`，相对正式版本仅有四行部署文档差异。没有混用旧候选证据。

隔离静态服务直接读取 preview.json 指定的实际运行构建及其 manifest，资源哈希为 `0e4887c7d29f468a80e30e3f66cadc134469600cdab6c2ee7e1f476f801c1ec7`。首次准备脚本错误地将 preview.json 当成构建 manifest，因缺少 output 字段退出；没有启动候选入口或执行浏览器操作。修正读取实际构建 manifest 后重新启动新夹具，原失败记录保留。服务不创建 Manager，不接入原生引擎。

沿用上文四种视口和十秒音视频，保留正常浏览器扩展。每次媒体流程增加自然结束与从头再次播放，仍通过浏览器原生控件的鼠标或触控输入操作，不直接设置播放状态或 currentTime。各状态比较实际媒体属性、提示、焦点、资源 URL、视口及错误；运行进度保留原值并按状态条件验证，不要求不同采样时刻的进度逐位一致。

结果为 128 个状态样本、64 组配对一致，无页面异常或横向溢出。两种媒体在四视口、两入口均自然结束：ended=true、paused=true、currentTime=duration=10；再次点击播放后从头推进，随后关闭时暂停、脱离文档并清除 src，焦点返回文件链接。各次暂停后八帧进度不变，进度条点击定位均为 5 秒。

本轮没有发现需要修改的候选差异。未检查扬声器输出、全屏、连续拖动、播放中断网或实体 Safari。纯验收文档变更未重复运行应用测试或重启服务；最近完整应用回归仍为 891 项 Node、74 项 Python。
