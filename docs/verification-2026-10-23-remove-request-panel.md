# 移除右侧待处理请求区块

## 改动

代码提交 `f31ed64`。根据用户截图和明确要求，移除“工作区详情 → 会话 → 待处理请求”，包括数量、跨会话卡片和自动展开逻辑。参考已有问题卡片验收记录，继续在所属会话或侧边聊天的输入框上方处理问答及审批。其他会话的问号与通知继续使用原有请求数据；不修改原生请求、回答协议或正文。

README 已同步。其他会话的请求在创建 DOM 前跳过，减少不必要的卡片渲染；不增加请求、轮询或缓存。
