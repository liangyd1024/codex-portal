启动提交诊断保留并调用原 React 回调，桌面和 iPhone 竖屏各旧／新／新／旧。上一候选四次均 76 次；新候选为桌面 78／73、手机 73／73。首次新候选的多余五次来自另外的状态发布调用位置，包括计划、附件、诊断与请求卡片，原始调用栈保留；没有删掉该样本，也没有将 78 次强行归一为 73 次。移除的三个空浮层注册在源码中明确可见，但总提交数仍受其他启动状态影响。
