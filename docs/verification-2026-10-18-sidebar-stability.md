# 侧边栏分区刷新稳定性修复

## 原因与修改

`readSidebar` 将 `account/read` 的超时或断线吞掉并当作空账号，从而返回成功但不含自定义分区的普通项目布局。前端会覆盖原有分区。修复后传播读取错误，由现有刷新错误处理保留最后成功布局并在后续刷新恢复；不猜测或复用旧账号身份。明确成功的退出登录或账号切换继续按实际身份读取。

只修改 `lib/sidebar.mjs` 的异常处理；其余代码改动为回归测试。前端、输入框、技能引用、手机连接和权限策略不变。发布前保留正式版新增的 `d871d54` 输入框按钮对齐修复。

- HTTP 验证身份查询失败返回 502/RPC_TIMEOUT，不读取无账号布局，恢复后正常返回。

- 4327 被另一工作树的预览占用，未停止该服务，未将其当成本次修复预览。后端错误路径由自动化测试验证，未故意中断真实目标引擎。
