## 导出、拒绝、取消与回滚

四视口共 8 个流程，初态、导出记录、目标拒绝、取消、缓存失败回滚共 40 份记录、20 组配对一致。

- 导出文件实际下载成功，格式版本、虚构机器与连接映射、缓存声明及覆盖范围一致。应用前缀内的指定设置和标签页值被导出，范围外的测试键未导出。
- 目标不匹配的文件被拒绝，原存储保持。取消合法导入也不改变存储。
- 仅针对指定虚构缓存行注入事务失败。失败后原设置和标签页值恢复，新增加的应用设置键不存在，范围外设置保留；错误提示一致，按钮恢复可用，文件输入清空。
