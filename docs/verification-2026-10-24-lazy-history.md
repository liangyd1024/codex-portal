# 轮次目录与历史按需读取

## 改动范围

- 轮次导航独立读取原生记录的轻量目录。目录保留原生执行 ID 和顺序，以显式用户消息、目标输入计数。自动继续执行归属到前一个输入。
- 首次打开不再为轮次导航逐页读取全部正文。目录未就绪时隐藏导航，不显示加载提示。失败提供重试入口。
- 向上滚动或点击旧轮次时读取历史正文。点击远端轮次仍逐页补齐连续正文，尚未实现直接随机定位。
- 普通会话历史接口可选择延迟返回已完成 MCP 调用的参数和结果。展开时按目标、会话、工具 ID 读取完整原文。默认历史接口仍返回完整数据。
- 工具关闭时不格式化结果、不构造结果 DOM。展开请求合并，失败可重试。切换上下文或移除节点后忽略迟到结果。
- 目录投影只用于导航预览，不写入正文和原生数据库。正文和工具完整内容不删改。

## 性能证据

优化前，同一长会话的采样包含 127 个原生执行轮次和 20 个显式输入。完整历史需 26 个串行分页请求，共约 8.92 秒；gzip 传输 35.91 MB，解码 JSON 67.97 MB。主要耗时在服务端等待及大工具结果处理，导航计算本身约 0.5 毫秒。

当前实现对真实原生数据进行只读函数采样：目录读取 275.7 毫秒，JSON 84,973 字节，gzip 29,280 字节。最新五轮延迟工具结果后 JSON 为 160,383 字节，对照完整返回为 1,769,244 字节，减少约 90.9%。读取分别为 32.7 和 34.9 毫秒。

会话持续增长，两次采样不是固定数据集的端到端对照。函数耗时不包含 HTTP、远程连接和浏览器渲染，不能据此承诺固定加载时间。桌面 IPC 专用正文读取与实时事件大结果未纳入此次传输优化。

- `npm test`：672 项 Node 测试、72 项 Python 测试通过。
- 覆盖目录投影、原生继续执行、最终回复优先、延迟结果完整还原、会话隔离、路由参数、静态模块加载、失败重试和上下文切换。
- 回归验证工具节点数据更新后替换其回调并保留展开状态；相同缓存节点保持不变。
- ego-browser 隔离组件页面：首次目录请求时导航隐藏，正文分页请求为 0，工具请求为 0。目录完成后显示完整轮次数；键盘方向键及 Enter 跳转正常；点击旧轮次才读取正文；展开工具才读取一次详情。
- 桌面悬停预览、键盘焦点、原文显示和无横向溢出通过。
- iPhone 12 模拟参数：390×844、DPR 3、mobile=true、触控开启。验证参数生效，使用触控事件打开目录与点击条目，弹窗关闭和定位正常，无横向溢出。补充 844×390 横屏无溢出检查。

## 发布

代码版本 `7d10af5822ee0dab80594fda790b47a8f1a89a83` 已推送并按指定版本安装。版本接口和禁用资源缓存的正式工作台浏览器加载检查通过。仅更新 RCM 网页，未重启原生引擎或会话。

重启后首次接口采样遇到连接恢复中的 HTTP 503；原生连接自动恢复后复测成功，无人工重启引擎。正式目录接口 180 毫秒，JSON 86,045 字节。最新五轮延迟结果接口 111 毫秒、204,202 字节；默认完整接口 157 毫秒、1,006,893 字节，此次样本 JSON 减少约 79.7%。其中 20 个工具结果标记为按需读取；抽查一个详情，与完整历史对应工具对象序列化后完全一致。会话在持续增长，此处为单次真实 HTTP 采样，非长期基准或浏览器端到端耗时。
