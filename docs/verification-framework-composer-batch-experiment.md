## 版本与范围

2026-10-25 重新读取版本接口：正式 4317 为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`，独立预览为 `accb11f2cfe0e6c1e6563de1560c86540978c4ba`。试验基于分支 `a0dc0b7`，资源哈希为 `890bf678fb69a33591f4c1f7f4bff74cc510280aaf8e5768ddb2a7aac5bcaea5`。

输入控制器先发布工具状态，紧接着设置附件按钮禁用状态，中间没有 DOM 读取。试验将两个 store 的发布放入同一个同步提交，保留附件控制器的独立发布路径。试验没有修改 CSS、公开接口或原生数据。

行为测试使用正式提交导出的静态源码与试验构建，业务接口及事件来自隔离夹具。使用同一 Ego Lite 空间，保留正常 React 调试回调。桌面为 1480×747、DPR 2、无触控；iPhone 12 模式为 390×844、844×390、390×480，DPR 3、触控开启。设备模式不代表真机软键盘验收。

## 行为结果

- 输入 54 个样本、27 组对照一致。覆盖组合输入保护、多行高度、全选、粘贴、撤销、手机回车换行和触控发送。输入节点身份、选区、焦点与发送次数一致。初次比较器误用被输入高度覆盖的 height 字段匹配视口；改用已记录的完整 viewport 后比较，未重跑或修改原始样本。
- 主输入附件 64 个样本、32 组对照一致。覆盖延迟解码、切换会话、迟到完成、返回原会话、预览、移除，以及处理中移除后的防复活。
- 主／侧聊附件 48 个样本、24 组对照一致。比较时仅将创建侧聊请求的随机 requestId 标记为动态 UUID；其他字段保持原样。覆盖聚焦与选区后的渲染、主侧附件隔离、预览及移除。
- 工具菜单 120 个样本、60 组对照中，40 组完全一致；20 组仅按钮计算背景色不同。差异集中在计划／目标操作后关闭的菜单，原始值包含过渡中的透明度。焦点、禁用、文案、布局、草稿、请求一致。本轮未采集这些节点的可见性证据，也未执行重新打开菜单的补验，因此不能直接判定为无影响或视觉通过。
- 上述样本未记录页面异常或横向溢出。真实 SSH 另做只读复核：严格身份检查通过，预览显示 connected，状态、模型与项目接口均为 200；未控制会话。

## 性能与撤回依据

提交计数对比实际候选资源与试验资源，不以旧候选代替正式行为基准。桌面与 iPhone 竖屏各按前／后／后／前执行，八次启动均从 72 次提交降为 70 次。计数包装继续调用原调试回调并在结束后恢复。

另做不包装回调的 16 次首屏测量，每种设备、每个版本各四次。所有样本均为 20 次夹具 API 调用。下表为 CDP 累计 CPU 计数中位数，不是用户感知首屏时间。

减少提交未带来可确认的耗时收益。桌面首个改动前脚本样本为 53.543 ms，其余三个为 79.212–80.668 ms；原始异常低值保留。共享浏览器上下文中的保留 Document 数不能用作单应用内存结论。此轮不能证明整体性能通过。

因此撤回试验，不增加一次候选更新。补丁与原始样本保存在仓库外。恢复后应用文件与分支 HEAD 无差异；重新构建为 dirty=false，资源回到 `0e4887c7d29f468a80e30e3f66cadc134469600cdab6c2ee7e1f476f801c1ec7`，与实际预览一致。

试验构建的完整回归为 891 项 Node、74 项 Python 通过，类型检查和构建通过。恢复后的构建及类型检查亦通过。整体验收、剩余类型迁移与性能门槛仍未完成，见[交付审计](framework-delivery-status.md)。
