# 排队消息栏与目标栏对齐

按用户提供的两张截图，将排队栏单行高度由 54px 收紧到 46px。左右内边距与目标栏一致，为 14px / 8px；底部间距统一为 6px。复用黑色前景、白底、18px 卡片圆角和 8px 按钮圆角。按钮保留 44×44px 触控区域。长消息继续换行并在原有上限内滚动。

## 验证

- ego-browser 独立 DOM 样例使用实际页面样式及本次修改后的 CSS，通过浏览器调试样式表加载。未发送真实排队、引导或删除请求。
- 桌面 1440×1000：相邻排队栏和目标栏均为 46px 高、880px 宽、18px 圆角；检查截图、键盘 Tab 焦点、悬停反馈。
- iPhone 12 模拟：390×844、DPR 3、mobile=true、5 点触控、粗指针。核对设备模式生效；两栏均 46px 高；触控引导样例触发一次；无横向溢出。长文本区域上限 100px；禁用按钮透明度 0.4。截图已检查。
- npm test：672 项 Node 测试与 72 项 Python 测试通过。
- 本次仅修改 CSS，无新增请求、轮询、DOM 节点或 JavaScript 计算。单行垂直占用减少 8px，底部间距减少 2px；未进行 CPU 或内存基准测试。
- 预览端口被其他项目占用，未启动独立预览服务。真实排队接口及实体手机未复测；本次没有修改输入、快捷键或原生执行逻辑。
