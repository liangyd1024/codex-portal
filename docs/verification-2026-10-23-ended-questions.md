# 原生轮次结束后移除问答提醒

## 行为与依据

用户明确要求：Codex 引擎执行结束后，会话不再提示回答。以原生轮次状态为准，不识别“结束”等自然语言，不修改原始消息。此规则替代 2026-10-22 验收记录中的已完成轮次保留策略，并与 README 的运行中问答规则一致。

- 正常完成、失败或中断均清除对应轮次的异步问题。卡片、顶部提醒及侧栏问号使用相同的数据来源。
- 已跳过问题同样清除。刷新、重连和迟到的条目完成事件不会恢复已结束问题。
- 回答提交复核原生历史或临时会话实时状态，拒绝过期问题，不因旧问题创建新轮次。
- 其他会话及仍在运行的轮次保留自己的问题。草稿和原始正文不删除。
