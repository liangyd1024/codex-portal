# 已有目标内容编辑

## 改动

已有原生目标时，点击输入区“目标”或“＋ → 编辑目标”打开编辑框。预填原生目标，支持保存和取消。运行中允许编辑，提交只包含 objective，不更改状态或预算，不额外启动普通消息轮次。原始历史消息保持不变。

编辑草稿按连接和会话保存。保存前读取原生目标，内容已变化则拒绝覆盖。请求结果不明时先读回核对，不自动重放。失败保留草稿，可重新读取当前目标。切换会话后迟到结果不关闭新弹框、不修改另一会话草稿。

## 验证范围

- 原生服务：只创建并操作专用验收会话。确认 thread/read 为 active 后调用 thread/goal/set，仅传 objective 与 origin=user，返回更新内容且状态仍为 active。随后暂停该测试目标，并中断该测试轮次；读回 paused。没有停止目标引擎或操作既有任务。
- 单元回归：运行中编辑仅传目标内容；拒绝目标变化、目标消失、原生读取失败和混入状态／预算参数。
