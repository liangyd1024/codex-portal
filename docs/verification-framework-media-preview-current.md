## 验证结果

图片、音频、视频及损坏视频共 72 个状态样本、36 组配对一致：

- 图片实际解码，尺寸为 `160×90`。
- 音视频实际读取元数据；视频尺寸、两秒时长、controls、preload 和 playsinline 属性一致。
- 损坏视频呈现相同错误、重试入口；重试仍失败，未伪造成功。
- 关闭后弹窗及媒体节点移除，焦点回到文件链接。音视频暂停并清除 src。

比较节点文本、可访问名称、隐藏状态、链接与资源参数、几何、计算样式、媒体属性、焦点和元信息请求顺序。所有样本无页面异常或横向溢出，设备参数正确。

PDF 补验 16 个状态样本、8 组配对一致。初次静态夹具给 PDF 沿用了静态页面的 frame-ancestors 限制，因此初轮 PDF 不作为显示通过证据。修正夹具，使内容响应采用产品文件接口的 `default-src 'none'; sandbox; frame-ancestors 'self'`、inline Content-Disposition，下载采用 application/octet-stream 与 attachment 后，重新完成四视口对照。查看两版共八张截图，均实际呈现蓝色页面和浏览器 PDF 工具栏。短高度和横屏沿用弹窗内部滚动；不把截图检查写成完整像素差分。

以补验替代初轮 PDF 后，合计 88 个状态样本、44 组配对一致。另对图片、音频、视频和 PDF 完成 32 次浏览器下载、16 组配对；建议文件名、字节数及 SHA-256 一致。每个下载文件均逐字节匹配其生成源文件。初轮 PDF 的重复下载不计入该汇总。

## 限制与交付

真实解码、元数据读取和下载已验证，但未测试连续播放、声音输出、播放期间断网、拖动进度条或媒体原生控件的全部交互。PDF 截图确认当前浏览器中的显示，未验证其全部内置工具。iPhone 模式仍是 Chromium 设备模拟，不代表实体 Safari。
