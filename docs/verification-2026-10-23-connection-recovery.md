# 连接恢复与运行状态同步

## 改动与范围

连接状态、网页实例或连接时间变化时，作废旧详情及侧栏请求，撤去缓存的桌面活动和后台命令确认状态。恢复时优先读取当前会话，再同步侧栏，不等待模型和项目目录读取。保留原始正文和草稿，不重发消息，不启动新轮次。

后台命令状态参与正文渲染缓存判断。仅后台命令结束、正文没有变化时，过程提示也会更新。已接管会话的成功原生 metadata 读取可校正漏收通知造成的运行状态，更新会话及项目汇总图标；读取期间收到的新通知优先，历史快照不能作为运行状态依据。此校正随当前会话详情读取进行，不扫描其他会话，不新增原生 RPC 或定时器。

## 验证

- 相关回归 25 项通过。覆盖连接时间换代、旧响应丢弃、后台命令状态失效、漏收通知校正、读取中收到新通知、快照及连接变化保护。
- 全量 `npm test`：455 项 Node、69 项 Python 通过。
- 独立 4327 预览，ego-browser 模拟 API。桌面 1480×747：运行图标包含会话及项目汇总共 3 处，断线后为 0；恢复 idle 后保持 0。后台命令从有到无，正文过程提示及停止入口更新。原始消息和草稿保留，无页面脚本错误。Tab 焦点可见。
- iPhone 12 参数：390×844、DPR 3、移动视口、5 点触控、coarse pointer。已核对设备模式；通过触控事件打开侧栏，验证断线后运行标记撤下、草稿保留。无横向溢出。
- 性能：沿用原有详情与侧栏读取，无新增轮询。相同详情请求合并、旧响应保护的回归通过。未进行真实网络耗时或 CPU 基准测量，不声称性能最优。
- 真实服务只读检查显示专用引擎仍为此前启动的进程，不能把桌面退出等同于专用引擎退出。未中断实际引擎或用户任务；真实引擎退出再启动、实体手机软键盘和中文候选窗未实测。本次未修改输入逻辑。
