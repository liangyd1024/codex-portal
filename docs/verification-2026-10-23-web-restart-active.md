# 运行中会话不阻止网页部署

## 变更

按用户要求，RCM 网页安装及页面“更新并重新部署”不再要求原生会话空闲。本机与 SSH 目标上的 active 会话均可继续运行。不依赖 Codex 当前部署会话 ID，不调用停止轮次、引擎维护或任务取消接口。

待处理请求及连接恢复仍独立检查。安装命令新增 `--allow-pending-request <request-key>`，用于用户明确授权的单次请求例外。仅匹配本机连接和指定 key；未知计数、新请求、远端同 key 和重连仍会阻止安装。参数不保存，不通过网页更新接口开放。

README 与 AGENTS.md 已同步长期规则。原有目标引擎维护和数据恢复限制不变。此次同时部署之前已提交的侧边聊天消息保留修复。

## 验证

- 完整 `npm test`：469 项 Node.js、69 项 Python 测试通过；`git diff --check` 通过。
- 部署检查测试覆盖本机和远端运行会话、失败及未知会话状态放行、连接恢复、请求精确例外及例外向预检的传递。
- 检查函数只读状态，不改写会话或请求。网页更新与命令行安装复用同一检查函数；本轮无 UI 样式或输入流程修改，未另做浏览器布局测试。
- 没有新增网络请求或轮询。移除按会话读取原生状态及失败历史的调用，仅读取网页连接状态并有界复核；实测两个连接的预检共 3 个 HTTP 读取，约 22 ms，原生接口调用为 0；没有测量长会话性能，不声称性能最优。
