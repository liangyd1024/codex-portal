# 项目行直接新建会话

按用户截图及一键进入项目新会话的要求，结合既有侧边栏一致性和新会话验证记录，移除项目行仅含“在项目中新建会话”的单项省略号菜单。行尾改为复用 plus SVG 的直接按钮；点击一次调用原有项目新会话入口，预选该项目根目录并聚焦输入框。项目展开折叠、会话行菜单、稳定 ID、草稿与原生创建流程保持不变；发送首条消息才创建原生会话。

桌面沿用悬停/键盘焦点显示行操作，窄屏常显 44×44px。断线或缺少项目根目录禁用；点击时再次核对连接。未声称原生图标和间距像素级一致。

验证：npm test 301 项 Node、55 项 Python 通过，日志 `/tmp/rcm-project-create-tests.log`。ego-browser space 57 使用 4327 独立临时状态及隔离模拟 API。桌面一次点击直接显示新会话页，cwd 为所选项目，焦点为 message-input，没有菜单，没有提前创建请求；390×844 Tab 到按钮有 solid 焦点、44px 高度，无横向溢出，Enter 直接进入，自动收起侧栏并聚焦输入框，无 JS 错误。浏览器此前持续最小化，未重复尝试截图；未验证实体手机和真实引擎创建，本次未修改输入提交/IME 逻辑。验收空间已关闭。
