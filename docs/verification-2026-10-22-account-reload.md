# 登录切换与右侧面板精简

## 问题与边界

- 用户确认桌面已更换账号。真实专用引擎仍返回旧账号；`account/read` 分别使用 `refreshToken:false/true` 后身份没有变化。用量读取返回 HTTP 401 / `token_revoked`。没有读取或复制认证文件。
- 本机配置的原生二进制导出协议说明：`refreshToken` 请求刷新令牌，不提供切换到桌面账号的保证。当前可用协议没有已验证的独立热加载登录接口。
- 失败会话处于 `systemError`；原生轮次记录为 failed，目标为空，后台命令和队列为空。仅此记录不能替代整个引擎的维护检查。
- 普通刷新只读最新引擎状态；“重新加载登录”明确确认后检查并重启专用原生引擎，保留任务语义、草稿和原始错误，不自动重发消息。已有维护标记不会被覆盖；本次成功停止后的维护记录通过改名保留。
- ChatGPT 账号切换、ChatGPT/API Key 切换和退出登录纳入刷新路径。API Key 只显示类型，不暴露 Key 或假造用量；不能据此区分两把 Key。
- 项目来自目标机器原生存储，分区按已核实的 ChatGPT 工作区身份读取。没有新增分区管理或桌面项目缓存写入，不宣称突破原有桌面同步限制。

## 修改

- 原生 account/updated 使账号、用量、模型、项目和分区读取失效；账号版本与连接版本阻止旧结果覆盖新状态。用量读完再次核对身份，避免拼接跨账号数据。
- 普通工作区刷新同时刷新账号与用量。已识别的失效登录隐藏旧身份及额度，阻止新消息提交。原生登录更新、专用引擎更换或显式重新加载后恢复。
- 新增设置内“重新加载登录”，复用原维护流程并增加分页、状态不明、待回答问题、提交中请求及连接变化检查。systemError 仅在轮次已结束且其他检查通过时可恢复。
- 移除重复的会话状态面板。空请求和空队列隐藏；有内容或队列读取异常时显示。切换右侧标签不会重新显示空面板。保留文件变化及诊断中的会话 ID。
