# 原生定时任务实施验收（2026-10-19）

## 实现边界

RCM 提供列表及会话入口，原生桌面负责工具调用、任务持久化和调度。没有修改 Codex 安装包、二进制、内置脚本、数据库或任务配置。长期边界已写入 AGENTS.md；本次业务任务变化均经原生 automation_update。

- `scripts/desktop-session.py` 连接目标用户现有 Unix IPC，核对 socket/目录身份和权限。使用版本化 owner discovery、模型设置读取、start-turn、带 expectedTurnId 的 interrupt-turn。没有启动协调服务、认领会话、伪装签名或调用受保护的 app-tools 通道；不支持时拒绝执行。
- `scripts/automation-store.py` 使用 SQLite `mode=ro` 和 `query_only` 读取原生快照，校验传统任务文件存在及更新时间。多库、账户迁移、未知结构拒绝推测。任务内容不复制到 RCM 状态文件。
- `lib/native-automations.mjs` 保存管理会话绑定、发送标识/摘要/回执，使用同一连接的现有身份验证传输。固定消息 ID 防重复，重启时将未完成回执改为待核对，原生 userMessage.clientId 用于确认。网页丢失回执时保留草稿及发送标识，不自动重发。
- 管理会话的普通接管及发送路由被拒绝；管理消息只经原生桌面通道。原始会话正文沿用既有 renderer，不添加合成的任务成功消息。
- 左侧任务列表打开时每 15 秒只读刷新；搜索、筛选和任务详情；修改/删除仅准备会话草稿。管理会话沿用输入法保护、草稿、原始历史和停止控件。普通会话、新建会话保持原流程。
- RCM 自身的绑定和回执纳入已有加密备份范围，不扩展到 Codex 原生任务或凭据。
