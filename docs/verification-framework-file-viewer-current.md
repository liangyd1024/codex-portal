## 文件预览

64 个状态样本、32 组配对全部一致。通过正文中的文件链接进入预览，覆盖：

- 元信息读取等待，完成后呈现完整文本。
- 关闭弹窗，焦点回到原文件链接。
- 读取失败提示，重试后显示文本及截断说明。
- 不支持预览的格式，保留下载入口和对应提示。
- 读取等待期间关闭，取消请求且不重新出现弹窗。
