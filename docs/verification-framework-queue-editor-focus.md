# 排队编辑焦点差异与修复

## 基准及发现

本轮对照正式 `227dbfe93ee88718c2437f7b7c7b119570a720a6` 的排队编辑功能。原候选为 `7eb6eb3`，资源 `44ed4d81fdeecb3addb105017d0a55c3a3e94e45607ff420a6e8a84f8cde203b`。桌面 `1480×747`／DPR 2／触控关闭；iPhone 12 模式 `390×844`、`844×390`、`390×480`／DPR 3／触控开启。

旧排队专项脚本曾关闭 React 调试回调，不能作为本轮正常环境的通过依据。本轮保留正常回调与扩展。四视口 96 个样本中，内容冲突和重新读取后的八组状态均有焦点差异：基准保持按钮焦点，候选焦点落到 body。短高度无变化关闭另出现一组焦点差异。其余内容、计算样式、几何、草稿、队列及请求对照一致，无页面错误或横向溢出。原始失败记录保留，不计为通过。

## 修复方式

React 继续创建编辑框节点。组件通过自身 Zustand 订阅统一更新 textarea 的值与只读属性、按钮禁用、反馈文本及 aria-busy；这些属性不再同时由 JSX 管理。只有 revision 变化才写入 textarea 值，避免状态变化覆盖输入或选区。

第一次修复取消编辑状态的 React 提交后，四视口重新读取的焦点恢复一致，但内容冲突仍有四组焦点差异。第二次调整同一同步操作的顺序：先标记忙状态并提交队列行，再更新编辑框禁用及反馈，最后发出请求。禁用与防重复保护仍在请求前完成。没有新增 focus()，没有强制抢回用户焦点，没有修改接口、草稿键或 CSS。

本轮只操作隔离夹具的虚构队列与模拟响应，未更改真实队列或执行原生任务。组合输入使用合成事件，不代表实体中文候选窗。

## 完整编辑复验

最终受测资源为 `f540c33b2c08c898410c24cddcc9de61467eede255ccd966055861c5ba12b2d7`。四视口 96 个样本、48 组配对全部一致，包括焦点、文案、计算样式、几何、草稿、完整请求和队列内容。覆盖打开、取消、草稿恢复、内容冲突、重新读取、组合输入阻止提交、保存等待、失败保留、重试成功、刷新等待及无变化关闭。

组合输入和无变化保存不产生额外写请求。失败与重试的完整请求相同。主输入草稿始终保持；保存后的队列 ID、位置、图片及未知输入字段保持，只有指定文字更新。无页面错误或横向溢出。正常调试环境下不再出现初轮焦点差异。

完整 npm test 通过 884 项 Node 和 74 项 Python 测试，类型检查与构建通过。未新增轮询或请求，当前场景的请求数与基准一致；没有用这些结果宣称整体提速，整体性能门槛仍需继续处理。

## 边界检查与取消焦点

四视口边界轮次共 84 个样本、42 组配对。40 组完整一致，包括断线后的保存提示、恢复、草稿重新打开、保存等待、切换会话和迟到失败；另有桌面默认与悬停状态。确认旧失败响应的正文已被页面读取后，新会话编辑框保持打开，新草稿保留且没有显示旧会话错误。

两组“第二次取消”仅焦点不同，且方向相反：一次基准落到 body、候选保持按钮，另一次反之。未将这两组改写为通过，也未为追求样本一致而取消刷新或强制设置焦点。随后增加只读 fetch、focusin／focusout 和队列节点替换记录，并单独触发刷新，核对原按钮断开后的行为。

补充轮次 48 个样本中，23 组完整一致，桌面第二次取消仍有一组自然刷新时序下的焦点差异。四视口两版共八个流程均记录到详情读取后队列行替换、原聚焦按钮断开、焦点变为 body；下一次重新打开并取消后均回到对应编辑按钮。受控刷新及刷新后取消结果一致，证明该焦点丢失行为基准也存在。保留自然时序差异，不把它扩大为任意刷新时刻焦点完全一致，也不在本次迁移中改写基准刷新策略。

## 发送补验的方法修正

初轮脚本将桌面的 queue-add 预期套用到触控模式，在基准手机页等待超时。检查同一页面的实际请求，触控模式发送的是 steer；发送前按钮也明确标为“引导当前任务”。源码 followUpAction 保留该区别。该轮不能计为手机排队新增通过。后续分别按桌面 queue-add、触控 steer 设置模拟失败和延迟，未为满足脚本改变产品行为。

修正后的四视口流程共 80 个样本、40 组配对全部一致。覆盖发送等待、拒绝与重试，已有队列项引导的等待、拒绝与重试，以及删除结果未知后由刷新确认移除。等待期间重复触发没有新增请求；每个流程最终五条写请求，失败与重试正文相同。手机首个请求为 steer，桌面为 queue-add；已有队列项均使用 queue-steer／queue-delete。主草稿和按钮状态一致，无页面错误或横向溢出。
