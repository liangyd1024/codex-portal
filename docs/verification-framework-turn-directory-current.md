## 目录失败与重试

Ego Lite 同一空间依次对照正式原始页面与当前构建，正常启用 React 开发工具。桌面 1480×747、DPR 2、触控关闭；iPhone 模式 390×844、844×390、390×480，DPR 3、触控开启。手机按钮通过命中检查后的触控事件操作。

目录 503 与 data 为 null 两类场景共 76 个样本、38 组配对。覆盖首次失败、显式重试、跳到最早轮次、桌面跳回最新轮次、手机重新打开目录和关闭。

比较目录与轮次文字、完整渲染正文、草稿、加载状态、目录行与高亮、控件位置及字体／颜色／边框、目录和历史读取参数、展示登记写入。仅对每个页面随机生成的 `/api/thread-view` 请求 body.viewId 做一一映射；同页 ID 稳定性、请求次数、revision 与其他正文原样比较。38 组全部一致，原始请求正文保留。

独立断言确认：首次失败只请求目录一次；重试后累计两次目录读取，尚未下载历史；选择最早轮次后读取三页历史，正文按 1、2、3、4 顺序完整显示。没有额外业务写入，草稿保留。所有样本设备参数正确、无页面横向溢出或捕获的应用错误。

## 历史失败与迟到响应

首轮历史失败脚本错误地等待目录提示持续保留，因超时停止。随后观察发现 master 已消费 503，正文保持原轮次，目录反馈被后续同步清除。原记录保留。修正等待条件为失败正文已消费且加载状态结束，不修改产品来适配测试。

横屏首轮在切换目标时停止：样本按钮下沿略超出视口，原脚本要求整个矩形都在屏内。观察后改为校验中心触点在屏内且 elementFromPoint 命中目标，继续使用真实触控事件；没有移动应用节点或改写产品布局。首轮部分记录保留，不重复计入最终对照。

完成桌面与竖屏首轮、横屏与短高度补轮后，取每个流程的完整记录，共 56 个样本、28 组配对。沿用上述页面 ID 一一映射，所有比较字段一致；设备参数、无横向溢出及应用错误为空均有独立断言。

历史失败流程确认首个响应为 503，重新选择目标后恰好读取三页成功历史，正文 1—4 完整且草稿保留。迟到流程确认：第一条历史请求等待期间切换到另一会话并输入新草稿；释放旧响应且确认其正文已消费后，仍显示新会话第 99 轮和新草稿，没有继续请求旧会话的下一页。比较保留读取参数、消费状态和展示登记次数，没有仅检查页面标题。

本轮共 132 个完整样本、66 组配对一致。未发现需要修改应用来对齐 master 的差异。
