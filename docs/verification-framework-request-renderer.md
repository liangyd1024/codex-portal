## 自动回归

新增四项行为测试：

- 相同签名不重建已挂载卡片，已发送问题不再次通知。
- 主侧及全局请求归属正确，不相关会话卡片不混入；原始未知字段与已有字段、详情展开状态保留。
- 回答保持对象身份，恢复跳过问题保留文本并触发重新投影。
- 侧栏交互期间不刷新侧栏，但卡片清除和控件刷新正常执行。

相关测试及完整 npm test 通过：888 项 Node、74 项 Python。类型检查与构建通过。没有关闭类型检查或为此引入宽泛 any。
