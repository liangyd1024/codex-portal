# 请求卡片与审批补验

## 基准与范围

正式网页仍为 `227dbfe`。隔离基准从该提交读取静态资源；迁移候选资源为 `7c82b343`，与独立预览 `06772a2` 的干净产物一致。候选隔离页创建时的工作提交为 `c4d0b0f` 且包含未提交修复，因此本轮按产物摘要归属，不能把它写成未经修改的 `c4d0b0f`。最新远端 master `0a3ee2a` 相对正式仅增加文档。

全部审批使用虚构会话、命令与路径。接口由静态隔离页拦截，未向真实引擎提交审批、停止或取消请求。本轮没有产品源码修改，也没有重启服务。

## 方法

使用同一 ego-lite 空间与页面，保留正常 React 调试回调和页面刷新行为。覆盖桌面 1480×747／DPR 2／触控 0，以及 iPhone 模式 390×844、844×390、390×480／DPR 3／触控 1。采样中核对实际视口、像素比和触控参数；桌面操作用鼠标，手机决策按钮用触控事件。

对比卡片子节点、文案、类名、禁用、隐藏、展开、aria-busy、角色、字体、前景、背景、边框、内外边距以及模拟写请求路径、方法和完整正文。另检查页面异常与横向溢出。本轮没有截图像素比较、完整几何比较或实体手机操作，不将计算样式一致扩展为全页面像素一致。

## 结果

| 检查 | 样本／对数 | 结果 |
| --- | --- | --- |
| 八种审批／工具请求分支 | 120／60 | 一致 |
| 断线、恢复、提交中和完成 | 40／20 | 一致 |

八种分支包括默认命令审批、本会话允许、文件变更审批、仅取消的权限请求、未知工具、空决策数组、全部决策不受支持以及提交失败。核对实际提交的 accept、acceptForSession、decline、cancel；本会话允许仅在接口提供时显示；未知工具保留专用实现说明与取消入口；不支持的决策不生成可操作按钮。失败后卡片保留、忙状态结束，按钮恢复。

第二组检查断线后按钮禁用与恢复提示、连接恢复后按钮可用、延迟响应期间 aria-busy 和提交提示，以及释放模拟响应后卡片移除。两版各场景完整状态一致。共 160 样本／80 对，无页面异常或横向溢出。

## 中断样本与修正

首轮仅等待 request-card 存在，在前一张“无可用操作”卡片尚未替换时查找下一张卡片按钮，出现 missing action。观察同页确认后续卡片已正常显示按钮，后续轮次改为等待详情 JSON 与当前请求一致。

第二轮在横屏候选页遇到按钮不可命中。检查发现该隔离页留有之前附件测试的 sessionStorage 图片草稿，最初脚本误重置了同名 localStorage 键。之后只重置这两个虚构入口的准确图片草稿键，并等待按钮可命中，再完整重做两版四视口。没有修改正式存储或产品布局。上述中断轮次不计入通过样本。

## 尚缺

请求卡片外层和非问题审批控件仍由原生 DOM 控制器管理；本轮验证建立迁移前的行为依据，不代表该区域已完成 React 迁移。真实审批、SSH 完整流程、页面全状态视觉、整体性能及其他剩余实现仍需继续核验。原有类型检查与完整回归证据见持续报告；本轮仅浏览器验证和文档更新，没有重复运行应用测试。
