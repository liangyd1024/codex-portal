# 当前会话发起网页部署

## 规则和实现

用户明确要求自身会话不能阻塞重新部署。AGENTS.md 与 README 已同步：仅网页服务重启时，安装程序从 Codex 执行环境 CODEX_THREAD_ID 识别调用会话，在配置指定的本机连接中精确豁免其 active 状态。未提供有效 ID 时仍按原空闲条件判断。其他连接、其他会话、任何待处理请求和正在连接状态不豁免；不停止或中断任何目标引擎会话。

备份前与重启前分别检查，阻塞消息列出连接及其他活动会话 ID。保留加密备份、指定提交安装、健康检查和失败回退。自身部署不等于引擎维护或数据恢复的授权，不更改原生引擎、数据库或配置。
