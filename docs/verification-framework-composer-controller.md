## 测试入口兼容修复

项目声明支持 Node 22.12+。较早 Node 22 需要显式启用类型剥离才能直接执行 `.ts` 模块，见 [Node 官方说明](https://nodejs.org/learn/typescript/run-natively)。原测试入口没有该参数，已有 JavaScript 导出入口转向 TS 后会在这些版本失败。

使用官方 Node 22.12.0 发行包，核对官方 SHA-256 后在仓库外运行：未加参数时目标提交测试报 ERR_UNKNOWN_FILE_EXTENSION；加入参数后 11 项通过。现由 scripts/run-tests.mjs 显式传入 --experimental-strip-types，保留 JavaScript 入口及同一测试套件；未改变正式部署策略。新增回归在默认关闭类型剥离时实际运行 TS 测试，验证入口仍可加载，避免只断言命令文本。

Node 22.12.0 与 24.11.1 的完整构建和 903／74 项回归均通过。README 同步使用完整共享入口，单文件示例明确所需参数。
