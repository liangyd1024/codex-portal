# 黑色滚动条与轮次交互复查

日期：2026-10-22。

## 依据与修改

依据用户截图要求滚动条为黑色，并复查 [轮次导航](verification-2026-10-22-turn-navigation.md)、[完整历史加载](verification-2026-10-22-navigation-expand.md)和[侧边聊天](verification-2026-10-22-side-chat-parity.md)的既有记录。本轮未重新核验 Codex 原生界面，不声称像素级一致。

- 统一全局滚动条为黑色，移除正文内部的灰色覆盖。提供标准 scrollbar-color 及 WebKit 样式。
- 轮次预览在正文或刻度滚动、点击外部时收起。Escape 忽略输入法组合事件。
- 轮次目录加载历史时按可见轮次保留阅读锚点，不再仅保留旧 scrollTop。
- 从目录跳转后焦点留在目标正文。直接关闭目录时仍恢复入口焦点。
- 方向键按刻度的实际显示顺序移动，避免补齐历史后 Map 的插入顺序与显示顺序不同。

保留首次仅读取最近轮次、点击导航后顺序加载全部的行为。未改变原生会话、执行、消息正文或历史读取接口。

## 验证

完整 `npm test`：419 项 Node.js、69 项 Python 测试通过。`git diff --check` 通过。

使用 ego-browser，在开发端口拦截全部业务 API 与 SSE，使用虚构测试数据。开始时只读复用已运行的开发预览；该预览退出后，按约定用全新临时状态目录启动预览。没有向真实会话发送消息或停止任务。

- 桌面 1440×1000：侧栏、正文和表格的 scrollbar thumb 计算颜色均为 rgb(0,0,0)。滚动正文及点击外部收起轮次预览；聚焦预览前后历史请求均为 0。无页面横向溢出、无 JavaScript 错误。
- iPhone 12 参数：390×844、DPR 3、mobile、触控模拟、coarse pointer。补充 844×390 横屏与 390×500 小高度场景；均无页面横向溢出。
- 触控打开手机目录，16 轮扩展到 21 轮，共 3 个串行历史请求。非底部可见锚点偏移约 -0.51px。靠近底部时，加载按钮收起使列表可视高度增加，滚动范围钳制产生约 44px 位移；当前阅读轮次仍在视口中，不再因新增五轮被挤出视口。
- 触控选择目录项后焦点留在所选 message-turn；Escape 直接关闭目录后焦点返回“更多操作”。
- 复查侧边聊天工具菜单：390×500 时边界为 x=18…250、y=199…433，完整处于视口内。触控外部收起、切换模型后收起通过。已查看桌面、手机目录及侧边工具菜单截图。

手机目录跳转检查中曾因测试等待了错误的 mobile-layout 节点、或点到了视口外的目录项而超时，修正验收定位后完成检查。开发预览中途退出导致一次连接失败，重新启动独立预览后完成。上述测试问题未标为产品通过项。

最后键盘采样发现补齐历史后 ArrowDown 没有移到下一显示刻度。随后代码改为读取实际 DOM 顺序；完整测试重跑通过，但这一行修复未再次浏览器验证。Escape 收起和 Enter 跳到正文已验证。

本轮不涉及输入发送逻辑。未执行真机输入法、系统选区、系统软键盘、Safari 或 Firefox 验收；未重新验证真实引擎端到端流程。
