## 提交次数与耗时

保留并调用原 React 提交回调，桌面与 iPhone 竖屏分别按旧／新／新／旧采集。八份诊断均在页面主体创建前接入：旧版每次 78 次提交，新版每次 76 次。减少的是两个空高亮层的首次提交，不将其他提交统称为无效渲染。

耗时另行采集，不带提交调用栈包装。两版、两种设备各按 ABBA 重复两轮，共 16 次；随后反转顺序再采 16 次。脚本时间中位数如下。

| 设备 | 首轮旧／新 ms | 反向复测旧／新 ms |
| --- | --- | --- |
| 桌面 | 78.73／79.56 | 79.18／78.89 |
| iPhone 竖屏 | 79.15／81.01 | 78.94／78.62 |

首轮桌面旧版首次为 16 个请求，其余均 20 个；反向复测两版全部 20 个。首轮手机偏高未在反向顺序重现。保留波动，不宣称稳定耗时改善。该改动确定减少两次同步提交，但整体首屏相对 master 的性能差距仍未解决。
