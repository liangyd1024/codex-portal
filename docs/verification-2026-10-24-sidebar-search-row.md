# 搜索与新建会话合并

搜索框与新建会话合并为一行，搜索在左侧伸缩，右侧为 44×44px 加号按钮。提示缩短为“搜索会话”，辅助名称仍为“搜索目标机器会话”。新建按钮保留名称、快捷键提示、禁用原因与原有处理函数。手机整行同为 44px，输入字号 16px。

## 验证范围

- 参考用户截图及现有侧栏加载稳定性记录。先核对正式页面样式，再用 ego-browser 在独立页面替换本次 DOM 并加载实际修改样式。预览端口由其他项目占用，未启动另一个预览服务。
- 桌面 1492px 宽：搜索框在左、新建按钮在右，同一行。Tab 从搜索进入新建，焦点为 2px 黑色实线。检查悬停和禁用透明度 0.4。
- iPhone 12 模拟：390×844、DPR 3、mobile=true、5 点触控，核对粗指针。打开手机抽屉，两控件整行 44px，无横向溢出，截图已检查。模拟触控新建按钮的样例回调执行一次，未创建真实会话。
- npm test 全量通过：675 项 Node 测试与 72 项 Python 测试。最终 CSS 调整后再次通过。
- 新增一个布局容器，无请求、轮询或新增计算。未进行 CPU 或内存基准测试。
- 未实测实体手机、系统中文输入法和剪贴板。未修改搜索事件、新建会话业务或发送逻辑。

代码版本以本文件所在提交为准。正式部署另行记录。
