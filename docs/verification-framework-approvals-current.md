# 当前候选审批卡片复核

## 版本与边界

正式 4317 与预览 4327 的版本接口均返回 200，分别为 `227dbfe93ee88718c2437f7b7c7b119570a720a6` 和 `7eb6eb350d6bef129d962df833d61c6aa23db7ef`。隔离入口使用正式提交导出的源码及与候选相同的资源 `44ed4d81fdeecb3addb105017d0a55c3a3e94e45607ff420a6e8a84f8cde203b`。

使用 ego-lite 同一任务空间，保留正常扩展和 React 调试回调。桌面为 `1480×747`、DPR 2、触控关闭；iPhone 12 模式为 `390×844`、横屏 `844×390`、短高度 `390×480`，DPR 3、触控开启。导航前后设置参数，并在每个样本检查实际值。手机审批按钮使用触控事件。

所有请求、命令与路径均为虚构样本。静态夹具拦截接口，没有提交真实审批或执行命令、修改文件。仅重置隔离入口的虚构视图及图片草稿键，没有清理正式存储或浏览器全局状态。本轮无产品代码修改、构建或服务重启。

## 决策分支

四视口共 120 个样本、60 组配对一致。覆盖默认命令审批、本会话允许、文件变更审批、仅取消的权限请求、未知工具、空决策数组、全部决策不受支持和提交失败。逐次核对 accept、acceptForSession、decline、cancel 的实际请求值。

不支持的决策没有生成操作按钮；失败后卡片保留、忙状态结束、按钮重新可用。所有样本的实际设备参数正确，无页面错误或横向溢出。隔离候选与干净预览产物的 71 个 public 文件已逐一按内容摘要核对一致。

## 断线与提交等待

四视口共 40 个样本、20 组配对一致。覆盖可用、断线禁用与恢复提示、重新连接、挂起提交和完成。等待期间 aria-busy 为 true，所有决策按钮禁用；释放模拟响应后卡片移除，每个流程仅一条 accept 请求。节点、几何、焦点及请求均一致，无页面异常或横向溢出。

## 展开详情与重建

四视口共 32 个样本、16 组配对一致。打开原始请求详情，在模拟请求中增加未知 future 字段并触发卡片重建，确认节点已替换且详情仍展开，原始 JSON 展示新增字段。随后通过桌面点击或手机触控拒绝请求，核对仅发送一次 decline，完成后卡片移除。各状态的几何、计算样式及焦点一致，无页面异常或横向溢出。

除请求路径、方法和完整正文外，对比卡片各节点的文案、类名、禁用、隐藏、展开、忙状态、角色、几何位置、焦点，以及字体、颜色、背景、边框和内外边距。另检查页面异常和横向溢出。

设备模式不代表实体软键盘或系统交互验证；计算样式和几何对照不扩大为全页面截图像素一致。原始脚本与结果保存在仓库外。
