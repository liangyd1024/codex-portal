## 真实 SSE 心跳与客户端隔离

每个网页入口新建两个只读客户端，收到初始状态和首次心跳后关闭其中一个。剩余客户端继续收到第二次心跳；再新建替代客户端，正常收到初始状态及 system/update 事件。六个客户端最后均由脚本关闭，不关闭任何已有客户端。

两入口均为 200，Content-Type 为 `text/event-stream; charset=utf-8`、Cache-Control 为 `no-store`、X-Accel-Buffering 为 `no`。检查前后连接均正常，待处理请求为零，网页接管项数量未变。业务事件计数可以不同，不将实时事件数量误判为协议差异；不保存原生消息正文。首状态时延仅作诊断，未用于性能结论。
