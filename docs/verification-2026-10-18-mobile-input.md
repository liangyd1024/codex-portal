# 2026-10-18 手机输入与同步反馈专项验收

## 反馈来源与实现

已读取用户引用的“用户问候与友好交流”会话，核对网页新建后同步失败、命令审批频繁、计划/目标/技能/插件入口和移除语音的要求，并查看本轮四张手机截图。

| 问题 | 本轮结果 |
| --- | --- |
| 手机无法添加图片 | 输入框增加 ＋，支持选择、粘贴、预览、移除，最多 4 张；压缩后使用引擎 image 输入，支持纯图片及运行中补充 |
| 语音按钮占用输入区域 | 移除网页语音入口，系统输入法听写不受影响 |
| 输入功能缺失 | 增加执行/计划、默认权限/完全访问，目标、技能、插件收进工具菜单；选择按连接和会话保存 |
| 逐次命令审批 | 完全访问使用引擎权限参数；已有请求仅在引擎提供 acceptForSession 时显示本会话允许，不伪造审批能力 |
| NoneType has no len() | 会话归属路径过滤空值；新增含 null 工作区和 cwd 的回归。当前真实本机数据未复现历史异常，不能将截图历史原因视为已完全确认 |
| 新建后同步错误 | 已成功创建但尚未落盘的空会话可使用创建返回值显示；只对已知新建会话启用。可选目标读取失败不再升级为全局同步错误 |
| 超时与长时间创建 | 区分只读超时和写入结果未知，创建超时不自动重放；仍依赖目标引擎响应速度，未声称消除所有耗时 |
| 提示覆盖聊天、短屏工具被裁切 | 手机提示改为文档流、限高滚动；工具菜单按可视视口定位；输入区域短屏可滚动 |

图片草稿限当前标签页 sessionStorage。失败保留文字和附件，成功只清除对应已发送内容；容量不足明确提示。图片需浏览器可解码，不支持的 HEIC 等格式提示转换。插件通过明确文字指令调用已启用插件，不是完整原生插件芯片协议；安装及授权仍在 Codex 管理。

## 验证证据

- 发布工作树 npm test：83 个 Node 测试、24 个 Python 测试全部通过。日志 `/tmp/rcm-input-release-tests.log`。语法检查和 git diff --check 通过。
- 新增回归覆盖图片格式/体积/数量、纯图和混合消息、message/steer 传参、迟到响应不清新草稿、仅消息路由扩大请求体且保留 CSRF、创建超时不重放、权限参数、技能插件校验、目标失败隔离与会话审批能力限制。
- ego-browser TaskSpace 50，4327 静态隔离预览及模拟 API：320、375、390、430px、844×390 和桌面 1280px 无横向溢出；手机输入可见控件至少 44px，发送 48px。375px 展开模型/档位分别为 297×44、273×44。
- 390×540 模拟短视口输入区和发送按钮底部为 527px；不等同于实体 Safari 键盘验证。
- 浏览器模拟验证上传、发送失败保留原文和图片、刷新恢复草稿、发送成功清除附件、计划/技能/插件/权限参数、停止、目标保存。执行模式刷新后仍为 plan。
- 实际本机引擎：仅操作本轮专用会话 `01a14e8a-466a-7d10-9841-900d66a76dd0`，发送生成的 32×32 红色 PNG，轮次 `01a14e8a-56d2-78d1-89f0-2e271a397d45` 完成并回复“红色”。没有向真实引擎发送用户截图，没有接管已有会话或停止引擎。
- 本轮浏览器截图受 Ego 窗口最小化限制，未取得新的渲染截图；以上浏览器布局依据语义快照和几何测量，不能代替完整视觉验收。
