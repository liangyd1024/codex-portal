## 实现与回归

将主控制器的 SSE 事件分发迁入严格 TypeScript 服务。事件仍按原顺序传给侧聊、账号刷新、通知、状态和当前会话处理。保留完整参数和未知字段，不增加解析转换或字段裁剪。账号版本仍由主控制器统一持有；旧目录请求完成后，仅最新账号版本可以刷新。消息解析、正文缓存、节点协调及 80 ms 流式合并刷新算法均未改变。

新增五项事件行为测试：完整文本增量和未知消息、日志输出分支与推理增量、按请求类型与键精确移除、连续账号切换后的旧请求排空与失败反馈，以及历史事件不重复通知和连接恢复。原八项通知测试接入实际 TypeScript 事件入口，保留原断言。类型检查、构建和完整 840 Node／74 Python 测试通过。

参数为桌面 1480×747／DPR 2／无触控，以及 iPhone 12 390×844、844×390、390×480／DPR 3／触控 1；导航后核对实际参数。

- 事件渲染：64 样本／32 对一致，覆盖初始、助手增量、计划消息、推理增量、命令输出、问题出现、问题移除、连续账号刷新。比较完整正文、问题文案、输入草稿／占位文案／禁用、模型选项、标题、滚动及选区。全部样本保留原正文节点和“这是一”选区，草稿不变，无异常或横向溢出。这是页面 Range 与事件分发验证，不代表实体系统选区手柄或软键盘。

## 事件批次耗时

以正式、上一迁移版、候选按 A/B/C/C/B/A 顺序执行，桌面与手机各六组。每组 25 批、剔除前五批，每批 20 个完整文本增量，共 240 个有效批次。分别测量同步分发和最后增量出现在正文中的时间。后者包含既有 80 ms 合并定时器、绘制帧等待及布局读取，不能当作纯 CPU 渲染成本。

| 设备 | 正式同步／显示中位数 | 上一版同步／显示中位数 | 候选同步／显示中位数 |
| --- | --- | --- | --- |
| 桌面 | 0.10／86.50、0.10／86.60 ms | 0.20／87.30、0.20／86.70 ms | 0.20／91.05、0.20／87.05 ms |
| 手机 | 0.10／88.10、0.10／88.15 ms | 0.15／87.85、0.20／87.50 ms | 0.20／88.30、0.20／88.65 ms |

桌面首个候选组偏高，另以旧／新／新／旧分别执行桌面和手机，每组 45 批剔除前五批，共 320 个有效批次。所有组同步分发中位数均为 0.20 ms。显示中位数：

| 设备 | 上一版 | 候选 |
| --- | --- | --- |
| 桌面 | 88.45／88.40 ms | 88.65／88.80 ms |
| 手机 | 88.65／89.15 ms | 89.10／89.00 ms |

同步分发未观察到可分辨增量；显示耗时仍有小幅差异，桌面候选高约 0.2–0.4 ms，手机结果交叠。首轮高值和加长结果均保留，不宣称性能门槛通过。所有样本正文节点稳定，无发送／引导请求、异常或横向溢出。整体性能仍需继续解决和验证。
