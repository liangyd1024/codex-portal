# 更新流程稳定性与耗时

## 原因

用户截图对应的更新在测试阶段退出。实际记录总耗时约 47.0 秒，Node 测试约 6.8 秒，失败位于 mobile-server.test.mjs 的撤销 SSE 连接断言。旧日志没有分阶段时间，不能把剩余耗时准确归因于 Git、进程启动或状态检查。本轮只读完整部署状态检查样本约 31 ms。

SSE 消息和 TCP 数据块没有一一对应关系。初始 manager/status 后还会异步发送 system/update。测试只读取一次初始块，随后撤销连接，再要求下一次读取立即为 EOF。当缓冲区仍有事件时，该断言误报。另一个连接隔离测试也错误假设下一块必含目标事件。

## 修改

- 撤销测试主动排入一个额外更新事件，在限定时间内读完缓冲数据直到 EOF，同时验证撤销后接口返回 401。连接隔离测试读取到指定事件，仍检查没有跨连接事件。没有修改手机配对、Origin、CSRF 或撤销实现，也没有跳过失败测试或自动重跑掩盖失败。
- 与正式版本相比，仅改根目录 README.md、AGENTS.md 或 docs/ 下 Markdown 时，同步 master 后直接完成。当前版本仍是实际运行版本，记录已核对的源码版本，不做应用测试、安装或重启。未知路径、测试、配置、脚本及任何运行代码变化仍走完整流程。关闭 Git 重命名检测，防止运行文件移动到文档目录后被漏检；文件名保留 NUL 分隔，不 trim 原始命令输出。
- 移除测试后、调用安装器前的一次重复入口检查。保留测试前检查，以及安装器安装前和实际重启前的复核、部署锁、正式版本祖先校验、工作区干净检查和失败回退。
- 更新状态记录阶段与命令耗时；私有日志分别记录 Git 操作、测试及安装耗时。后续慢更新可按实际阶段定位，不根据进度文字猜测。

## 验证

- 相关回归通过；两组 HTTP/SSE 测试连续 30 次运行无失败，约 8.0 秒。新增工作流回归覆盖文档快捷路径、运行文件删除与重命名、未知文件、分支分叉、工作区脏状态及正式版本变化。没有减少正常代码更新的测试范围。
- 完整 npm test：628 项 Node.js、70 项 Python 通过。Node 阶段约 4.7 秒、Python 阶段约 1.5 秒。与旧失败运行负载不同，不据此声称测试运行器提速。git diff --check 通过。
- ego-browser 加载实际更新模块和公共样式，模拟失败到纯文档成功、键盘 Enter 单次提交、提交中禁用及 iPhone 12 触控提交。iPhone 12 参数 390×844、DPR 3、mobile、触控、coarse pointer 均核对，无横向溢出。实体手机未实测；本轮不改消息输入。
- 真实发布耗时及上线版本在后续记录补充。仅文档路径减少完整测试和安装重启开销，Git 拉取仍受网络影响，不声称网络耗时已解决。
