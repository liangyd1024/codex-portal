# 手机交互优化与验收（2026-10-18）

## 交付范围

已完成代码优化、隔离预览、浏览器模拟交互、真实服务的专用会话验证。**没有正式部署；没有实体 iPhone / Android 验收。** 下文的“通过”均附验证范围，不能等同于 Safari 真机通过。

开发预览：`http://127.0.0.1:4327`，`RCM_MOBILE=0`，独立状态目录 `/tmp/rcm-mobile-preview.iNFnIy`。危险操作只在模拟接口或自动化测试的临时服务中执行，没有停止在用目标服务、撤销真实手机登录或导入正式浏览器数据。测试目录和专用会话保留，没有批量删除。

本轮保留工作区原有的侧栏和会话交还改动。操作语义依据仓库的[创建验收](verification-2026-10-18-creation.md)、[交还验收](verification-2026-10-18-handoff.md)及现有实现；未声称已经与 Codex 的原生手机界面逐像素对齐。

## 已实施优化

1. 手机断点集中在 `mobile-ui.js`，覆盖竖屏和触控横屏。按钮/菜单项至少 44×44px，主要操作 48px；常用按钮之间保留 8px；表单输入 16px；开关和答案整行可点。保留浏览器缩放。
2. 顶部只保留导航、标题、连接状态、更多和详情。刷新、自动刷新、消息信息、交还入口移入更多；接管放到输入区域。会话行和更多按钮分别占位，触控时更多始终可见。
3. 竖屏文字输入独占一行，底部保留模型、语音、发送/停止。横屏保持紧凑。输入区、菜单、抽屉和弹窗使用可视视口高度及偏移，解除旧最小高度限制，并保留安全区。
4. 抽屉开启后主区域 `inert`，Tab 在当前面板内循环；关闭回到入口。Escape 只关闭最上层菜单/弹窗；短屏弹窗整体滚动，底部按钮不再盖住表单。详情切换分类回到顶部。
5. 手机 Enter 换行；桌面 Enter 发送、Shift+Enter 换行。保护 composition、`isComposing`、Safari 的 229 键码及候选确认后的短间隔。
6. 草稿持续写入按连接/会话隔离的 sessionStorage，隐藏、切换、重新配对前同步。成功只清理发送时的对应版本；失败保留原文。导入后不再由旧页面的 pagehide 覆盖新导入的草稿。
7. 创建、发送、停止、审批、侧栏变更、刷新和配对有可见等待反馈及重复提交保护。禁用原因直接显示；网络恢复只合并读取，不重放写请求。配对等待 20 秒后可重试；听写不支持、权限拒绝、服务失败均给出说明。
8. 验收中一并修复：创建成功后访问已移除的 `collapsedProjects` 变量；归档提示妨碍撤销；输入宽度变化时 ResizeObserver 循环；接管后空会话提示未更新；详情分类保留旧滚动位置遮住入口；更多菜单中的异步按钮变为禁用后未正常收起菜单。

HTTP API、连接 ID、配对协议和目标任务控制语义不变。服务端仅增加前端静态文件路由，未配对入口仅额外开放配对页所需的 CSS。

## 验证层级与共用状态

- **B**：ego-browser（ego-lite / Chromium）加载实际页面，`test/fixtures/mobile-browser.js` 拦截 API 和事件流；图片使用仅匹配测试图片 URL 的响应拦截。所有模拟写请求不会发送给真实引擎。
- **T**：Node/Python 自动化测试；手机权限测试使用全新临时 HOME、真实 TLS 服务器和合成登录会话。
- **L**：4327 预览连接真实本机服务，只使用本轮专用会话。
- **待验**：需要真实设备或外部服务，未用模拟结果代替。

## 尺寸、滚动与焦点证据

- 竖屏：320×720、375×812、390×844、430×932；横屏：844×390；桌面：1280×900。
- 每种手机尺寸测量主界面、更多菜单、侧栏、会话菜单、新建弹窗、设置、手机访问，共 **35 场景、320 次控件测量**。未发现小于44px的目标或页面横向溢出。视口内目标的中心及左右边缘命中通过；窗口外内容采用滚动后实际操作，不能把“有 DOM”当可达。
