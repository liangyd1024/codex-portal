# 目标状态栏收紧

依据用户提供的现有目标栏截图及确认，仅减少外框上下留白和输入框上方间距。保留原有目标编辑、删除和暂停语义。

单行外框从 54px 降为 46px（约 15%）；底部间距从 8px 降为 6px。操作按钮保持 44×44px。长文字仍可换行。沿用黑色细边框、公共圆角、字号及图标。

## 验证

- 目标栏相关 4 项测试通过。完整 npm test 通过：671 项 Node.js、72 项 Python 测试。完整测试包含共享目录中其他会话的未提交修改。
- ego-browser 隔离组件模拟使用真实 goal-toolbar.js 和页面顺序加载的 12 份样式；修改前测量计算样式，高度 54px、上下 padding 4px、黑色边框。
- 桌面 1440×1000：修改后高度 46px；按钮尺寸保留；默认、悬停、可见焦点、Tab 顺序、禁用透明度 0.4 验证通过。已并排查看目标栏与输入框。
- iPhone 12/14 共用参数 390×844、DPR 3、mobile=true、5 触点、coarse pointer；执行前核对设备模式。使用移动布局及 12px 侧边距时高度 46px，无横向溢出。额外以 24px 侧边距验证文字自动换行，高度 52.5px，无溢出。
- 触控编辑入口可响应。目标读取失败时显示“目标待确认”并禁用操作。844×390 横屏及 390×480 可视高度模拟无横向溢出。
- 开发预览端口已被占用，没有启动或停止预览服务。本次为隔离组件模拟，未执行真实原生目标变更、实体手机或真实软键盘验证；未重新验证完整异步请求生命周期。未修改输入或业务逻辑。
- 性能：只修改现有 CSS 的两个间距值，不新增 DOM、请求、计时器或计算。未测量 CPU、内存与渲染耗时，不声称性能最优。
