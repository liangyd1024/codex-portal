# 自动跟随登录与认证恢复

## 授权与范围

用户要求切换账号后自动加载，不再手动点登录重载，并明确授权自动恢复可以中断任务。本功能使用 RCM 连接配置 `autoReloadLogin: "interrupt"` 保存该策略，默认关闭。只在正式网页启动；开发预览不启动检测器。没有更改 Codex 安装、配置、认证文件或任务存储。

## 实现

- 登录文件只读取 stat 元信息。原生 `app-server` 的独立只读进程仅执行 initialize、initialized 和 account/read；不启动或恢复会话、不导出令牌，完成后退出。
- 通过原生返回的账号类型、邮箱及工作区识别账号切换。套餐变化和同账号令牌刷新不触发重启。RCM 只持久化文件信号及失败尝试摘要，不保存账号或凭据内容。
- 正常状态每 15 秒只读元信息；没有文件信号时最多每分钟探测一次。每个管理器合并并发恢复，断开连接后停止监测，迟到响应不能操作新连接。
- 自动维护通过原生接口暂停目标、停止轮次及后台命令，再复用完整维护检查和登录重载。保留原生队列，不复制、删除或重发消息。停止的目标、命令不自动重建。
- 准备失败最多三次。已尝试重启而结果不明时不重复执行，同一登录变化的尝试摘要保存在 RCM 状态中。新登录信号到达后重新检查。

## 验证记录

真实原生协议已导出核对 account/read；原生只读探测与当前运行引擎返回同一 ChatGPT 身份及工作区。单次本机测量：元信息读取约 65ms，原生只读探测约 911ms。未修改真实账号或凭据，不将此次同账号核对当作跨账号切换验收。

回归测试覆盖普通令牌刷新、工作区切换、API Key 文件变化、退出后重新登录、并发请求合并、迟到响应、维护中断、原生队列保留及重启失败不重复执行。Python 测试验证探测进程只调用账号读取，并验证元信息检查不读取凭据内容。

此前经用户授权，真实停止两个专用测试服务并完成一次登录重载；正式账号和用量读取成功。此操作发生在自动检测器上线前，不标为自动恢复验收。

## 未验证与限制

真实切换 ChatGPT 账号、API Key 往返、SSH 自动恢复、跨入口并发提交尚未真实验收。原生接口没有跨入口互斥锁，维护仍可能因新任务到达而被拒绝。未知状态不会强制重启。无文件信号的同类型 API Key 更换无法提前识别。没有进行手机实体输入或布局验证，本次未修改页面布局和输入逻辑。
