## 改动

- 入口从左侧移至右侧“工作区详情 → 定时任务”。
- 每条任务用“…”收纳编辑、删除。名称打开本任务详情；编辑和删除先显示任务对象、管理方式与原生内容，不再直接跳到固定会话。
- 明确点击“前往管理会话”后才填写对应任务 ID 的草稿；执行会话和运行记录仍独立打开。管理会话已有草稿时不覆盖、不追加。
- 原生 dialog 支持 Escape、焦点约束及返回任务名称；菜单支持键盘及 Escape。关闭详情不会发送消息。
