# 网页插件 @ 引用验收

## 改动与依据

以用户提供的 Codex 候选列表截图为交互依据。输入 `@` 显示插件，按内部名称、显示名称和简介过滤；仅显示已安装且启用项。复用技能候选布局与行内引用。支持方向键、Enter、Tab、Escape 和点击选择。引用随草稿保存和删除，发送失败保留。

本机原生 `app-server generate-ts --experimental` 的 `UserInput` 确认 `mention` 包含 `name` 和 `path`。只读核对桌面前端实现，其插件引用使用 `plugin://${plugin.id}`。服务端重新读取目标目录，按原生 ID 校验后发送 `mention`，替换原有额外文字指令。新轮次和运行中补充共用此路径。

- 模拟延迟请求在 Escape 关闭后不再弹出；清空输入后行内引用移除。
- 原生协议类型和桌面实现为只读核对；未向真实模型发送任务，插件工具实际执行未验收。
