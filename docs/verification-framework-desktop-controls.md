## 隔离行为对照

使用 ego-lite。桌面 1480×747、DPR 2；iPhone 12 参数 390×844、844×390、390×480、DPR 3、移动与触控开启。所有请求由模拟接口接收，没有向真实桌面或引擎发送消息、解锁或停止任务。

四视口各比较入口、桌面可用／不可用／恢复、发送进行中、拒绝、重试成功、结果未知、重复提交阻止、刷新后的未知回执、解锁进行中、解锁失败和再次解锁成功，共 104 个样本／52 对全部一致。手机控件使用触控事件。比较包括按钮完整状态、标签、文本、样式、尺寸、焦点、节点身份、相邻位置、输入可用性、草稿、存储回执和 POST 内容。无页面异常或横向溢出。

对照只规范化随机消息 UUID；另行断言三次发送的 ID 各不相同，未知结果回执与最后一次发送 ID 相同，避免规范化掩盖 ID 错用。刷新会重建节点，因此节点身份按每次页面加载单独记录。

类型检查、820 项 Node／74 项 Python、构建通过。干净构建资源与隔离候选一致。
