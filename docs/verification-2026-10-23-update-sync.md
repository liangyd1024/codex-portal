# 更新状态跨入口同步

## 范围

系统更新保留一个按钮。打开设置或展开更新面板时自动检查远端 master。检查使用固定的 git ls-remote，不修改源码，不部署。并发检查合并，成功和失败结果均缓存 60 秒。

更新状态通过既有 SSE 连接推送，不随所选目标连接变化。服务端共用一个目录监听器，接收后台更新进程的原子文件替换和安装记录变化。正常情况下不轮询文件；目录监听不可用时降级为共享文件监听。最后一个入口离开时释放监听。

服务版本变化后先保存草稿，再自动刷新。中文组词期间延迟刷新。草稿存储失败时保留页面。旧 HTTP 响应不得覆盖新推送状态。部署仍执行原有空闲检查、备份、测试、健康检查及失败回退。

## 验证

- npm test：447 项 Node 测试、69 项 Python 测试通过。Node 约 3.30 秒，Python 约 2.13 秒。
- 两个 HTTP SSE 客户端均收到更新事件；断开后订阅释放。三个并发版本检查只产生一次远端查询；缓存期间无重复查询。失败缓存及运行期间跳过远端查询通过。
- 后台原子写入到两个订阅者收到同一状态的测试约 9.38 毫秒。此值是本机测试样本，不代表所有网络延迟或性能最优。
- ego-browser 独立 4327 预览：桌面 1480px，单一更新按钮，键盘焦点可见，无横向溢出。
- API fixture：更新中禁用按钮、阶段显示、失败恢复、断线自动重试、已是最新版本通过。没有从预览执行真实部署。
- iPhone 12／14 共用 390×844、DPR 3 参数；已核对移动视口和触控模拟生效。触控打开详情及更新按钮通过，按钮高度 44px。844×390 横屏及 390×500 可视高度缩小场景无横向溢出。
- 中文文本全选、剪切、粘贴后，模拟组词期间不刷新，组词结束后保存完整文本并只刷新一次。刷新函数在 fixture 中记录调用，没有提交会话消息。
- 实体设备软键盘、选区手柄、系统剪贴板菜单、中文候选窗未实测。完整真实网页按钮更新链路及域名配对入口尚未做本次端到端验收。
