# 使用与运维指南

[项目首页](../README.md) · [开发指南](development.md)

## 配置与运行

需要 macOS、Node.js 22.12+（含 npm）、Python 3、Git 和已登录的 Codex。
加密备份另需 age。

在干净的克隆目录中执行：

```sh
npm ci --ignore-scripts
npm run doctor
npm run init
npm test
npm run deploy -- --ref HEAD
```

如果 Codex 不在默认位置，使用：

```sh
npm run init -- --binary /absolute/path/to/codex
```

也可使用自动准备脚本：

```sh
sh scripts/bootstrap-macos.sh
```

脚本检查工具、安装依赖、初始化、测试并部署。
已有 Homebrew 时，它会补齐 Node.js、Python 3 和 age。
它不安装 Homebrew 或 Codex，也不清空已有依赖目录。

`doctor` 只检查环境，不启动原生引擎。
`init` 创建权限为 `600` 的连接配置；重复运行保留已有身份。
配置损坏时会报错，不自动覆盖。

打开本机网页：[http://127.0.0.1:4317](http://127.0.0.1:4317)。
默认配置为 `~/Library/Application Support/RemoteCodexManager/connections.json`。
需要其他位置时，设置绝对路径 `RCM_CONFIG`。

### 管理连接

入口：“工作区详情 → 设置 → 目标机器连接”。
点击“添加机器”，填写机器地址。用户名留空时使用服务所在机器的 SSH 配置。支持 Tailscale 名称、IP 和 SSH 别名。
点击“连接并添加”后，自动读取机器名称、HOME、Python 和 Codex 路径。目标 Mac 需要 Python 3 和已安装的 Codex。识别不会启动或重启原生引擎。

- 默认尝试已有 SSH 配置、密钥或 agent。也可点击“使用密码登录”；密钥登录失败时会自动显示密码输入框。
- 勾选“记住密码”时，密码保存在运行网页服务的 Mac 登录钥匙串中；连接配置仅保存随机凭据引用。取消勾选时仅保存在服务内存中，重启后需在管理连接中重新输入。
- 密码不写入浏览器草稿、普通配置、日志、Git 或普通备份。迁移到其他 Mac 后需要重新输入；不会跟随备份迁移钥匙串密码。
- 管理连接可更换密码；指定新私钥会改用密钥登录。移除连接时会清理该连接的凭据。
- macOS 拒绝访问凭据时，先解锁运行网页服务的 Mac 屏幕和登录钥匙串，再重试连接。锁屏可能限制密码读取，即使登录钥匙串显示已解锁。解锁后仍失败时，在该 Mac 的“钥匙串访问”中检查 `CodexPortal.SSH` 的访问控制。
- 密码条目不存在时，在管理连接中重新输入。临时取消“记住密码”只在当前网页服务进程中保存密码，重启后失效。网页不会自动解锁 Mac、放宽钥匙串权限或缓存已读取的钥匙串密码。
- SSH 主机公钥须预先核验。身份不符时停止连接，不自动信任。
- 自定义端口、Codex 路径和 SSH 私钥放在“高级设置”。路径指运行网页服务的机器上的私钥路径；不复制私钥。
- “管理连接”只编辑当前机器。更换机器请使用左侧机器选择器。默认显示名称；自定义路径在高级设置，设为默认与移除在更多操作。
- 修改可执行路径或私钥时先检测，再保存。只改名称不发起远端探测。已有私钥留空表示保留。
- 更换地址、用户或 HOME 时新建连接。连接 ID 和机器 ID 保持稳定，改名不改变身份。
- 环境识别或检测不代表全部原生接口可用。失败保留表单，可修正后重试。

旧页面写入会被拒绝，避免覆盖新配置。刷新前先保存草稿。
有待处理请求或连接正在恢复时，不能移除或替换连接。
移除只断当前入口，不停止目标任务。
手工修改配置后，重启网页再使用管理界面。

开发预览和端口说明见[开发指南](development.md#启动预览)。
## 通过 Tailscale 远程访问

### 准备

- 在 Mac 安装并启动 Codex Portal。
- 在 Mac 和访问设备上安装 Tailscale。
- 将两端加入同一 Tailscale 网络，并确认连接正常。
- 使用期间，让 Mac 保持开机、联网且服务运行。

### 开启访问

1. 在 Mac 打开 [Codex Portal](http://127.0.0.1:4317)。
2. 进入“工作区详情 → 手机访问”。
3. 展开“Tailscale · 跨网络访问”。
4. 点击“开启 Tailscale 访问”。
5. 等待页面显示 HTTPS 地址。
6. 在远程设备打开该地址，或用手机扫描二维码。
7. 按页面提示输入配对码。

Codex Portal 配置 Tailscale HTTPS Serve，并检查转发结果。转发成功后才显示地址。远程设备无需安装局域网证书。

### 连接失败

| 现象 | 处理 |
| --- | --- |
| 提示未安装或未登录 Tailscale | 在 Mac 打开 Tailscale，完成登录后重试 |
| 提示 HTTPS 转发未生效 | 按错误提示检查 Tailscale 的 HTTPS 设置，再重试 |
| 提示已有 Serve 配置冲突或公网 Funnel | 先核对现有服务用途。Codex Portal 不会覆盖冲突配置 |
| 地址无法打开 | 确认两端 Tailscale 已连接，再确认 Mac 上的本机网页可访问 |
| 页面要求配对 | 在 Mac 的“手机访问”面板获取配对码，按页面提示输入 |

不要把本机地址 `127.0.0.1` 填入远程设备。请使用面板生成的 HTTPS 地址。

### 仅使用同一 Wi-Fi

1. 将手机和 Mac 连接到同一网络。
2. 在“手机访问”面板点击“开启同一 Wi-Fi 访问”。
3. 按页面提示安装并信任证书。
4. 扫描二维码，完成配对。

此方式不需要 Tailscale。两种方式使用不同的访问地址。

## 浏览目录与新建项目

1. 在“新建会话 → 选择项目”中点击“浏览文件夹 / 新建项目”。
2. 进入目标目录，或在父目录中点击“新建文件夹”。
3. 点击“使用此文件夹”。

目录属于当前目标机器。支持主目录、上级目录、绝对路径和隐藏文件夹。
已有同路径项目会复用。选择项目保留草稿，不发送消息。
项目通过原生接口登记，但不保证自动进入 Codex 桌面项目列表。

创建结果未知时，先刷新父目录核对。关闭弹窗不会撤销已送达的创建请求。
接口不兼容时，按页面提示处理，不重复创建。

## 账号与用量

“工作区详情”显示目标登录身份。ChatGPT 账号可显示邮箱及剩余额度。
API Key 模式不显示账号额度或 Key 片段。
身份每分钟刷新一次。断开时隐藏；读取失败后自动重试。
Codex Portal 不保存账号凭据。

### 手动重新加载登录

桌面 Codex 与 Codex Portal 专用引擎是不同进程。桌面切换账号后，引擎可能仍保留旧登录。
刷新网页只重读身份，不重启引擎。

1. 在目标机器的 Codex 中完成登录。
2. 断开其他入口，确认目标任务已结束。
3. 打开“设置 → 目标机器连接 → 高级维护 → 重启引擎并重新加载登录”。
4. 等待维护检查和重新加载完成。

检查覆盖会话、目标、后台命令、队列和待处理请求。
运行中或状态不明时会阻止操作。
通过后只重启 Codex Portal 专用引擎，不重启桌面，也不重发消息。
失败或结果未知时，先检查连接诊断，不连续重试。

### 自动恢复登录

此选项会中断目标任务。启用前，须明确授权此行为，包括其他入口的任务。
在对应连接设置 `"autoReloadLogin":"interrupt"`。
省略或设为 `"off"` 时，保持手动流程。

自动恢复仅在正式网页运行。它检查登录文件元信息，并通过原生接口核对账号。
同一 ChatGPT 账号和工作区的令牌刷新不触发重启。
账号变化或已识别的认证错误会启动维护：暂停目标、停止轮次和后台命令，再重载引擎。

- 不删除或复制原生队列。后续执行仍由原生引擎决定。
- 不重发失败消息，不重建已暂停目标或已停止的测试服务。
- 未登录时等待用户登录。同类型 API Key 更换可能只能在认证失败后识别。
- 准备阶段最多尝试三次。重启结果未知时停止重试。
- 无法确认任务结束、协议不可用或存在维护标记时停止维护。
- SSH 目标须在对应环境验证后启用。

识别认证失效后，网页隐藏旧身份，暂停新消息并保留草稿。
账号切换不删除或复制原生项目。

## 消息时间与耗时

消息时间来自原生历史，按北京时间显示。缺少时间时不显示，不用接收时间代替。
轮次耗时优先使用 `durationMs`，否则使用原生结束与开始时间之差。
没有有效数据时不显示。历史回退接口可能不提供逐条消息时间。

## 手机系统通知

iPhone / iPad（iOS 16.4+）：

1. 用浏览器分享菜单将网页添加到主屏幕。
2. 从主屏幕打开应用，按需重新配对。
3. 在“设置 → 任务通知”开启并允许通知。
4. 点击“测试通知”检查结果。

普通 iOS 浏览器标签页不能开启此通知。Android 需使用支持通知的安全浏览器。

通知通过服务端 Web Push 加密发送。切换应用或锁屏后，页面无需保持运行。
电脑须保持开机、联网并运行 Codex Portal。通知横幅仍受系统权限、专注模式和网络影响。
升级后，已授权设备会尝试自动接入后台推送。失败时，在任务通知中重新开启。
“测试通知”先检查手机通知接收器版本，再经过服务端推送通道。
测试通知绑定点击测试时打开的会话，并预览该会话最近结束轮次的回复。点击通知可返回该会话。未打开会话时，测试通知只打开应用。
测试区分推送服务接受、手机处理和系统显示失败。等待手机回执最多 20 秒。
手机调用系统显示成功仍不代表用户看到了横幅。声明式推送使用 `mutable: true`，允许接收器保留点击目标；接收器兼容 `PushEvent.notification` 和旧版 JSON 消息。接收器未运行或显示失败时，支持的 iOS 版本仍可使用声明式通知兜底。

网页引擎的完成和待处理事件直接触发通知。已查看会话同时使用只读历史核对完成状态和原生异步问题。
后台核对覆盖开启通知后查看过的最近 20 条会话，离开后最长保留 24 小时，运行中每 15 秒检查，空闲或读取失败时每 60 秒检查。前台已有新读取时延后后台检查。
首次读取不补发旧任务完成通知。仍待回答的原生异步问题会提醒，并与实时事件去重。
通知标题标明会话和状态。正文预览原生助手的最后回复、待回答问题或错误原因。只截取显示文本，不改写会话正文。
同一手机配对身份、访问地址和连接只保留最新订阅。更换订阅后保留已发送记录，避免再次提醒旧事件。不同配对设备和本机浏览器分别接收。
已回答或已结束轮次的问题不提醒。桌面审批等未提供原生事件的状态不能保证提醒。
暂时投递失败最多尝试 6 次，超过 1 小时放弃。失效订阅自动移除。
关闭任务通知只关闭当前设备的当前连接。撤销手机配对后停止该配对的推送。
推送密钥、订阅和短期投递队列保存在 Portal 独立状态目录，不改写 Codex 原生数据。
通知诊断仅保留最近 160 条接收、显示、点击和页面定位记录，不记录正文或订阅凭据。本机可通过 `/api/push/trace` 检查；手机仅可读取自身配对记录。诊断记录不等同于用户已看到通知。

## 定时任务

“工作区详情 → 定时任务”可搜索、筛选并查看原生任务和运行记录。
面板打开时每 15 秒刷新。Codex Portal 不保存任务副本，也不执行调度。

1. 在目标机器的 Codex 桌面新建并打开专用管理会话。
2. 在网页点击“新建任务”，选择并绑定该会话。
3. 在管理会话中核对并发送任务指令。
4. 以原始工具结果和回复确认变更。

绑定后不提供更换入口。编辑和删除使用任务菜单，再点击“前往管理会话”。
已有草稿不会被覆盖；先处理草稿，再返回任务入口。
“消息已接收”不表示任务已变更。

定时任务管理面板支持文字、停止轮次和历史查看。
管理面板中的图片、模型切换和工具确认仍需在桌面处理。
桌面必须保持运行并托管该会话。
协议不兼容或桌面关闭时，网页保留草稿，不切换到独立引擎执行。
发送结果未知时，先核对原始会话，再按页面提示解锁。

此能力依赖版本化内部协议。未知存储结构或账号迁移时，请在桌面查看。
Heartbeat 结果可能仅在原会话中。纯 CLI 目标没有桌面调度能力。
SSH 目标还需兼容桌面；其任务管理尚未完成真实验证。

## 安装指定版本与回退

部署仅重启 Codex Portal 网页，不停止 Codex 桌面、目标引擎或任务。
连接会短暂断开并自动恢复。`git pull` 只更新源码，不更新运行服务。

确认待部署提交包含已上线改动，然后执行：

```sh
npm test
npm run deploy -- --ref <commit>
```

指定版本部署不要求当前工作目录干净。未提交修改保留在工作区，不进入发布版本。
构建提交须与目标提交一致，且产物摘要未变。构建本身仍须来自干净的目标提交。
若当前工作区有其他会话的修改，在独立检出目录运行测试和部署。
安装器将同一仓库的 `master` 工作区记录为后续网页更新来源。保留该工作区；临时检出目录不作为更新来源。
依赖清单从目标提交读取，不从当前工作区复制。
只执行 `npm run build` 不能满足部署验证。
安装器先准备独立版本和生产依赖，再重启网页。
准备失败时保留旧网页。健康检查失败时恢复旧网页配置。

健康检查核对版本、首页和发布资源，不代表浏览器交互已验证。
安装不自动备份，也不删除旧版本或配置。
已有手机配置和证书继续保留。

部署仍检查待处理请求和连接恢复状态。
如已明确授权忽略某个请求，可追加 `--allow-pending-request <request-key>`。
豁免只对本次安装生效，不授权停止引擎。

回退时，用同一部署命令指定先前的兼容提交。
已有完整版本可校验后复用。旧网页 plist 保存在 `install-history/`。
不要直接修改已安装版本文件。

## 空闲会话资源回收

离开全部网页视图后，最多保留 10 个可释放的普通空闲会话。
超过数量时先释放最早空闲会话；连续空闲 3 小时也会释放。
历史保留，再次打开时通过原生接口恢复。
原生卸载会结束 REPL 变量和工具连接等临时状态。

运行轮次、活动目标、后台命令、队列或待处理请求会阻止释放。
正在查看或页面状态未确认的会话不自动释放。
实际卸载由原生引擎决定，其他入口订阅可能延长驻留。

临时侧聊不计入 10 个普通会话。完成过轮次、离开全部视图且空闲 3 小时后会退订。
空白侧聊保留。卸载后不能恢复原 ID，需点击“开始新侧聊”。
新侧聊保留草稿，不重放旧消息。

## 网页系统更新

入口：“工作区详情 → 设置 → 系统更新”。
更新对象是网页所在机器，不随选中的 SSH 目标切换。

更新程序检查工作目录、连接状态和版本，再同步 `origin/master`。
它使用完整测试和标准安装流程。
未提交改动、未推送提交、分叉或检查失败会阻止更新，不强制覆盖。
仅 README、AGENTS 或 `docs/` Markdown 变化时，只同步源码，不重启网页。

更新在后台执行。刷新页面不会重复启动更新。
日志位于 Codex Portal 状态目录的 `logs/web-update.log`。
重启后自动恢复连接并保存草稿，再刷新页面。
中文输入组词或草稿保存失败时，暂不刷新。

网络失败时保留原网页。开发预览不提供正式更新。
若异常退出留下 `deployment.lock`，先确认无安装进程，再手动删除提示的单个锁文件。

## 连接和维护

同一会话同一时间只从一个入口操作。当前没有跨入口控制锁。

### 新建与发送

选择目标和项目后填写消息。首次发送才创建会话。
创建成功但发送失败时，在同一会话重试。
创建结果未知时，先核对侧栏，不重复创建。
网页会尝试通知桌面发现新会话，但不保证立即进入桌面项目列表。

每条消息最多 4 张图片，支持选择、粘贴、预览和移除。
手机图片会压缩。无法解码的格式需先转为 JPEG、PNG 或 WebP。
发送失败保留草稿；标签页存储容量不足时会提示刷新风险。

普通网页会话运行中，新输入可进入原生队列。
支持编辑、删除和引导。接口不支持时禁用操作，不建立网页备用队列。

| 状态 | 桌面快捷键 |
| --- | --- |
| 空闲发送 | Enter |
| 运行中排队 | Enter |
| 引导当前轮次 | ⌘/Ctrl+Enter |
| 换行 | Shift+Enter |

手机触控模式默认直接追加，回车换行。
桌面托管和侧聊使用各自已支持的发送能力。

### 模式、目标与引用

“工具”可切换默认或计划模式，下一轮生效。
计划生成后可确认执行；暂不执行会保留草稿。
网页固定使用“完全访问”，运行轮次保留启动时权限。

“＋ → 目标”用于启动新目标。已有目标时，普通消息只补充会话，不替换目标。
修改目标使用目标栏或“编辑目标”。暂停、继续和完成需在空闲时操作。

输入 `/` 或 `$` 搜索技能，输入 `@` 搜索会话和已启用插件。
候选支持方向键、Enter / Tab 和 Escape。
引用属于当前草稿，发送失败保留，成功后清空。
插件安装与账号授权仍在 Codex 管理。语音可使用系统听写。

桌面托管会话的普通聊天输入框也提供“＋”、图片、技能和插件。
发送前校验当前项目的技能和插件目录，再通过原生桌面接口发送结构化输入。
图片可单独发送。发送失败或结果未确认时保留草稿。
模型、计划模式、目标设置和工具确认仍由桌面处理。
网页创建的会话尚不支持桌面直接跨入口发送。需要时使用“交还桌面”，待释放后在桌面打开。

会话引用限同一连接，每条最多 20 个。
被引用会话不接管、不恢复。普通网页通过只读 MCP 适配分页读取原生历史。
旧发起会话需要启用工具时，须空闲并可安全释放。
运行中添加引用、首次目标启动同时附带引用尚不支持。
跨入口工具兼容性与 SSH 引用仍需单独验证。

### 文件与图表

原始回复中的文件链接可预览或下载。
图片可放大，音视频使用浏览器播放器，PDF 使用浏览器阅读器。
HTML 默认显示源码，可点击“浏览器打开”在新标签页查看页面。
浏览器预览支持文件内嵌的样式、图片和 JavaScript，不加载外部或同目录资源，不允许访问工作台数据或提交表单。
SVG 仍仅显示源码。Office 和压缩包等提供下载。

文件从会话所属连接读取，不上传第三方。
仅允许原生历史可核验的绝对路径；受保护路径不可读。
文件缺失、连接离线或历史未落盘时可重试。

完整 Mermaid 代码块在浏览器本地渲染，支持源码、复制和放大。
当前使用 Tiny 版本，不含思维导图、架构图、KaTeX 和 ELK。
无法渲染时保留源码。Safari 需 17.4+。

### 失败与恢复

异步问题在输入框上方回答。失败保留草稿；结果未知时不自动重发。
异步问题可收起或跳过。同步问题仍需回答才能继续。
问题仅在原轮次仍运行且由网页控制时可提交。

当前会话可见且连接正常时，历史读取完成后间隔 5 秒继续同步。
返回页面或恢复网络时立即检查，并按需重建实时连接。短暂恢复显示轻提示。
页面进入后台时取消未完成的读取；已发送的操作不会自动重发。失败保留内容和草稿并重试。
重连后接管失败的原因可在“设置 → 连接诊断”查看。

模型容量不足时，当前受控会话按 10、30、120、300 秒自动重试。
重试使用原生空输入继续，不重复原消息。
切换会话、断连、新任务或未知提交结果会取消旧重试。
关闭网页后不继续后台重试。

### 自动选择会话入口

打开会话后，网页自动检查可用入口。桌面正在托管时，消息通过原生桌面接口发送。其他可恢复的会话通过原生接口继续。
桌面会话使用原有模型与工具。电脑端须保持运行。执行中可以先写草稿，任务结束后再发送。
入口无法确认时，保留草稿并显示原因。点击“重试”重新检查，不会自动重发消息。

### 交还桌面

点击会话顶部“交还桌面端”。
有运行轮次、目标、后台命令、队列或待处理请求时，操作会被拒绝。
退订后仍需等待原生引擎卸载，默认可能约 30 分钟。
其他入口仍订阅时会继续等待。

关闭网页不等于交还。交还意图会保留，重连不会自动接管。
需要返回网页时，点击“在网页继续”。

连接可配置 `threadUnloadDelaySecs`，范围为 0–86400 秒。
该值仅在专用引擎启动时传入，不修改全局配置。
应用到在用引擎前，须另行授权重启并完成维护检查。
缩短时间也会缩短普通断线后的恢复宽限。

### 停止目标服务

普通断开只断当前入口。停止目标服务会影响所有入口。

1. 结束目标任务、目标模式、后台命令和排队输入。
2. 断开其他入口。
3. 完成维护检查并明确确认停止。

维护标记会阻止兼容入口自动连接，但不是跨入口锁。
维护结束后，在目标机器执行：

```sh
python3 scripts/restore-apply.py resume
```

随后手动连接。不要用停止服务或恢复命令打断其他入口。

专用引擎使用 launchd `Interactive` 类别，文件句柄软限制为 4096。
网页更新不会改变在用引擎参数。应用参数仍需单独授权并检查空闲。
提高句柄限制不能修复原生泄漏。

## 加密备份

安装 age 后，初始化密钥并备份：

```sh
python3 scripts/data-backup.py key-init
python3 scripts/data-backup.py backup
```

如需包含浏览器导出文件，执行：

```sh
python3 scripts/data-backup.py backup --browser /absolute/path/browser-export.json
```

私钥位于 `~/Library/Application Support/RemoteCodexManager/keys/backup-identity.txt`。
权限为 `600`。请另存离线副本；丢失私钥后无法解密。
默认备份位于同级 `backups/`。

备份包含：

- `output-journal.sqlite` 的一致性快照，不直接复制运行中的 WAL/SHM。
- Codex Portal 标题、订阅、交还、通知、连接、归档同步及任务管理会话绑定状态。
- 连接配置、手机配置、配对、本项目证书及证书私钥。
- Codex Portal 日志和显式提供的浏览器导出文件。

不包含 Codex 原生数据、登录凭据、SSH 私钥、SSH 密码、macOS 钥匙串、其他项目凭据、Cookie 或临时文件。
引用工具和授权缓存也不在备份范围。备份不是完整聊天历史。
输出日志和浏览器缓存仍可能含会话内容。

备份记录来源、时间、版本、文件摘要和缺失项。
超过 1 GiB 的加密包会生成分卷，原包保留。
备份仅存本地或指定目录，不自动调度、上传或删除历史包。

自定义路径沿用 `RCM_CONFIG`、`RCM_STATE_DIR`。
也可传入 `--config /absolute/config.json --state-dir /absolute/web-state`。
网页状态与本机输出日志分别收集。

## 浏览器数据

入口：“设置 → 浏览器数据备份”。
导出包含当前 origin 的 Codex Portal 设置、当前标签页草稿和详情缓存，不读取 Cookie。
其他浏览器、标签页和旧缓存库需分别处理。

导入时先选择身份匹配的连接，再预览覆盖范围。
按连接导入保留未选连接、全局设置和待处理发送记录。
连接集合完全一致时，可选择整份导入。
来源机器或目标身份不匹配时拒绝导入。

导出文件可能含草稿和会话内容，可用 `backup --browser` 加密保存。
恢复的缓存不获得会话控制权，也不替代网络最新状态。

## 恢复

先解密并校验到不存在的新目录：

```sh
python3 scripts/data-backup.py restore /absolute/path/backup.age.index.json --identity /absolute/path/backup-identity.txt --machine MACHINE --destination /absolute/new/restore-directory
```

此步骤不改实时数据。错误密钥、来源、格式、路径或摘要会被拒绝。
不支持自动跨机器覆盖。验证目录包含明文，使用后自行清理。

原地恢复前，结束任务并断开所有网页入口的全部连接。然后执行：

```sh
python3 scripts/restore-apply.py apply /absolute/restore-directory --entrances-disconnected
```

程序再次校验身份和空闲状态，生成恢复前备份，再进入维护模式。
它停止本项目网页和专用服务，保留旧文件及 WAL/SHM 到 `restore-history/`。
替换失败时恢复旧文件和服务。

恢复后关闭自动连接、撤销手机配对并保留证书。
浏览器数据需另行导入。Codex 原生数据不会迁移。
