# 侧边栏一致性与功能差异（2026-10-18）

对照本机 Codex Desktop 26.1013.40934、目标引擎实际协议，以及桌面工具返回的项目、分区、置顶顺序。此版本只发布侧边栏管理；以 e729d32 为基线，包含已提交的 LAN/Tailscale 手机访问修复，不包含主工作区正在开发的会话交接功能。

## 本轮实现

- `/api/sidebar` 统一返回可见会话、真实项目、当前账号分区、归属、排序偏好、完整置顶列表和操作能力。显示用只读事务读取目标机器快照；在线连接提供当前账号及本入口的实时运行状态。不会因为实时分页遗漏旧置顶会话。
- 延续交互会话过滤：内部 subagent、Guardian、exec、ambient suggestion 记录不进入侧边栏；目录名、临时哈希目录不会生成项目。保留所有底层记录。
- 兼容桌面旧项目 ID 与引擎 ID 的迁移，分区位置和项目归属分别处理。按目标机器及当前账号选择布局，不遍历其他账号来猜测当前布局。
- 读取项目/列表/按连接分组；最近活动和手动顺序；独立的置顶排序。项目活动时间从完整可见记录计算，不依赖搜索结果或已加载页。保留项目与直接会话交错顺序、置顶服务器顺序和稳定 ID 次序。
- 项目、分区展开折叠及左右方向键；展开状态按浏览器、目标机器和账号保存。搜索临时展开结果，清除搜索与刷新后恢复原折叠状态。
- 右键、Shift+F10、行尾菜单、窄屏可点击菜单；菜单支持方向键、Home/End、Esc。重命名输入支持中文 IME，失败保留输入并回到输入框。
- 支持重命名、置顶/取消置顶、置顶会话拖动与键盘上移/下移。自动排序时不允许手动排序。手动命名等待已开始的自动命名写入结束，并阻止后续自动标题覆盖。
- 已归档入口支持标题搜索、分页、阅读、恢复。归档后有撤销；已归档会话不允许继续发送。归档前核对轮次、运行状态、目标、排队输入、后台终端；运行中或核对失败时拒绝，不自动停止任务。
- 写操作全部走已核验的引擎接口；保留原有 Origin、CSRF、目标机器隔离。账号/记录版本变化时拒绝旧操作；同一入口防重复提交。超时不重发，网页重新读取实际列表供核对。
- 收到相关引擎事件时刷新，并每 15 秒核对桌面布局；菜单或编辑框打开期间不做周期刷新。断线保留当前显示并禁用写操作。

## 同步接口限制

“协议能调用成功”不足以证明桌面版同步成功。以下操作经过独立测试后发现桌面界面仍由额外的桌面状态管理，因此保留读取能力，修改菜单置灰，显示需在桌面版操作的说明。网页没有建立另一套组织状态，也没有直接改写 Codex 数据库或全局配置。

| 操作 | 当前版本行为 | 实测依据 |
| --- | --- | --- |
| 新建、重命名、删除分区 | 不开放写入 | 引擎创建成功，但桌面账号布局未加入新分区。测试分区已通过引擎删除；其中会话先移出，记录保留。 |
| 会话移动到项目/自定义分区 | 不开放写入 | 引擎归属变化未可靠体现在桌面列表；测试归属已恢复。 |
| 项目置顶、项目移动到分区、项目及分区重排、项目内会话手动重排 | 读取桌面排列；不开放写入 | 没有可同步全部桌面组织状态的目标引擎接口。 |
| 修改分组方式、全局排序偏好 | 读取桌面设置；不开放写入 | 偏好由桌面维护；网页修改会形成第二套状态。 |
| 标记已读/未读、自动标记已读 | 不开放写入；不显示未经确认的未读圆点 | 桌面使用按身份和执行主机隔离的读状态，引擎 readState 更新成功但桌面 isUnread 不变；不能把引擎回执当成桌面状态。 |
| 桌面独有的 Orbit、Agents、ChatGPT/云端项目等 | 不显示为伪项目 | 当前产品连接目标机器本地 Codex，引擎快照不提供这些云端对象。 |

折叠记忆属于网页体验状态，按需求独立于桌面保存。项目分区、归属和排序不在浏览器单独保存。

## 其余功能差异（只盘点）

优先级：P1 为高频工作流，P2 为体验完善，P3 为低频扩展。以下基于已安装基线与本轮代码检查，不代表已做这些功能的端到端验收。

| 功能 | 状态 | 已有能力与差异 | 优先级 |
| --- | --- | --- | --- |
| 文本发送、模型与思考档位、执行中补充要求 | 已支持 | 实际调用目标引擎；连接和控制状态约束、草稿保留 | P1 |
| 图片与文件附件发送 | 缺失 | 发送接口当前只构造 text；历史图片显示不等于上传发送 | P1 |
| 会话分叉、历史消息编辑、重新执行 | 缺失 | 没有对应网页入口和完整分支状态处理 | P1 |
| 全文搜索与结果定位 | 部分支持 | 侧边栏标题搜索、打开会话；没有全消息索引、匹配轮次跳转及高亮 | P1 |
| 排队消息编辑、取消、重排 | 部分支持 | 可以读取队列；没有编辑、删除、重排入口 | P1 |
| 目标管理 | 部分支持 | 可读取目标及状态；没有创建、暂停、完成等管理入口 | P2 |
| 后台终端交互 | 部分支持 | 输出阅读与停止时终止后台任务；没有终端输入、会话选择或 PTY 交互界面 | P1 |
| 文件、代码差异、产物预览 | 部分支持 | 文件变更列表、差异文本、生成图片展示/下载；没有桌面级工作区文件编辑、完整产物面板 | P2 |
| 语音 | 部分支持 / 平台限制 | 浏览器听写、预览、取消与草稿恢复；依赖浏览器权限/识别支持，不等于桌面实时语音对话 | P2 |
| 系统通知 | 部分支持 / 平台限制 | 完成/失败/待处理通知、多页去重与重新打开后补发；受浏览器权限、后台生命周期限制 | P2 |
| 未读状态一致性 | 平台限制 | 当前桌面私有读状态没有可靠的目标引擎同步通路；本轮明确禁用写入 | P1 |

## 部署方式

在独立 worktree 提交，通过 `node scripts/install-local.mjs --ref <commit>` 生成部署前加密备份，再安装到以完整提交 SHA 命名的不可变 release，核验本机 4317 健康状态。只重启网页入口，不停止目标 Codex 服务。安装流程失败会恢复旧 launchd 配置。实际部署 SHA、加密备份和安装记录位置在本轮交付消息列明。
