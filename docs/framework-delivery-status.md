完整迁移 RCM 前后端应用层到 React、TypeScript、Zustand、Vite 和 Node.js、TypeScript、Fastify。网页与手机的功能、文案、样式、布局和交互不变。保留原 CSS、存储格式、连接 ID、未知原生字段和已核实的 Codex 接口。

在既有 `refactor/framework-migration` 分支及独立 worktree 连续完成实现。期间仅执行必要针对性回归，不为小模块重复浏览器测试、重启预览或新增阶段报告。全部实现后执行类型检查、完整 npm test、构建，冻结完整候选，再统一更新 4327／4338／4339。验收完成前不合并 master，正式 4317／4318／4319、原生会话与引擎保持运行。用户最新授权：完整目标完成且验证通过后，将现有分支及工作树成果整合回原仓库 master 并提交；先核对最新 master 与其他会话改动，串行合并，不丢弃成果。此授权不表示当前已完成，也不追加正式部署或删除工作树。

统一验收重新读取实际 4317 与最新 master；先桌面，再 iPhone 390×844、DPR 3、触控，以及 844×390 横屏和 390×480 短高度。使用已授权 ego-lite。差异按基准修复，仅复验受影响范围。性能先定位原因再优化；不以提交次数推导性能。SSH 诊断有界，外部阻塞不停止其他工作。用户已明确改为仅使用浏览器设备模式验收，不再等待 iPhone 镜像。实体软键盘、候选窗、系统选区与系统剪贴板未实测，保留能力边界，不作为本轮阻塞。
