## 目标与执行顺序

完整迁移 RCM 前后端应用层到 React、TypeScript、Zustand、Vite 和 Node.js、TypeScript、Fastify。网页与手机的功能、文案、样式、布局和交互不变。保留原 CSS、存储格式、连接 ID、未知原生字段和已核实的 Codex 接口。

在既有 `refactor/framework-migration` 分支及独立 worktree 连续完成实现。期间仅执行必要针对性回归，不为小模块重复浏览器测试、重启预览或新增阶段报告。全部实现后执行类型检查、完整 npm test、构建，冻结完整候选，再统一更新 4327／4338／4339。正式 4317／4318／4319、master、原生会话与引擎保持运行，不合并或正式部署。

统一验收重新读取实际 4317 与最新 master；先桌面，再 iPhone 390×844、DPR 3、触控，以及 844×390 横屏和 390×480 短高度。使用已授权 ego-lite。差异按基准修复，仅复验受影响范围。性能先定位原因再优化；不以提交次数推导性能。SSH 诊断有界，外部阻塞不停止其他工作。用户已明确改为仅使用浏览器设备模式验收，不再等待 iPhone 镜像。实体软键盘、候选窗、系统选区与系统剪贴板未实测，保留能力边界，不作为本轮阻塞。

## 候选修复与检查结果

- 类型检查、完整 `npm test` 和生产构建通过：910 项 Node、74 项 Python，无失败、跳过或取消。构建使用新目录；未执行正式安装。
- 手机布局中的说明节点原先晚于按钮搬移创建，触发 React `NotFoundError`。现已在移动布局搬移前创建稳定节点，保留 DOM 文案、CSS 和搬移算法。三种手机尺寸复验通过。
- 手机配对 IIFE 原先遗留 `process.env.NODE_ENV`，浏览器报错并停留在检查状态。构建现显式替换生产环境值；新增无 Node 全局变量的浏览器产物回归。配对脚本从 651603 字节降至 224270 字节，这是产物体积变化，不等同端到端性能提升。
- 已增加等值状态发布检查，避免控件说明、运行提示、交还、容量重试及批注在内容不变时重复同步更新。实际变化保持原来的同步语义。
- CSS 共 12 个文件与正式基准逐字节一致，加载顺序一致；React 初始 Shell 与原始结构对照无差异。消息解析与节点协调算法保留。

## 性能实测与剩余定位

同机、同虚构数据、相同浏览器和设备参数，新旧入口交替测量。数值为毫秒；启动每入口每设备 4 次，输入每入口每设备 20 个样本，长会话更新 10 个样本，切换 8 个样本。小样本不能推导普遍提速。

| 指标 | 桌面：基准 → 候选 | 手机：基准 → 候选 |
| --- | --- | --- |
| 启动脚本累计耗时范围 | 51.0–61.0 → 75.3–82.5 | 61.9–64.4 → 75.9–79.3 |
| 输入处理 p50 | 4.30 → 4.00 | 5.05 → 3.95 |
| 输入显示 p50 | 10.70 → 8.85 | 8.95 → 8.00 |
| 输入显示 p95 | 15.2 → 17.5 | 17.2 → 16.7 |
| 200 轮尾部更新 DOM p50 | 88.65 → 88.35 | 88.40 → 87.75 |
| 200 轮尾部更新 DOM p95 | 89.5 → 89.5 | 90.3 → 768.1 |
| 会话切换 p50（包含完成后两帧） | 43.40 → 59.85 | 67.40 → 75.70 |
| 会话切换 p95 | 49.9 → 66.8 | 76.1 → 95.4 |

输入样本无 API 请求，原有节点保留。长会话正常样本无额外请求；候选手机有一次 768.1 ms 异常，同时出现一次请求，不能删除该样本或标为通过。对应长帧记录约 699.8 ms、无脚本条目、blockingDuration 为 0，尚不足以证明具体原因。

启动原始堆占用桌面约 88–97 MiB 对 95–100 MiB，手机约 88 MiB 对 91 MiB；包含浏览器扩展和采样开销，不是独立应用保留内存。启动请求计数受现有 pageshow 刷新时序影响，常见 16 或 20；未将请求竞态隐去。加载时刻波动较大，不据此宣称首屏提速。

切换 CPU 采样发现 React DevTools 扩展在提交后调用 `measureHostInstance`，增加几何读取。仅在虚构数据页临时排除该扩展的提交回调后，桌面切换 p50 为 51.35 → 43.20，手机为 70.25 → 78.50。桌面差异没有稳定复现，手机差异尚未排除；此实验不修改应用或浏览器全局设置，也不替代原始验收结果。

进一步在虚构数据页排除启动阶段的扩展提交观测后，脚本累计耗时为：桌面基准 45.3–68.5、候选 72.7–75.3；手机基准 60.5–62.9、候选 69.4–74.9。扩展只能解释部分开销，剩余启动差异仍存在，不能以观测污染为由认定性能通过。

隔离状态接口的两组 HTTP 测量（每入口每组 500 次）p50：基准 0.196／0.115，候选 0.119／0.130；p95：基准 0.426／0.184，候选 0.242／0.242。仅表示模拟传输层，不表示原生任务或真实网络性能改善。
