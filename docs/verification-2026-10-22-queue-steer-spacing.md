# 排队、引导与正文留白验收

## 核实依据

- [OpenAI 官方 Queue 与 Steer 说明](https://developers.openai.com/blog/mastering-codex-remote-for-engineering)：Queue 等待当前回复结束；Steer 引导当前执行。
- [官方快捷键入口](https://learn.chatgpt.com/docs/reference/commands)没有列出此处的默认发送组合键。因此只读核对了本机当前桌面资源：默认 Enter 发送时，运行中使用 Command/Control+Enter 执行另一种跟进方式。未修改桌面资源或配置。
- 从连接配置读取 Codex 二进制路径，执行 `app-server generate-json-schema --experimental`。核实 `thread/queue/add`、`list`、`delete`、`start` 以及 `turn/steer.clientUserMessageId`。协议校验新增 `queueWrite` 能力；协议不支持时禁用写入。

## 修改

- 普通网页控制的主会话：手机触控默认追加；桌面默认排队。桌面 Enter 使用默认行为，Command/Control+Enter 引导，Shift+Enter 换行；空闲时正常发送。保留输入法组合状态防护。
- 输入框上方展示原生队列。每项提供引导和删除；任务已结束时提供立即发送。输入框也有直接引导按钮。
- 排队存储、顺序、消费和自动执行均由原生引擎负责。RCM 不保存业务队列副本，不增加轮询、任务调度或完成事件启动器。沿用现有队列读取与变更事件刷新。
- 转为引导时读取原生队列内容及消息标识，成功后删除原队列项。引导成功而删除失败时，重试仅删除，避免重复引导。超时结果未知时禁止同一队列项自动重放。连接切换后不继续发送旧连接请求。
- 短会话正文靠近输入框。删除只会增加、不回收的滚动锚点底部占位。长内容保持滚动；历史定位超出实际内容高度时自然限制位置。
- 队列列表只在数据或状态变化时重绘。输入过程中不会反复序列化队列图片的 Base64。短屏时队列可收缩并独立滚动。

## 验证

### 原生服务

通过配置中的本机二进制启动独立 app-server 连接，使用专用测试会话和全新临时工作目录。测试内容只要求短暂等待及回复固定文本，不读写业务文件。

- 当前轮次运行时调用 queue/add，list 返回排队项。
- 当前轮次结束后，原生引擎自动执行下一条；收到下一轮完成事件，队列为空。没有由 RCM 调用 queue/start 推进。
- 第二个完整测试中，对队列项调用 turn/steer，使用原生 clientUserMessageId；收到当前 turnId，queue/delete 返回 deleted=true，队列为空。
- 两个完整测试会话完成后通过原生接口退订并归档。最初探测曾在原生已自动消费后调用 queue/start，返回“queued submission not found”；此结果促使实现取消任何客户端自动启动逻辑。该探测未操作业务会话。

### 浏览器模拟

使用 ego-browser（ego-lite）实际页面与全 API 模拟数据。没有通过模拟页面向真实引擎提交内容。

- 桌面：Enter 命中 queue-add；队列引导命中 queue-steer；删除命中 queue-delete；Command+Enter 和引导按钮命中 steer。响应后草稿清空；Shift+Enter 换行；模拟中文组合输入未误发送。
- 留白：1440×1000 短会话，对比原来顶部布局与新布局，最后正文到运行提示的间距由 708px 降至 32px。该值为一次布局测量，不是所有设备的固定间距。已检查截图。
- iPhone 12/14 共用 390×844、横屏 844×390；iPhone 17 为 402×874；补充 390×500 可视高度缩小。均为 DPR 3、mobile=true、5 点触控模拟。使用真实触控事件点击发送，各场景均调用 steer，没有页面横向溢出或脚本错误。
- 横屏 844×390 存在 12 条队列消息时，队列可滚动，发送按钮底部位于 377px，中心命中按钮，未裁切。已检查截图。
- 单元与 HTTP 测试覆盖原生参数、身份保持、无应用调度、原生拒绝、队列消失、清理失败仅重试删除、连接变化、未知结果防重放、CSRF 和入口分流。

最终回归：419 项 Node 测试和 69 项 Python 测试通过。另从暂存树导出独立目录复核，排除其他会话尚未提交的导航和滚动条修改。代码版本及部署状态见交付补记。

## 范围与限制

普通网页控制的主会话支持本次排队流程。桌面托管入口和侧边聊天沿用既有能力，没有把未核实的排队接口标成可用。队列暂不提供编辑和重排，保持原生返回顺序；排队沿用会话原生模型与执行设置。

实体 iPhone、真实中文候选窗、系统剪贴板菜单和软键盘未测试。横屏及缩短高度属于浏览器设备模拟。原生验证使用文字输入；图片与技能结构经适配复用，未进行真实图片排队消耗测试。尚未部署时不能以预览通过代替上线。
