# 初始轮次总数验收

版本以包含本记录的功能提交为准。

## 改动与依据

依据用户确认及既有[轮次导航验收](verification-2026-10-22-turn-navigation.md)，在刻度上方显示“共 N 轮”。手机轮次入口与目录标题显示相同总数。本次未重新核验 Codex 桌面视觉，不声称像素级一致。

沿用现有只读历史读取，在同一 SQLite 读取事务内按 thread_id 统计 thread_turns。详情首屏与桌面托管详情透传 totalTurns，不读取全部正文、不新增分页请求、不修改 Codex 原生数据。总数随详情刷新更新。原生 RPC 回退若未返回总数且仍有历史分页，显示“总数未知”；历史完整时可用已加载轮数。

## 验证

- 全量 npm test：427 项 Node、69 项 Python 通过。
- 回归覆盖首屏预览仅含 1 轮但总数为 7、翻页仍为 7、其他空会话为 0，以及未知总数不误报为已加载数量。
- ego-browser 独立 4327 预览，业务接口由现有测试样本拦截。首次加载 16 轮，显示共 21 轮，历史分页请求为 0。桌面键盘方向键、可见焦点和页面无横向溢出通过，截图已检查。
- iPhone 12 设备参数：390×844、DPR 3、mobile=true、触控模拟开启。确认参数生效后，通过触控事件打开更多菜单及轮次目录。入口和目录均显示共 21 轮，无页面横向溢出、无 JavaScript 错误，Escape 可关闭目录。未测试实体设备、真实软键盘或输入法；本次不改输入流程。
- 手机检查首次跨工具调用时设备模拟被浏览器重置，导致等待超时；在同一次调用中重新启用并确认参数后，触控检查通过。
- 真实本机原生库只读性能采样：379 轮会话，COUNT 使用 idx_thread_turns_page 覆盖索引。100 次查询中位 0.026ms，最大 0.282ms。仅代表本机热查询，不代表 SSH 全链路或所有规模最优。
