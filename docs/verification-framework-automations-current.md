## 版本与环境

正式 4317 为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`，候选 4327 为 `41605a7075e216ec7a743ab6605cb10a138d34ff`。本轮重新读取版本接口并 fetch origin/master；master 为 `0a3ee2ac8c97cafa89870d78323cf0dfc2f3692e`，相对正式版本仅有四行文档差异。候选静态夹具的资源摘要与干净构建相同：`ec11c5735025907428ff45249d6f1eea683c5fc5ae740c174e3787bd02bae65b`。

使用同一 Ego Lite 空间及页面，保留正常扩展和 React 调试回调。桌面 1480×747、DPR 2、无触控；iPhone 12 模式 390×844、844×390、390×480、DPR 3、触控开启。每次导航后重新设置设备参数，全部样本核对实际视口、DPR 和触控能力。

测试入口只提供虚构任务、会话和模拟接口，不连接原生引擎。固定任务观察时间与运行时间，避免采样时钟改变展示文案。列表筛选使用输入控件和 select；桌面按钮使用鼠标，手机按钮使用中心命中检查后的触控。菜单切换与 Escape 使用浏览器键盘，不代表实体手机软键盘。

本轮没有发现候选独有差异，因此没有修改产品代码，也没有重复应用测试、构建或重启。报告与汇总文档在重构分支提交；master 和正式服务保持。

本轮覆盖上述两项虚构任务的展示与管理入口，不证明真实原生任务执行、未绑定目标的选择器全部状态、大列表性能或实体手机系统操作通过。更早的选择器专项见[历史任务迁移报告](verification-framework-automations.md)，不可将历史候选证据写成本轮重新验证。整体性能、真实 SSH 与当前候选全量集成仍未完成。
