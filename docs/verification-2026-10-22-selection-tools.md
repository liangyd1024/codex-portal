# 正文选区、注释、侧边聊天和图文剪贴板

## 变更范围

- 正文选区提供“添加到对话”和“在侧边聊天中提问”。注释包含原文、可选评论、编号标记和输入区计数；可展开编辑或移除。草稿按连接及会话保存。
- 注释按已核实的桌面 `Response annotations` 格式发送。用户输入和被引用原文保持原样。原始历史消息不改写。
- 侧边聊天通过原生 `thread/fork`、`ephemeral: true` 和 `excludeTurns: true` 创建。继承源会话历史，使用桌面侧边聊天的任务隔离指令。发送仍使用原生 `turn/start`，停止使用原生中断。关闭面板只隐藏，不中断任务。
- 临时会话不支持原生历史分页。服务端仅缓存原生通知用于展示，不保存独立任务状态或执行循环。引擎连接变化后拒绝将缓存当作可继续的会话。
- 输入区全选同时选择文字和图片。复制/剪切使用系统剪贴板的纯文字与 HTML 表示，支持多张图片和跨输入区粘贴。只选择部分文字时沿用系统行为。失败和图片仍在处理时保留草稿。

## 验证

- Node 行为测试覆盖剪贴板转义与图片格式、注释原文、原生完成事件合并、临时分叉参数、创建幂等、连接变化和不确定结果不重放。
- 全量 `npm test`：405 项 Node、69 项 Python 通过。所有测试使用现有隔离目录约定。
- ego-browser 模拟验证：添加注释、评论输入、原草稿保留；真实系统快捷键全选、剪切、粘贴恢复文字和图片，并在另一会话粘贴成功；侧边聊天打开和选区携带；发送失败保留草稿与选区。
- 390px × 844px 页面和侧边聊天没有页面横向溢出。窄屏侧边聊天使用覆盖面板，具有关闭、Escape 和 Tab 焦点范围处理。
- 合成 composition/Enter 不触发侧边聊天发送。未验证真实中文输入法候选窗、实体手机长按菜单和软键盘。
- 真实原生引擎：独立源会话记录随机口令，临时分叉正确回答口令，验证继承上下文。未操作既有业务会话。
- 真实开发预览 HTTP 接口：创建独立源会话、临时分叉、发送和读取原生完成回复通过。源测试会话已通过原生接口归档。

## 性能

选区只检查当前消息；高亮使用 CSS Highlights，不修改正文 DOM。滚动标记定位合并到动画帧。侧边聊天复用消息缓存和 DOM reconciliation，不以轮询采集输出。

浏览器模拟同一轮连续 100 个流式增量，原有完整回复节点保持同一 DOM 身份。该样本从注入事件到两次动画帧后读取约 129 ms，包含浏览器调度；不作为网络响应时间或性能最优的证明。

## 差异和边界

- 网页重新加载后不恢复临时聊天入口；主会话注释和图文草稿仍保留。面板关闭后可在同一页面重新打开。
- 侧边聊天当前支持文字和选中文本，图片整体剪切粘贴适用于主输入区。语音评论、与桌面同步未发送注释未接入。
- 跨应用接收 HTML 图片的能力取决于接收应用。当前没有承诺所有外部应用都能保留图片。
- SSH 目标和桌面托管会话的注释发送尚未完成真实验证。桌面适配仍发送完整原生文本格式，不修改其协议或数据库。
- 运行中的临时聊天没有被自动停止。未确认的发送结果锁定发送，提供重新读取和核对后继续入口。
