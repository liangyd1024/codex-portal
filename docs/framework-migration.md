## 已实现范围

- 锁定 React、TypeScript、Zustand、Vite 和 Fastify 的直接版本及依赖锁文件。

- 模型与思考档位 select，以及发送／引导／停止按钮，已由 React 管理各自节点、视图和事件。React 挂载原页面结构，诊断、刷新提示、模型及连接选项、排队消息、手机访问、系统更新、浏览器备份、通知、连接设置、账号标签及连接指示使用 React 渲染。页面顶层状态通过 Zustand 保存；原有草稿和原生数据保持对象身份。

## 开发操作

使用 Node.js 22.12 或更高版本（Vite 8 的运行要求）。在此重构分支的独立工作树内执行：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test
npm run start:preview -- --mobile
```

`npm test` 会先构建，再执行 Node 和 Python 测试。不需要再次构建。
禁止用 `npm install` 或 `npm run install` 初始化开发环境；原安装生命周期会部署正式服务。
启动前检查 4327、4338、4339 的占用原因，不自动换端口，不停止正式进程。

默认创建新的私有临时状态目录。重启同一验收实例时，可将 `RCM_PREVIEW_ROOT` 设为已有验收目录的绝对路径。目录必须带有本程序生成的验收标记；不能复用其他非空目录。

手机需要信任本次验收独立生成的 CA，并使用验收页面生成的配对码。证书和配对数据不能复制到正式手机目录。真实操作只针对专用测试会话，不同时从两个入口控制同一会话。
