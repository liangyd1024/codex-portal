# 未回答问题保留与紧凑布局

## 行为与依据

用户反馈：异步问题显示后随助手结束而消失；单题内容过高，需要滚动。

复核已有问题协议记录，并只读核对已安装客户端的 `app-initial-c95ddb62696e.js` 与 `app-primary-58a09006cc0c.js`。原生结构化回答保留 questionItemId、question、answer，通过 send-now 提交。客户端运行中提醒以 inProgress 为条件；本次按用户要求扩展网页的未回答卡片展示期限，不声称完全复刻桌面提醒行为。

- 正常完成的轮次保留未回答问题。已接受的结构化回答移除对应问题；关闭会话、失败或中断不保留活动提示。刷新从原生历史重建，不建立另一份业务状态。
- 回答时复核原问题、连接、控制权及完整答案。有活动轮次时使用原生 turn/steer；空闲时复用既有 message → turn/start。保留并发防重、结果未知禁止重放。运行状态发生竞争时保留答案并报错，不自动重试执行。
- 不新增轮询。重连恢复读取最近 5 轮完整历史一次；更旧问题的自动恢复范围仍受分页限制。
- 当前会话问题卡片不重复显示会话名。压缩标题、选项、输入区留白，输入框默认一行，可调整高度。正文与输入保留 16px。手机选项及收起按钮至少 44px，操作按钮至少 48px。
- 提高问题区域的可用高度。单题完整显示；多题、长题、横屏及高度不足时仍允许滚动。

## 验证

- `npm test`：424 项 Node 测试、69 项 Python 测试通过。
- 新增回归覆盖：轮次完成后保留、空闲回答只启动一次原生轮次、向后续活动轮次回答、跨轮次回答清除旧题、重连恢复、发送结果未知不重放。
- 4327 独立状态预览。ego-browser 隔离 API 模拟，没有向真实会话提交回答。
- 桌面 1280×900：单题三选项加文字回答，问题容器 clientHeight/scrollHeight 均为 349px，无横向溢出。截图已查看。
- iPhone 12 模拟：390×844、DPR 3、mobile=true、5 点触控。单题容器 clientHeight/scrollHeight 均为 391px，无内部滚动及页面横向溢出。触控选择通过，截图已查看。
- 同一设备横屏 844×390、高度缩小 390×550：无横向溢出，问题区保留纵向滚动。高度缩小不等同真实软键盘验证。
- 桌面键盘焦点可见；中文文本输入、全选、剪切与粘贴通过；合成 composition 期间提交不发送。
- 模拟回答失败保留草稿；进行中禁用发送；成功后移除卡片；断线禁用提交；刷新保留草稿。
- 没有新增每帧计算或定时请求。布局以 CSS 完成。未进行 CPU/内存专项基准，不声称性能最优。
- 未验证实体手机选区、剪贴板菜单、真实软键盘及中文候选窗。未进行真实引擎或 SSH 回答闭环；原生调用由既有协议证据和本次适配测试覆盖。
