# 网页字体对齐

## 改动与依据

参照用户提供的桌面/网页截图，并只读检查本机 ChatGPT.app/Contents/Resources/app.asar 中 Codex 的 app-shared CSS：默认字体为 -apple-system、BlinkMacSystemFont、Segoe UI、sans-serif，正文允许独立字体覆盖，leading-relaxed 为 1.625。桌面实际字号偏好、缩放及正文字体覆盖未读取，不能声称像素级一致。

网页统一系统字体变量，去掉根节点与正文之间不一致的 Inter 优先级；正文与输入框 14px → 16px、行距 1.625；表格 13px → 14px；代码块 12px → 14px、行内代码 .92em；主要侧栏文字 14px，小标题不再小于正文。保留用户气泡配色和字重、现有布局宽度及消息原文。
