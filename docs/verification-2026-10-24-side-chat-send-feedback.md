# 侧边聊天发送回显

## 原因与修改

用户反馈发送后的输入迟迟没有显示，并要求与正文交互一致。依据用户截图、正文当前发送实现及[发送反馈验收](verification-2026-10-22-send-feedback.md)、[侧边聊天交互验收](verification-2026-10-22-side-chat-parity.md)。

正文在请求前建立发送回执；侧边聊天原先只渲染原生 turns，需要等待 HTTP 返回完整轮次或原生事件。运行中补充若只返回 turnId，显示会继续等待原生消息。侧边聊天现复用正文的 createSendReceipts 和状态文案，在请求发出前显示输入、选文及图片。收到原生消息后匹配去重。回执只在网页内存中展示，不写入原生历史或消息缓存。

失败时保留草稿；断网或服务端结果不明确时显示待确认，并阻止直接重复发送。按临时会话对象隔离回执，迟到响应不覆盖新会话草稿。回执节点复用 RenderCache，不新增轮询或网络请求。不改变原生执行速度。

## 验证范围

- 相关 21 项测试通过。包含实际 submit 函数的慢响应、重复提交、仅返回 turnId、事件早于响应、明确拒绝、503 结果不明确和切换会话回归。共用回执与侧边缓存测试覆盖部分原生快照和原输入保留。
- ego-browser 组件验收加载实际前端模块和公共样式，API 完全模拟，消息渲染器只实现用户消息。未向真实业务会话发送消息。开发预览端口由另一项目占用，本轮没有启动独立预览，也没有中断已有预览。
- 桌面 1440×900：键盘发送、慢请求立即显示、事件先到去重、运行中补充、重复同文输入、失败与断网草稿保留、迟到响应隔离通过。
- iPhone 12：390×844、DPR 3、mobile、触控和 coarse pointer 已核对。触控发送立即显示，Enter 换行，合成中文组合输入不发送，全选、剪切及粘贴中文通过。重复提交被阻止。补测 844×390 横屏、390×500 高度缩小，无页面横向溢出。
- 最终公共样式顺序核对后重新查看桌面及 390×844 截图。黑底白字气泡及 12px 回执沿用正文样式；本轮没有修改 CSS。
- 本机合成组件中，从调用发送到回执 DOM 插入约 0.7–1.5 ms，仅为同步执行样本，不包含屏幕绘制或真实网络耗时，不代表所有设备性能。新增网络请求为 0。

完整回归结果与部署版本见后续交付记录。首次共享工作区并发回归出现停止按钮测试源码截取失败、事件流分块断言失败。其他会话随后提交停止按钮测试适配。本轮不修改无关测试；事件流相关测试单独复测通过，完整测试继续核验。

实体手机、真实软键盘、系统中文候选窗及剪贴板菜单未实测。真实原生发送耗时、图片推理和插件执行未验证。组件验收不等于正式网页上线。
