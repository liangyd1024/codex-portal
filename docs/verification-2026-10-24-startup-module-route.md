# 工作台启动模块路由修复

## 原因与修改

正式网页能返回 HTML，但入口模块依赖的 `/process-summary.js` 未注册到静态资源白名单，HTTP 返回 404。模块依赖图加载失败，工作台显示通用加载失败提示。

补齐该模块的静态路由。沿用已有缓存、压缩、访问验证及 MIME 类型处理。新增 HTTP 回归测试，从 bootstrap 入口递归检查相对模块导入，确认全部返回 200 和 JavaScript 类型。测试在修复前复现 404，在修复后通过。

## 验证

- 服务端与启动恢复相关测试：23 项通过。
- 完整测试第一次运行：手机 SSE 撤销测试失败，读取到了未消费的事件；未修改该测试或业务逻辑。
- 完整复核：603 项 Node 测试及 70 项 Python 测试通过。
- 模块图 HTTP 检查约 47ms，仅为测试环境单次样本，不代表正式性能基准。生产仅增加静态路由映射，没有新增轮询和 API 请求。
- 真实正式网页修复前已通过浏览器复现模块 404。
- 开发预览端口被另一个项目占用，未停止该服务，未改用其他端口。预览浏览器验证未执行。
- 本次未修改布局或输入流程，未执行移动设备模式、实体手机或中文输入验证。

本记录随修复提交保存。正式部署结果另行补记。
