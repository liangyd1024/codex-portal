# 会话控制状态类型迁移验收

## 范围与版本

本轮在 `refactor/framework-migration` 中将主控制器的 13 个会话上下文函数迁入 `src/web/services/session-context.ts`。包括连接是否可用、协议能力、会话标签、控制归属、交还状态、快照历史及运行状态。工厂持有原 state 引用，每次调用读取当前值，不复制原生记录。

正式 4317 的对照版本为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`。重新 fetch 后的 `origin/master` 为 `0a3ee2ac8c97cafa89870d78323cf0dfc2f3692e`，相对正式版本只有四行文档差异。隔离构建资源为 `8cd1f0debd199b725cf32850825833d014e783add7d6594fad4da214d5e0e61c`。应用提交为 `3e37b0b817c3e370ae86d9bd777d1b528192f3bc`。该提交的干净构建 dirty=false，资源哈希与上述隔离验收构建一致。

原状态文案表仅移到工厂创建之前。13 个函数经过 TypeScript 去类型及 AST 格式化后，与迁移前函数逐个完全一致。CSS、节点结构、公开请求、原生执行语义和存储格式未改动。此检查不能代替运行验收。

按用户要求再次执行配置驱动的严格 SSH 只读身份检查，仍约 15 秒连接超时，未进入身份验证。没有改动 SSH 配置或停止目标服务。
