# 手机侧栏滚动约束

代码提交：`7ccf8b87aee539fa7ac6782993e5127f92646b37`。

## 原因与改动

正式页面在手机设备模式下，列表可视宽度为 315px，滚动内容宽度为 318px。横向偏移可达到 3px，并显示横向滚动条。侧栏本身宽度固定。

手机列表改为只允许纵向滚动，限制滚动链和边界回弹，保留双指缩放。增加两侧各 3px 内边距，为焦点轮廓留出空间。未修改原生排序、项目和会话数据。

交互参考已有手机验收记录 `verification-2026-10-18-mobile.md` 中的抽屉、单列表滚动及菜单操作。未声称对齐原生手机客户端的全部交互。

开发端口被其他项目使用，未启动或替换开发预览服务。隔离测试页使用仓库的 mobile-browser 模拟数据，API 请求由 fixture 拦截。通过浏览器 CSS 调试接口替换该测试页的移动样式表，验证工作区改动。未修改正式服务资源或原生业务数据。早期内联样式预览被页面策略阻止，不计为通过；以下结果来自替换样式表后的实际计算样式。
