# 轮次导航重复文字写入检查

代码提交 `d2e5c6c`。正式基准 `227dbfe`，候选资源 `a4497cef6607ff2c574391493203782ce58adba18a1b53edba252c1c8b8f70a8`。本轮只修改重构分支的轮次导航文字更新，不调整样式、操作入口、读取顺序或原生会话语义。

## 定位与修改

侧栏重复刷新 CPU 采样中，轮次导航 syncLoad 的自身采样约 1439 ms，整段约 7495 ms；该值含采样干扰，只用于定位。另有输入框测量和正常 React 调试扩展开销，本轮未关闭扩展。

syncLoad 对反馈、加载按钮、轮次数、入口及目录标题反复赋值 textContent，内容相同时也会替换文本节点。候选只在文字不同的时候赋值，状态变化仍同步更新。没有跳过整个轮次刷新、改变定时器或删减内容。

相关 20 项轮次导航测试覆盖自动读取、取消、重试、失败文案和目录读取边界。完整 848 Node／74 Python、类型检查、构建通过。

## 重复刷新测量

同一 ego-lite 页面，侧栏可见、两个分组展开、两条会话。桌面 1480×747／DPR 2／无触控，iPhone 12 390×844／DPR 3／触控 1。按旧／新／新／旧排列，各四组，每组 65 次去除前五次，共 480 个有效耗时样本。

MutationObserver 观察五处文字节点。每组旧版记录 1320 次变更，候选为 0；观察计数包含五次预热。每次仍只有一次侧栏快照和一次活动读取，无发送请求、页面异常或横向溢出。该结果证明重复文字写入减少，不代表完整刷新或整个系统不再更新 DOM。

| --- | --- | --- |
| 桌面 | 12.00／40.85、2.40／10.80 ms | 12.10／35.70、2.95／10.05 ms |
| 手机 | 13.95／52.05、16.05／54.25 ms | 15.90／41.75、10.80／31.05 ms |

帧后时间包括刷新完成、浏览器调度与布局读取。重复组之间仍有大幅波动，不能据此宣称整体性能通过或性能最优。首轮侧栏刷新差异继续保留。

## 行为复验

桌面 1480×747，以及 iPhone 模式 390×844、844×390、390×480，对照正式源码加载相同的隔离历史数据。分别延迟成功和 409 拒绝回执，在等待期间切到另一会话，比较旧响应返回前、返回后及回到原会话三个状态。共 16 个流程／8 对、24 对状态比较一致。包含五处导航文字、标题、完整轮次 ID、滚动值、历史请求次数、草稿、触控日志及页面异常。各流程当前会话在旧响应返回前后完全相同；回到原会话仍保留草稿。无异常或横向溢出。

手机按钮使用触控。短高度测试先聚焦目标，将其滚入视口；这不是实体手指滚动验证。初轮脚本没有处理抽屉下方目标，后续又遇到搜索刷新期间节点暂时移除和定位不稳定，均在基准或隔离候选中保留原始失败记录。检查页面后，改为等待搜索完成、节点稳定，再聚焦并触控。没有因此修改产品布局、延迟策略或会话操作。最终完成所有新旧流程；后续补跑均记录实际视口、DPR 和触控点数。初始桌面及竖屏成功组记录了设备设置，但未单独保存实际参数字段，范围如实保留。
