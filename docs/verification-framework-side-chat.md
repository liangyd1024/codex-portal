# 侧聊 React 迁移与对照验收

## 范围与版本

实现提交：`00a3ec9`。正式基准：`227dbfe`。本轮复核 `origin/master` 相对正式只增加四行验收文档，没有产品差异。所有修改仅在框架迁移分支，正式服务未部署。

侧聊面板、恢复按钮、选文片段、模型控件、输入表单结构及重新打开按钮迁入 React/TypeScript。Zustand 保存视图状态。组件内适配独占可用属性与原生 option 子树，避免禁用状态更新改变焦点。侧聊附件直接位于同一 React 表单树中。

消息正文继续使用原解析、缓存和节点协调。侧聊生命周期、原生输入协调仍在 JavaScript，主控制器迁移也未完成。未改变 CSS、接口、持久化格式或原生执行语义。

## 验证与性能

提交前类型检查通过，完整测试为 820 项 Node、74 项 Python，全部通过。旧侧聊测试调整为检查视图数据，仍有源码函数提取，不声称所有结构耦合测试已消除。

输入性能对照上一版迁移资源 `ed11899a` 与本候选：四张侧聊附件和一张主聊天附件，桌面与手机按 ABBA 顺序采样，共 2,000 个有效样本。测量输入事件到强制布局。桌面组中位数旧版为 2.3–2.5 ms，新版 2.2–2.4 ms；手机旧版 2.3–3.7 ms，新版 2.2–2.3 ms。未观察到本轮稳定退化；该样本不能证明全系统提速，也不能替代与 master 的完整性能验收。
