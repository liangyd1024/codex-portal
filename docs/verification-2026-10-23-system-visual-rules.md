# 系统视觉规则与目标栏、引导按钮

## 原因与修改

用户要求整个系统采用一致规则，并指出目标栏灰边框及引导按钮默认灰底。原目标栏位于 composer 外，使用全局结构分隔线变量；输入框黑色变量只在局部作用域生效。引导按钮缺少完整组件样式。

AGENTS.md 现约束所有页面与组件：统一字体、交互边框、配色及按钮层级；区分结构分隔线与交互边框；参考原生交互时不得另起视觉风格；验收须检查计算样式和相邻组件。公共样式增加 --control-* 与 --panel-radius。目标栏和输入框共用黑色细边框、白底及 18px 圆角。目标操作图标改为黑色。引导按钮显式使用白底黑字、黑边框、8px 圆角，保留浅灰悬停及禁用反馈。

规则是全系统规范；本次代码范围为截图中的目标栏、输入框及引导按钮，没有重做全部旧页面，不宣称全系统存量界面均已验收。

## 验证

- 完整 npm test：462 项 Node、69 项 Python 通过。仅样式与文档变更，没有新增重复实现的测试。
- ego-browser 独立 4327 预览、全新状态目录。原端口占用进程自行退出后才启动；没有停止其他会话服务。浏览器交互通过模拟接口，无真实任务操作。
- 桌面 1440×900：计算样式确认目标栏及输入框为 1px 黑边、白底、18px 圆角；引导默认白底黑边，悬停浅灰，键盘 Tab 焦点为 2px 黑色实线，空输入禁用。截图并排核对通过。
- iPhone 12/14 共用 390×844、DPR 3、5 触点，启用移动视口和触控，执行前核对参数；触控暂停目标通过。目标栏保持黑边，无横向溢出。未实测实体设备、真实软键盘与中文候选窗；未修改输入事件。
- 浏览器重新加载时首次夹具未保持，曾只读显示真实预览首页，未操作真实会话；重新注入夹具后完成后续验收。
- 无新增请求、轮询、计时器或依赖；只新增常量样式变量与局部选择器。未测 CPU、内存，不声称性能最优。
