# 轮次加载完成后显示

按用户提供的截图与指示，轮次历史在后台读取时隐藏轮数、刻度、箭头和手机轮次入口。全部读取完成后显示总轮数与刻度。去掉进度文案；失败或取消后只保留重试入口。正文预留间距不随加载状态变化，避免完成时改变正文宽度。

沿用现有分页和取消逻辑，不新增请求或轮询。隐藏部分目录，不向用户展示不完整计数；索引扫描与历史传输量未优化，不声称加载提速。

## 验证

- npm test：659 项 Node 测试及 72 项 Python 测试通过。覆盖加载期间空文案与隐藏、失败重试、取消、完整计数。
- ego-browser 隔离组件验收：读取一页时导航及手机入口均隐藏；完成后显示“共 1 轮”和一个刻度。未产生额外分页请求。
- iPhone 12 设备模式：390×844、DPR 3、mobile=true、触控模拟开启；核对实际视口、像素比、触点数。加载完成后触控打开目录，标题与条目正常，无横向溢出。桌面及手机截图已检查。
- 组件使用当前模块和样式的独立样例，未启动完整开发预览。未验证实体手机与软键盘；输入流程未变更。
