# SSE 连接协调类型迁移

## 范围与基准

正式 4317 版本为 `227dbfe93ee88718c2437f7b7c7b119570a720a6`。本轮重新 fetch 后，origin/master 仍为 `0a3ee2a`，相对正式版本只有四行部署文档变化。对照使用正式版本的原始前端源码。

本次从 `2402704` 开始，将 app.js 的 setupEvents 迁入严格 TypeScript 服务 `src/web/services/event-connection.ts`。主控制器仍提供当前连接 URL、原生 EventSource、侧聊和视图上报依赖。保留回调顺序、恢复条件、错误分类和消息对象，未修改 CSS、DOM、存储键或公开接口。

仅 system/update 沿用来源校验。旧流的 open/error 回调行为仍与基准一致，不在本次迁移中新增连接策略。关闭旧流仍由原有调用方负责。

- 五项行为测试覆盖首次连接、重复 open、断流恢复、视图上报与恢复分别失败、命名事件与普通事件原对象透传、旧流更新通知忽略、未知字段，以及替换连接后的既有回调行为。
- 从正式提交提取完整 setupEvents 函数，执行同一组五项断言。基准使用 threadViewReport=null，通过外部属性 setter 观察清空动作；未改写被提取函数。两组均通过。
- 类型检查、独立构建通过。完整 npm test：896 项 Node、74 项 Python 通过。
- 构建资源指纹：`c7582f6cb96177f27a331a7ae64c3e6203808169c5cbbdc026646c81141dc48d`。浏览器验收针对该构建，不沿用旧候选结果。

Ego Lite 在同一个验收空间中顺序操作静态隔离入口。EventSource 使用真实浏览器网络流，控制端只关闭验收流，不实例化 Manager 或连接原生引擎。两版各在以下四种模式执行三次断流及恢复，共 24 次恢复、12 组配对：

| 模式 | CSS 视口 | DPR | 触控 |
| --- | --- | --- | --- |
| 桌面 | 1480×747 | 2 | 关闭 |
| iPhone 12 竖屏 | 390×844 | 3 | 开启 |
| iPhone 横屏 | 844×390 | 3 | 开启 |
| iPhone 可视高度缩小 | 390×480 | 3 | 开启 |

12 组完整状态一致。每次断流保留中文草稿并禁用输入；恢复后输入重新启用，消息节点身份保留，无页面横向溢出。三个循环分别记录累计 2／3／4 次打开，活动流均为 1、等待流为 0，无应用错误。逐样本核验视口、DPR 与触控参数。手机验收面板使用触控事件，并检查点击点未被遮挡。

首轮手机脚本将验收面板 summary 当成 button，因定位失败停止。检查真实 DOM 后修正目标类型，单独执行三种手机模式；首轮已完成的桌面结果保留，没有把脚本失败归为应用失败或跳过手机检查。

## 限制与运行状态

本报告证明连接协调迁移及上述恢复流程，不能证明全应用迁移完成或性能整体通过。未声称实体软键盘、IME 候选窗或系统选区已经验证。

本轮 SSH 只读身份重试约 15 秒超时；预览 SSH 状态为 error，模型、项目读取返回 503。历史成功记录仍保留，但不能代表当前 SSH 可用。未停止远端服务、会话或任务。

代码提交时独立预览仍运行 `accb11f`；本轮新资源已在静态隔离入口验收。更新实际预览须重新检查待处理请求及连接中状态，再记录运行版本。正式 4317／4318／4319 未更新。
