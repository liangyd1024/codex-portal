# 点击轮次导航后加载完整历史

## 行为

按用户本轮指定的交互调整。首次进入会话保持原有最近历史读取。悬停、聚焦不触发完整历史请求。点击桌面刻度时立即定位，同时顺序读取全部剩余历史页；顶部箭头也可触发。手机打开轮次目录时触发同样的加载。原始正文与原生轮次 ID 保持不变。

复用历史分页、正文节点缓存和滚动锚点。每次只有一个扩展加载流程，不并发拉取历史，不增加轮询。加载时显示已加载轮数；支持取消、失败重试。取消只停止后续翻页，在途页仍可正常完成并保留。切换连接或会话后，旧流程停止，不更新新会话的加载提示。已有历史读接口负责拒绝迟到响应。

完整加载后不再发起历史请求。大量刻度仍沿用可滚动导航，不强行压缩到一个屏幕。

- 基于 `7894170` 的独立源码快照，仅包含本次修改，执行 `npm test`：393 项 Node、68 项 Python 通过。快照用于排除其他会话同时进行的正文渲染修改。
- 新增单元测试覆盖顺序翻页、进度回调、完成后不再请求、失败续载、在途取消、上下文失效、繁忙和游标未推进。
- ego-browser 桌面模拟：初始 16 轮、0 次历史请求；点击一次补齐到 21 轮、3 次历史请求。加载中重复点击未增加请求，所选轮次相对正文顶部偏移从 11.5px 到 11px，无横向溢出或 JavaScript 错误。
- 模拟失败后保留现有轮次，点击重试完成加载。模拟在途取消后仅完成当前页，不再翻页；续载仅请求剩余两页。
- 模拟键盘 Enter 触发后切换会话，旧页返回未覆盖新会话刻度或提示，也未继续请求历史。
- 390px 模拟手机：目录自动加载、取消及续载通过。完整目录与关闭按钮可见，没有页面横向溢出。Escape 关闭后焦点返回“更多操作”，输入草稿保留。桌面与手机截图均已查看。

## 性能与范围

首次进入没有新增历史请求。五个早期轮次按每页两轮模拟验证了三个串行请求，重复点击不重复请求。每页之间让出事件循环，沿用原有缓存和滚动保持逻辑。

更长历史的模拟性能采样期间，其他会话修改了正文渲染逻辑，因此不将该采样作为本次版本的性能结论。未测量真实 SSH 网络、完整长会话的 CPU、内存或磁盘开销，不声称性能最优或任意规模下无卡顿。加载全部正文仍会增加内存及渲染成本。浏览器业务请求全部为模拟，没有向真实会话发送消息或接管任务。

未重新实测 Codex 原生界面、实体手机及输入法；本次未修改输入流程。
