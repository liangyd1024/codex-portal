# 正文过程摘要验收（2026-10-24）

代码版本：`13b2be4`。

## 依据与变更

用户确认以所提供 Codex 截图为交互参考：正文之间显示简短动作摘要，点击展开原始详情，运行时显示状态，结束后折叠过程。未进行桌面 Codex 实时像素对比。

通过本机 Codex `app-server generate-json-schema` 核对 `ThreadReadResponse` 的 `commandActions`：支持 `read`、`listFiles`、`search`、`unknown`。摘要只根据这些原生字段分类，不解析命令字符串猜测行为；缺少分类时显示通用命令摘要。相同动作在摘要中合并，展开详情仍保留所有条目及顺序。

保留已有正文分组、最终回复、耗时、原始工具详情和展开状态机制。运行中显示执行状态；当前原生思考条目显示“正在思考”；命令非零退出显示“执行未成功”。历史命令不能凭旧状态证明仍在运行，只有实时后台进程匹配才显示后台运行。补充系统错误、拒绝结束状态的判断。

重连继续使用现有连接横幅和状态未确认提示。不生成或改写原生重连日志，不将网络日志当成助手正文。本轮未改变输入、网络协议或任务执行。
